# Design token leveling review

Scope: `packages/ui/src/styles/*`, `packages/ui/test/token-lock.json` + `packages/ui/scripts/check-tokens.mjs`, `packages/app/src/theme/{schema,tokens}.stylex.ts`, `packages/app/lint/design-scale.js` + `oxlint.config.ts`, and how `create()` calls in `packages/app/src`, `packages/ui/src` and `packages/canvas/src` use them. I read all of it and ran no code. Counts come from `grep` over `*.ts`/`*.tsx` with tests excluded. **Seen** means I read it in the code. **Inferred** means it follows from the code but I didn't render anything to check.

---

## 1. How the area works today

There are three layers. (1) **Raw ramps.** `theme.stylex.ts` declares a 20-step ramp (`steps` 0…150, `theme.stylex.ts:3-5`) for each hue as `--nyte-theme-N` / `--nyte-theme-translucent-N`. Hue scopes are made with `createTheme` (`:595-631`). (2) **Values.** `roles.stylex.ts:32-100` maps colour roles onto ramp steps with `light-dark()` and `prefers-contrast` pairs (`step(light, dark)`, `:4-5`). `tinted`/`accent` (`:102-128`) re-point some roles when a hue scope is active, and `surface-theme.ts` pairs a ramp with `tinted`/`accent` to make `surfaceTheme` and `intent` (`ui/src/surface-theme.ts:16-37`). `tokens.stylex.ts` declares type (`:32-56`), one space unit (`:58-60`), motion (`:62-70`), elevation (`:22-30`, with one more shadow, `--nyte-shadow-md-outline`, living in `roles.stylex.ts:98`) and a long flat `components` group (`:72-327`) of per-component px values with coarse-pointer branches. App layout values go in `app/src/theme/tokens.stylex.ts:6-86`. (3) **Handles.** `vars.stylex.ts` (`role`, `type`, `motion`, `shadow`, `appearance`) and `schema.stylex.ts` (`space`, `glyph`, `avatar`, `button`, `input`, `row`, `menu`, `dialog`, `radius`, `layer`, …) re-export each custom property as a `defineConsts` string. The app adds `shell`, `sidebar`, `settings`, `workbench`, … in `app/src/theme/schema.stylex.ts`. `text.stylex.ts:5-21` is the only composed preset (size, leading and tracking per level). `check-tokens.mjs:15-70` locks only the **names** of properties and handles, not their values. `design-scale.js` enforces the space scale (`:8-20`, `:418-427`), a 2px size grid (`:429-446`), a control-size lookup against a hand-copied table of token px values (`BOX_HANDLES`, `:22-45`, `:479-510`), no literal colours (`:453-477`), no raw weights (`:550-577`), no `light-dark()` outside tokens (`:579-594`) and no coarse-pointer forks (`:517-534`). Nothing checks font size, line height, radius, duration, easing, z-index or JSX `size=` props (`oxlint.config.ts:289-323`). In use, the 287 `text.*` preset uses sit next to 104 hand-written `fontSize: type.*` declarations, and component-specific tokens (`menu.*`, `row.*`, `dialog.*`, `tray.*`, …) are used alongside the generic scales they duplicate.
