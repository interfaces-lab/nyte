description: "Tokens, styled primitives, and headless Base UI re-exports, shipped as @nyte-ai/ui"
---

`@nyte-ai/ui` wraps [Base UI](https://base-ui.com) in StyleX styles driven by `--nyte-*` custom
properties. Components with a styled wrapper come from the package root. Everything else
re-exports Base UI unstyled from its own subpath.

```ts
import "@nyte-ai/ui/styles.css";
import { Button } from "@nyte-ai/ui";
import { Popover } from "@nyte-ai/ui/popover";
```

Change how a primitive looks with [token overrides, `className`, or
`xstyle`](/cloud/foundations/theming).
