```ts title="Import"
import { Autocomplete } from "@nyte-ai/ui";
```

The same `Autocomplete` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Autocomplete } from "@nyte-ai/ui/autocomplete";
```

A search field that filters a list as the user types. Reach for it when a choice comes from a list
too long to scan, such as fonts or models.

## Usage

- `Autocomplete.Trigger` is a compact select-style button. Its children become the ellipsised value
  and a chevron follows them.
- `Autocomplete.Popup` is a 280px panel, at most 320px tall, with no padding. An
  `Autocomplete.Input` inside it is a search bar with a hairline beneath. The list scrolls below it.
- Rendered with `inline` and no popup, for example inside a [Menu](/cloud/components/menu), the
  input, list, rows, and group labels take menu row geometry instead.
- `selected` on `Autocomplete.Item` shows a trailing checkmark for the current value. Inline, the
  row is also filled.
- Pass the data to `items` on the root and render each entry from a function child on
  `Autocomplete.List`. Inside a group, render the group's entries with `Autocomplete.Collection`.
- Each `Autocomplete.Item` takes a `value` identifying it. Pass the item being rendered so props like
  `itemToStringValue` receive it. Act on a pick in its `onClick`.
- `value` with `onValueChange` on the root controls the search text. Clear it in `onOpenChange` so
  the next open starts fresh.
- `mode` decides how filtering and inline completion work. `"list"`, the default, filters items and
  leaves the input alone. `"none"` does neither, for a list you filter yourself.
- `autoHighlight` highlights the first match as the user types.
- Keep `Autocomplete.Status` and `Autocomplete.Empty` mounted. Their content is announced politely,
  so update their children instead of hiding the element. `Autocomplete.Status` takes padding only
  while it has content.
- `Autocomplete.Positioner` defaults to `side="bottom"`, `align="center"`, `positionMethod="fixed"`,
  and `collisionPadding={8}`.
- The popup attaches the ref from [Overlays](/cloud/foundations/overlays), so a host can keep it
  above native views.

## Anatomy

```tsx
<Autocomplete.Root>
  <Autocomplete.Trigger />
  <Autocomplete.Portal>
    <Autocomplete.Positioner>
      <Autocomplete.Popup>
        <Autocomplete.Input />
        <Autocomplete.Status />
        <Autocomplete.List>
          <Autocomplete.Group>
            <Autocomplete.Separator />
            <Autocomplete.GroupLabel />
            <Autocomplete.Collection>
              <Autocomplete.Item />
            </Autocomplete.Collection>
          </Autocomplete.Group>
        </Autocomplete.List>
        <Autocomplete.Empty />
      </Autocomplete.Popup>
    </Autocomplete.Positioner>
  </Autocomplete.Portal>
</Autocomplete.Root>
```

## Examples

### Searchable picker

<Preview>
  <AutocompleteDemo />
</Preview>

```tsx
interface ModelGroup {
  readonly label: string;
  readonly items: readonly string[];
}

const groups: readonly ModelGroup[] = [
  { label: "Anthropic", items: ["claude-opus-4-6", "claude-sonnet-4-6", "claude-haiku-4-5"] },
  { label: "OpenAI", items: ["gpt-5.2"] },
  { label: "Google", items: ["gemini-3-pro"] },
];

const [model, setModel] = useState("claude-sonnet-4-6");
const [search, setSearch] = useState("");

<Autocomplete.Root
  items={groups}
  value={search}
  autoHighlight
  onValueChange={setSearch}
  onOpenChange={(open) => {
    if (!open) setSearch("");
  }}
>
  <Autocomplete.Trigger aria-label="Model">{model}</Autocomplete.Trigger>
  <Autocomplete.Portal>
    <Autocomplete.Positioner sideOffset={4}>
      <Autocomplete.Popup>
        <Autocomplete.Input aria-label="Search models" placeholder="Search models" />
        <Autocomplete.List>
          {(group: ModelGroup, index: number) => (
            <Autocomplete.Group key={group.label} items={group.items}>
              {index > 0 && <Autocomplete.Separator />}
              <Autocomplete.GroupLabel>{group.label}</Autocomplete.GroupLabel>
              <Autocomplete.Collection>
                {(item: string) => (
                  <Autocomplete.Item
                    key={item}
                    value={item}
                    selected={item === model}
                    onClick={() => setModel(item)}
                  >
                    {item}
                  </Autocomplete.Item>
                )}
              </Autocomplete.Collection>
            </Autocomplete.Group>
          )}
        </Autocomplete.List>
        <Autocomplete.Empty>No models match</Autocomplete.Empty>
      </Autocomplete.Popup>
    </Autocomplete.Positioner>
  </Autocomplete.Portal>
</Autocomplete.Root>;
```

### Inside a menu

With `inline` and `open`, the list renders in place. The rows match the menu's.

```tsx
<MenuSubmenu label="Model" value={model}>
  <Autocomplete.Root inline open items={models} value={search} onValueChange={setSearch}>
    <Autocomplete.Input aria-label="Search models" placeholder="Search models" />
    <MenuSeparator />
    <Autocomplete.List>
      {(item: string) => (
        <Autocomplete.Item
          key={item}
          value={item}
          selected={item === model}
          onClick={() => setModel(item)}
        >
          {item}
        </Autocomplete.Item>
      )}
    </Autocomplete.List>
  </Autocomplete.Root>
</MenuSubmenu>
```

## Props

`Autocomplete.Trigger`, `Input`, `Positioner`, `Popup`, `Status`, `Empty`, `List`, `GroupLabel`,
`Item`, and `Separator` take `xstyle`, and `className` and `style` as plain values, not functions of
state. See [Theming](/cloud/foundations/theming). The other parts are Base UI's.

| Prop       | Type      | Default | Description                                                   |

## Accessibility

- Name the input with an `aria-label`. Give the trigger an `aria-label` naming the field, since its
  text is only the current value.
- `Autocomplete.Input` renders `role="combobox"`, `Autocomplete.List` renders `role="listbox"`, and
  each `Autocomplete.Item` renders `role="option"`. The checkmark is hidden from assistive
  technology.
- Arrow Down and Up move the highlight through the items. `loopFocus` wraps at the ends. Enter picks
  the highlighted item. Escape closes the popup.
- `Autocomplete.Status` and `Autocomplete.Empty` announce their content politely, which covers async
  loading and empty results.
- `Autocomplete.GroupLabel` labels its parent group.
- The trigger shows the focus ring on keyboard focus. See [Focus](/cloud/foundations/focus).
- The popup appears without motion under `prefers-reduced-motion: reduce`.
