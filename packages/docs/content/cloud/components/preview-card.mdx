```ts title="Import"
import { PreviewCard } from "@nyte-ai/ui";
```

The same `PreviewCard` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { PreviewCard } from "@nyte-ai/ui/preview-card";
```

A card that previews where a link goes, shown on hover or a touch or pen hold. Reach for it when a sighted reader benefits
from seeing the destination before clicking.

## Usage

- `PreviewCard.Popup` paints a raised card, a column at most 260px wide with 8px padding, and fades
  in with a slight scale. Style what goes inside it yourself.
- The trigger renders an `<a>` with no look of its own. Give it a real `href`, since the link is the
  keyboard and screen reader navigation target. Pass `render` to put the trigger
  on another element, such as a list row.
- A 500ms touch or pen hold opens the preview and suppresses the following click. Moving more
  than 8px or cancelling the pointer ends the hold.
- Put everything the card shows on the linked page as well. Nothing unique lives in the popup.
- The card opens after `delay`, which is 600ms, and closes after `closeDelay`, which is 300ms. Both
  live on the trigger.
- `PreviewCard.Positioner` defaults to `side="bottom"`, `align="center"`, `positionMethod="fixed"`,
  and `collisionPadding={8}`. Pass `sideOffset` for the gap.
- To open from a trigger outside the root, pass one handle from `PreviewCard.createHandle()` to both
  the trigger and the root.
- The popup attaches the ref from [Overlays](/cloud/foundations/overlays), so a host can keep it
  above native views.

## Anatomy

```tsx
<PreviewCard.Root>
  <PreviewCard.Trigger />
  <PreviewCard.Portal>
    <PreviewCard.Backdrop />
    <PreviewCard.Positioner>
      <PreviewCard.Popup>
        <PreviewCard.Arrow />
        <PreviewCard.Viewport />
      </PreviewCard.Popup>
    </PreviewCard.Positioner>
  </PreviewCard.Portal>
</PreviewCard.Root>
```

```tsx
import { create, props } from "@stylexjs/stylex";
import { focus } from "@nyte-ai/ui/a11y.stylex";
import { intent } from "@nyte-ai/ui/surface-theme";
import { role, type } from "@nyte-ai/ui/vars.stylex";

const styles = create({
  link: {
    color: role.contentSecondary,
    fontSize: type.fontBase,
    textDecorationLine: "underline",
    textUnderlineOffset: "2px",
  },
  title: { fontWeight: 500 },
  detail: { color: role.contentSecondary, fontSize: type.fontSm, lineHeight: type.leadingSm },
});

<PreviewCard.Root>
  <PreviewCard.Trigger
    href="/cloud/components/button"
    {...props(intent.primary, styles.link, focus.ring)}
  >
    Button
  </PreviewCard.Trigger>
  <PreviewCard.Portal>
    <PreviewCard.Positioner sideOffset={8}>
      <PreviewCard.Popup>
        <span {...props(styles.title)}>Button</span>
        <span {...props(styles.detail)}>Variants and sizes.</span>
      </PreviewCard.Popup>
    </PreviewCard.Positioner>
  </PreviewCard.Portal>
</PreviewCard.Root>;
```

### Timing

Open sooner and keep the card up longer.

```tsx
<PreviewCard.Trigger href="/docs/sdk" delay={200} closeDelay={600}>
  SDK
</PreviewCard.Trigger>
```

### Wider card

`xstyle` on the popup overrides its size.

```tsx
const styles = create({
  card: { width: 280, maxWidth: "min(280px, var(--available-width))", padding: 10 },
});

<PreviewCard.Popup xstyle={styles.card}>{children}</PreviewCard.Popup>;
```

## Accessibility

- The popup is a visual preview, not a replacement for the linked page. Touch and pen users
  can open it with a 500ms hold. Keep essential information on the destination.
- The link is the accessible interface. Screen reader users read the link text and continue,
  without being walked through the preview.
- The trigger carries `data-popup-open` while the card is open.
- Escape closes the card. Outside press closes it.
- The card appears without motion under `prefers-reduced-motion: reduce`.
