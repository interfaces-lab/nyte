```ts title="Import"
import { PreviewCard, PreviewCardContent, PreviewCardTrigger } from "@nyte-ai/ui/preview-card";
```

A card with more about its trigger. For one line, use [Tooltip](/cloud/components/tooltip).

## Usage

- Touch never opens the card, so repeat its content elsewhere.

## Anatomy

```tsx
<PreviewCard>
  <PreviewCardTrigger />
  <PreviewCardContent />
</PreviewCard>
```

```tsx
import { Button } from "@nyte-ai/ui/button";

    fontSize: type.fontSm,
    lineHeight: type.leadingSm,
  },

<PreviewCard>

  <PreviewCardContent side="right" align="start" aria-label="Details for Fix flaky tests">
    <span {...props(styles.title)}>Fix flaky tests</span>
    <span {...props(styles.detail)}>
      <span {...props(styles.detailIcon)}>
```


### One card for a list

```tsx
import {
  createPreviewCardHandle,
  PreviewCard,
  PreviewCardContent,
  PreviewCardTrigger,
} from "@nyte-ai/ui/preview-card";

const [handle] = useState(() => createPreviewCardHandle<Suggestion>());

<>
  {suggestions.map((suggestion) => (
    <PreviewCardTrigger
      key={suggestion.id}
      handle={handle}
      payload={suggestion}
      delay={0}
      render={<div role="option">{suggestion.label}</div>}
    />
  ))}
  <PreviewCard handle={handle}>
    {({ payload }) =>
      payload === undefined ? null : (
        <PreviewCardContent side="right" align="end" sideOffset={6}>
          {payload.description}
        </PreviewCardContent>
      )
    }
  </PreviewCard>
</>;
```

### PreviewCardContent

Renders the portal, positioner, and popup. Positioning props go to the positioner and the rest to
the popup.

| Prop                 | Type                                                                       | Default    |
| -------------------- | -------------------------------------------------------------------------- | ---------- |
| `side`               | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `align`              | `"start" \| "center" \| "end"`                                             | `"center"` |
| `sideOffset`         | `number \| OffsetFunction`                                                 | `4`        |
| `alignOffset`        | `number \| OffsetFunction`                                                 |            |
| `collisionAvoidance` | `CollisionAvoidance`                                                       |            |
| `tint`               | `Tint`                                                                     |            |

## Accessibility

- Keyboard focus on the trigger opens the card after `delay`. Escape and an outside press close
  it.
- The card appears without motion under `prefers-reduced-motion: reduce`.
