---
title: Kbd
description: "A keyboard shortcut drawn as a key cap"
---

```ts title="Import"
import { Kbd } from "@nyte-ai/ui/kbd";
```

## Usage

- Pass one string per key in display order.

## Examples

<Preview>
  <KbdDemo />
</Preview>

```tsx
<Kbd keys={["⌘", "K"]} />
<Kbd keys={["⇧", "⌘", "D"]} />
<Kbd keys={["⌘", "N"]} plain />
```

## Props

| Prop        | Type                  | Default | Description                                |
| ----------- | --------------------- | ------- | ------------------------------------------ |
| `keys`      | `readonly string[]`   |         |                                            |
| `plain`     | `boolean`             | `false` | No fill and no padding.                    |
| `xstyle`    | `XStyle`              |         | See [Theming](/cloud/foundations/theming). |
| `className` | `string`              |         | See [Theming](/cloud/foundations/theming). |
| `style`     | `React.CSSProperties` |         | See [Theming](/cloud/foundations/theming). |

## Accessibility

- Renders a `<kbd>` with one `<span>` per key.
