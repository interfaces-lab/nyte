The same `Select` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Select } from "@nyte-ai/ui/select";
```

A 24px trigger showing the current option. It opens a list below itself and writes back the
option the user picks. Reach for it when a setting takes one of a few named values. For a
searchable list use [Autocomplete](/cloud/components/autocomplete).

## Usage

- `options` is the whole list. Each option has a `value`, a `label`, and an optional `fontFamily`
  that renders that option in its own typeface.
- The select is controlled. Pass `value` and update it in `onValueChange`, which receives the
  option's `value` typed as `T`.
- `label` names the trigger for assistive technology. It is not rendered.
- The trigger is 112 to 180px wide. `width="wide"` lets it fill its container.
- The list opens below the trigger, aligned to its end, and flips above when there is no room.

```tsx
type Theme = "system" | "light" | "dark";

const themes = [
  { value: "system", label: "System" },
  { value: "light", label: "Light" },
  { value: "dark", label: "Dark" },
] as const satisfies readonly SelectOption<Theme>[];

const [theme, setTheme] = useState<Theme>("system");

<Select<Theme> label="Theme" value={theme} options={themes} onValueChange={setTheme} />;
```

## Props

`xstyle`, `className`, and `style` land on the trigger.

| Prop                           | Type                                      | Default      | Description                            |
| ------------------------------ | ----------------------------------------- | ------------ | -------------------------------------- |
| `label`                        | `string`                                  |              | Accessible name of the trigger.        |
| `value`                        | `T extends string`                        |              | The selected option's value.           |
| `options`                      | `readonly SelectOption<T>[]`              |              | The list, in order.                    |
| `onValueChange`                | `(value: T) => void`                      |              | Called with the picked option's value. |
| `disabled`                     | `boolean`                                 | `false`      | Dims the trigger and blocks opening.   |
| `width`                        | `"standard" \| "wide"`                    | `"standard"` | `wide` fills the container.            |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming) |              |                                        |

`SelectOption<T>` is `{ value: T; label: string; fontFamily?: string }`.

## Accessibility

- The trigger renders `role="combobox"`, the list `role="listbox"`, and each option `role="option"`
  with `aria-selected`.
- Arrow keys move the highlight, Enter selects, and Escape closes the list.
- Typing matches option labels.
- The focus ring appears on keyboard focus. See [Focus](/cloud/foundations/focus).
