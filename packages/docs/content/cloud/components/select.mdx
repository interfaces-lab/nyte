```ts title="Import"
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@nyte-ai/ui/select";
```

For a searchable list, use [Autocomplete](/cloud/components/autocomplete).

## Usage

- Pass `items` to `Select` so `SelectValue` shows the chosen label instead of the raw value.
- `onValueChange` can receive `null`.
- Name the trigger with `aria-label`.

## Anatomy

```tsx
<Select>
  <SelectTrigger>
    <SelectValue />
  </SelectTrigger>
  <SelectContent>
    <SelectItem value="choice">Choice</SelectItem>
  </SelectContent>
</Select>
```

```tsx
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@nyte-ai/ui/select";
import { useState } from "react";

type Theme = "system" | "light" | "dark";

const themes = [
  { value: "system", label: "System" },
  { value: "light", label: "Light" },
  { value: "dark", label: "Dark" },
] as const satisfies readonly { readonly value: Theme; readonly label: string }[];

function ThemeSelect() {
  const [theme, setTheme] = useState<Theme>("system");

  return (
    <Select
      items={themes}
      value={theme}
      onValueChange={(next) => {
        if (next !== null) setTheme(next);
      }}
    >
      <SelectTrigger aria-label="Theme">
        <SelectValue />
      </SelectTrigger>
      <SelectContent>
        {themes.map((option) => (
          <SelectItem key={option.value} value={option.value} label={option.label}>
            {option.label}
          </SelectItem>
        ))}
      </SelectContent>
    </Select>
  );
}
```

<SelectTrigger aria-label="Default model" width="wide">
  <SelectValue />
</SelectTrigger>

## Accessibility

- The trigger has `role="combobox"`, the list `role="listbox"`, and each option `role="option"`
  with `aria-selected`.
- Arrow keys move through the options, Enter picks, and Escape closes. Typing matches option
  labels.
- Keyboard focus on the trigger shows the [focus ring](/cloud/foundations/focus).
