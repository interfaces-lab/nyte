A menu that opens where the user right clicks or long presses inside an area. It shares the
surface and rows of [Menu](/cloud/components/menu).

## Usage

- Treat a context menu as a shortcut. Users may not discover it, especially on touch devices or
  with assistive technology, so expose the same actions from a visible control such as a
  [Menu](/cloud/components/menu) button.
- `trigger` is the area that responds to right click and long press. It receives the handlers, so
  pass an element that renders its own node.
- `label` names the popup for assistive technology.
- Items run `onSelect` and close the menu.
- `xstyle`, `className`, and `style` go to the popup on `ContextMenu` and to the row on
  `ContextMenuItem`.
- The popup attaches the ref from [Overlays](/cloud/foundations/overlays).

## Anatomy

```tsx
<ContextMenu>
  <ContextMenuItem />
  <ContextMenuSeparator />
</ContextMenu>
```

## Props

Every component below also takes `className` and `style`, merged onto the same element as
`xstyle`. See [Theming](/cloud/foundations/theming).

### ContextMenu

| Prop           | Type                                    | Default | Description                           |
| -------------- | --------------------------------------- | ------- | ------------------------------------- |
| `label`        | `string`                                |         | Accessible name of the popup.         |
| `trigger`      | `React.ReactElement`                    |         | The area that opens the menu.         |
| `open`         | `boolean`                               |         | Controlled open state.                |
| `onOpenChange` | `(open: boolean, eventDetails) => void` |         | Called when the menu opens or closes. |
| `xstyle`       | `XStyle`                                |         | Merged last onto the popup.           |

The popup opens at the pointer, keeps 8px from the viewport edge, and flips when there is no room.

### ContextMenuItem

Takes `onSelect`, `icon`, `leading`, `meta`, `danger`, `disabled`, `textValue`, `size`, `layout`,
`background`, and `xstyle`, as [MenuItem](/cloud/components/menu#menuitem) does.

### ContextMenuSeparator

Takes `xstyle`, `className`, and `style`.

## Accessibility

- Right click or long press inside the trigger opens the menu. Escape closes it.
- The popup has `role="menu"` and the `label` as its name. Items are `menuitem`.
- Arrow Down and Up move the highlight and wrap. Typing matches item text, overridden by
  `textValue`. Enter and Space activate.
- Disabled items stay reachable with the arrow keys and do not activate.
