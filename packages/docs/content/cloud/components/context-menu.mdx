A menu that opens at the pointer on right click or long press. Use it as a shortcut to actions that
also have a visible control, since many people never right-click.

## Usage

- Name `ContextMenuContent` with `aria-label`.

## Anatomy

```tsx
<ContextMenu>
  <ContextMenuTrigger />
  <ContextMenuContent>
    <ContextMenuGroup>
      <ContextMenuGroupLabel />
      <ContextMenuItem />
      <ContextMenuLinkItem />
      <ContextMenuCheckboxItem />
    </ContextMenuGroup>
    <ContextMenuSeparator />
    <ContextMenuRadioGroup>
      <ContextMenuRadioItem value="choice" />
    </ContextMenuRadioGroup>
    <ContextMenuSub>
      <ContextMenuSubTrigger />
      <ContextMenuSubContent>
        <ContextMenuItem />
      </ContextMenuSubContent>
    </ContextMenuSub>
  </ContextMenuContent>
</ContextMenu>
```

### ContextMenuContent

Renders the portal, positioner, and popup. Positioning props go to the positioner and the rest,
including `ref`, to the popup. The popup opens at the pointer unless `anchor` is set.

| Prop                 | Type                 | Default                                                      |
| -------------------- | -------------------- | ------------------------------------------------------------ |
| `collisionAvoidance` | `CollisionAvoidance` | `{ side: "flip", align: "shift", fallbackAxisSide: "none" }` |
| `collisionPadding`   | `number \| Padding`  | `8`                                                          |
| `tint`               | `Tint`               |                                                              |

Takes the same props as `ContextMenuContent`.

## Accessibility

- The popup has `role="menu"`. Items are `menuitem`, radio items `menuitemradio`, and checkbox
  items `menuitemcheckbox` with `aria-checked`.
- Arrow Down and Up move focus and wrap. Typing matches item text, or `label` when set. Enter and
  Space activate. Escape closes.
- Arrow Right opens a submenu. Arrow Left closes it.
- Disabled items stay reachable with the arrow keys and do not activate.
