```ts title="Import"
import {
  NumberField,
  NumberFieldDecrement,
  NumberFieldGroup,
  NumberFieldIncrement,
  NumberFieldInput,
} from "@nyte-ai/ui/number-field";
```

For a small bounded value, such as a font size.

## Usage

- Both value callbacks receive `null` when the input is cleared.
- Save in `onValueCommitted`. It fires when the user leaves the input, releases a button, or presses
  an arrow key, not on every keystroke.
- The buttons default to "−" and "+". Pass children to replace them.

## Anatomy

```tsx
<NumberField>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

```tsx
<NumberField
  defaultValue={settings.uiFontSize}
  min={12}
  max={16}
  onValueCommitted={(uiFontSize) => {
    if (uiFontSize !== null) save({ uiFontSize });
  }}
>
  …
</NumberField>
```

## Accessibility

- Name `NumberFieldInput` with `aria-label` or a label.
- Arrow Up and Arrow Down step the value. Home and End jump to `min` and `max` when set.
- Alt with an arrow steps by `smallStep`, Shift by `largeStep`.
- The group shows the focus outline while anything inside it has focus.
