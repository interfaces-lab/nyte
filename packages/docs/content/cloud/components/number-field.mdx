import { NumberField } from "@nyte-ai/ui";

The same `NumberField` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { NumberField } from "@nyte-ai/ui/number-field";
```

A 24px stepper. A minus button, the value, and a plus button share one frame. Reach for it for a
small bounded integer, such as a font size.

## Usage

- `label` is required. It names the input, and the buttons become "Decrease …" and "Increase …"
  with the label in lower case.
- `value` with `onValueChange` controls the field. `defaultValue` leaves it uncontrolled.
- `onValueChange` receives a number. Clearing the input does not call it.
- `min`, `max`, and `step` bound the value. `step` defaults to 1.
- `format` takes `Intl.NumberFormatOptions`, so a percent is a format option, not a suffix.

## Props

Every Base UI `NumberField.Root` prop passes through, except `render` and `children`, and
`onValueChange` is narrowed to numbers.

| Prop                           | Type                                      | Default | Description                          |
| ------------------------------ | ----------------------------------------- | ------- | ------------------------------------ |
| `label`                        | `string`                                  |         | Names the input and its two buttons. |
| `onValueChange`                | `(value: number) => void`                 |         | Called with each committed number.   |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming) |         |                                      |

## Accessibility

- Arrow Up and Arrow Down step the value. Home and End jump to `min` and `max`, when those bounds
  are set.
- Alt with an arrow key steps by `smallStep`, Shift by `largeStep`.
- The frame shows the focus ring while the input inside it has keyboard focus.
