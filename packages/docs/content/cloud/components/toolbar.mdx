```ts title="Import"
import { Toolbar } from "@nyte-ai/ui";
```

The same `Toolbar` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Toolbar } from "@nyte-ai/ui/toolbar";
```

Lays out a row of [Button](/cloud/components/button) and [Toggle](/cloud/components/toggle) controls
and moves focus between them with the arrow keys, so the whole toolbar is one stop in the tab
order.

## Usage

- `Toolbar.Button` renders a `Button`. Pass a `Button`, a `Toggle`, or a popup trigger to `render`
  to set its variant, size, and label.
- Toolbar items stay focusable while disabled by default, which keeps the arrow key order stable.
  Pass `focusableWhenDisabled={false}` to drop an item out of it.
- `Toolbar.Separator` draws a hairline across the toolbar's axis.
- `Toolbar.Root` lays its items out in a row with a 2px gap. Size and edge it with `xstyle`.

## Anatomy

```tsx
<Toolbar.Root>
  <Toolbar.Button />
  <Toolbar.Separator />
  <Toolbar.Group>
    <Toolbar.Button />
    <Toolbar.Button />
  </Toolbar.Group>
</Toolbar.Root>
```

```tsx
<Toolbar.Root aria-label="Layout">
  <Toolbar.Group aria-label="Panels">
    <Toolbar.Button
      render={<Toggle iconOnly icon="panel-left" aria-label="Sidebar" defaultPressed />}
    />
    <Toolbar.Button render={<Toggle iconOnly icon="console" aria-label="Terminal" />} />
  </Toolbar.Group>
  <Toolbar.Separator />
  <Toolbar.Button render={<Button iconOnly icon="refresh" aria-label="Refresh" />} />
  <Toolbar.Button render={<Button iconOnly icon="trash" aria-label="Delete" />} />
</Toolbar.Root>
```

### With a tooltip

A tooltip goes the other way around. The toolbar item is the `trigger` of a
[Hint](/cloud/components/tooltip).

```tsx
<Toolbar.Root aria-label="Changes">
  <Hint
    content="Refresh"
    trigger={
      <Toolbar.Button
        render={<Button iconOnly icon="refresh" aria-label="Refresh" title={undefined} />}
      />
    }
  />
</Toolbar.Root>
```

## Props

`Toolbar.Root`, `Toolbar.Group`, and `Toolbar.Separator` take `xstyle`, and `className` and `style`
as plain values. `Toolbar.Button` passes `className` and `style` to what it renders.

## Accessibility

- `Toolbar.Root` renders `role="toolbar"`. Label it with `aria-label` or `aria-labelledby`.
- Arrow keys move focus between items. Focus wraps at the end unless you pass `loopFocus={false}`.
- Orientation follows the `orientation` prop and lands on `data-orientation` for every part.
- A disabled item gets `data-disabled`, and `data-focusable` while it remains reachable by arrow
  key.
