```ts title="Import"
import { Icon, PanelToggleIcon } from "@nyte-ai/ui/icon";
```

## Usage

- `Icon` takes the text color of its parent.
- `PanelToggleIcon` animates its divider as the panel shows or hides, except under reduced motion.

## Examples

<Preview>
  <IconDemo />
</Preview>

```tsx
<Icon name="folder" />
<Icon name="folder" variant="filled" />
<Icon name="warning" size={14} label="Warning" />
<Icon name="sparkle" size={12} />
```

### Panel toggle

<Preview>
  <PanelToggleIconDemo />
</Preview>

```tsx
const [visible, setVisible] = useState(true);

<Button
  iconOnly
  aria-label={visible ? "Hide sidebar" : "Show sidebar"}
  onClick={() => setVisible(!visible)}
>
  <PanelToggleIcon side="left" visible={visible} />
</Button>;
```

## Props

### Icon

| Prop        | Type                     | Default      | Description                                 |
| ----------- | ------------------------ | ------------ | ------------------------------------------- |
| `name`      | `IconName`               |              |                                             |
| `size`      | `number`                 | `16`         | Width and height in pixels.                 |
| `variant`   | `"outlined" \| "filled"` | `"outlined"` | Stroke or fill.                             |
| `label`     | `string`                 |              | Announced as `role="img"`. Omit to hide it. |
| `xstyle`    | `XStyle`                 |              | See [Theming](/cloud/foundations/theming).  |
| `className` | `string`                 |              | See [Theming](/cloud/foundations/theming).  |
| `style`     | `React.CSSProperties`    |              | See [Theming](/cloud/foundations/theming).  |

### PanelToggleIcon

| Prop      | Type                | Default | Description                   |
| --------- | ------------------- | ------- | ----------------------------- |
| `side`    | `"left" \| "right"` |         | The panel's edge.             |
| `visible` | `boolean`           |         | Whether the panel is showing. |
| `size`    | `number`            | `16`    | Width and height in pixels.   |

## Accessibility

- Without `label`, the icon is `aria-hidden`. An icon-only control needs its own `aria-label`.
- `PanelToggleIcon` is always hidden. Name the control that holds it.
