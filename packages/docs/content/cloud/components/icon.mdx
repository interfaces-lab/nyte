```ts title="Import"
import { Icon, PanelToggleIcon } from "@nyte-ai/ui";
```

The same names are exported from their own subpath. Pick one path per file.

```ts title="Subpath"
import { Icon, PanelToggleIcon } from "@nyte-ai/ui/icon";
```

A glyph chosen by a semantic name. Reach for it wherever a surface needs an icon, rather than
importing a glyph from Central Icons.

## Usage

- An icon is decorative and hidden from assistive tech unless it has a `label`. Label it only when
  nothing beside it says the same thing.
- It takes the text color of its parent.
- Controls draw their glyphs at 12, 14, or 16. [Button](/cloud/components/button) picks the size
  from its own `size` through the `icon` prop.
- `PanelToggleIcon` draws a panel outline whose divider moves as a panel shows or hides. The
  motion drops out under reduced motion.

### Panel toggle

<Preview>
  <PanelToggleIconDemo />
</Preview>

```tsx
const [visible, setVisible] = useState(true);

<Button
  size="icon"
  aria-label={visible ? "Hide sidebar" : "Show sidebar"}
  onClick={() => setVisible(!visible)}
>
  <PanelToggleIcon side="left" visible={visible} />
</Button>;
```

## Props

### Icon

| Prop        | Type                     | Default      | Description                                 |
| ----------- | ------------------------ | ------------ | ------------------------------------------- |
| `name`      | `IconName`               |              | One of the names under `IconName`.          |
| `size`      | `number`                 | `16`         | Width and height in pixels.                 |
| `variant`   | `"outlined" \| "filled"` | `"outlined"` | Stroke or fill drawing of the same glyph.   |
| `label`     | `string`                 |              | Announced as `role="img"`. Omit to hide it. |
| `xstyle`    | `XStyle`                 |              | See [Theming](/cloud/foundations/theming).  |
| `className` | `string`                 |              | See [Theming](/cloud/foundations/theming).  |
| `style`     | `React.CSSProperties`    |              | See [Theming](/cloud/foundations/theming).  |

### PanelToggleIcon

| Prop      | Type                | Default | Description                      |
| --------- | ------------------- | ------- | -------------------------------- |
| `side`    | `"left" \| "right"` |         | The edge the panel sits against. |
| `visible` | `boolean`           |         | Whether the panel is showing.    |
| `size`    | `number`            | `15`    | Width and height in pixels.      |

## Accessibility

- Without `label`, the icon carries `aria-hidden`. An icon-only control needs its own
  `aria-label`.
- `PanelToggleIcon` is always hidden. Name the control that holds it.
