```ts title="Import"
import { Tabs } from "@nyte-ai/ui";
```

The same `Tabs` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Tabs } from "@nyte-ai/ui/tabs";
```

One list of tabs, one panel visible at a time. Reach for it when the panels are peers and the reader
only needs one of them at a time.

## Usage

- `variant` on `Tabs.Root` sets the look of its list and every tab in it. A nested `Tabs.Root` sets
  its own.
- Each `Tabs.Tab` and each `Tabs.Panel` needs a matching `value`. Without `defaultValue` on the
  root, the first tab starts active.
- `value` with `onValueChange` controls the root. `value={null}` leaves no tab active.
- Tabs activate on Enter or Space. `activateOnFocus` on the list activates them on arrow key focus
  instead.
- A hidden panel unmounts unless you pass `keepMounted`. A kept panel carries `hidden`, so a panel
  whose `xstyle` sets `display` has to hide itself under `[hidden]`.
- `Tabs.Root` and `Tabs.Panel` bring no look of their own. Lay them out with `xstyle`.
- `Tabs.Indicator` is optional. It sits over the active tab and follows it. Paint it with `xstyle`.

## Anatomy

```tsx
<Tabs.Root>
  <Tabs.List>
    <Tabs.Tab />
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel />
</Tabs.Root>
```

Every part takes `xstyle`, and `className` and `style` as plain values, not functions of state.

## Accessibility

- The parts render `role="tablist"`, `role="tab"`, and `role="tabpanel"`. The indicator renders
  `role="presentation"`.
- Label `Tabs.List` with `aria-label` or `aria-labelledby`.
- Arrow keys move focus along the list. Focus wraps at the end unless you pass `loopFocus={false}`.
- Enter and Space activate the focused tab, unless `activateOnFocus` activates it on focus.
- A disabled first tab is skipped and the next enabled tab is selected. Server rendering does not
  know which tabs are disabled, so set `defaultValue` or `value` to an enabled tab.
- The focus ring appears on keyboard focus. See [Focus](/cloud/foundations/focus).
