```ts title="Import"
import { Tabs } from "@nyte-ai/ui/tabs";
```

## Usage

- `variant` styles the list and its tabs. Nested roots set their own.
- Each `Tabs.Tab` and `Tabs.Panel` needs a matching `value`. Without `defaultValue`, the first tab
  starts active.
- `value` with `onValueChange` controls the root. `value={null}` leaves no tab active.
- A hidden panel unmounts unless you pass `keepMounted`. A kept panel carries `hidden`, so an
  `xstyle` that sets `display` must also hide it under `[hidden]`.
- `Tabs.Root` and `Tabs.Panel` bring no look of their own. Lay them out with `xstyle`.
- Paint the optional `Tabs.Indicator` with `xstyle`.

## Anatomy

```tsx
<Tabs.Root>
  <Tabs.List>
    <Tabs.Tab />
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel />
</Tabs.Root>
```

## Accessibility

- The parts render `role="tablist"`, `role="tab"`, and `role="tabpanel"`. The indicator renders
  `role="presentation"`.
- Label `Tabs.List` with `aria-label` or `aria-labelledby`.
- Arrow keys move focus along the list. Focus wraps at the end unless you pass `loopFocus={false}`.
- Enter and Space activate the focused tab. With `activateOnFocus`, focus activates it. `segmented`
  turns `activateOnFocus` on by default.
- A disabled first tab is skipped. Server rendering cannot skip it, so set `defaultValue` or `value`
  to an enabled tab.
