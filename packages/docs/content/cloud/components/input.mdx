A single-line text field. `InputGroup` draws the frame around an `Input` and the glyphs or controls
beside it, such as a search icon or match toggles. For multi-line text use
[Textarea](/cloud/components/textarea).

## Usage

- Every input needs an accessible name from a `<label for>`, `aria-label`, or `aria-labelledby`.
  A placeholder is not a name.
- `raised` is the default frame, for panels and the workbench. `quiet` sits on a filled settings
  surface. `bare` drops the frame, for a field whose container already draws one.
- Inside an `InputGroup`, `Input` defaults to `bare`, takes the group's `size`, and grows to fill
  the row.
- `size` sets the type and, for a framed input or a group, the height. `sm` is 24px, `default` is
  28px, and `lg` is 36px.
- `value` with `onValueChange` controls the field. `onValueChange` receives the string.
- Set `aria-invalid` when validation fails. The border turns red.
- The input has no width of its own. Size it with the parent or with `xstyle`.

## Anatomy

```tsx
<InputGroup>
  <Icon />
  <Input />
</InputGroup>
```

### In a group

The group is a `<label>`, so a click on the icon focuses the input.

<Preview>
  <InputGroupDemo />
</Preview>

```tsx
<InputGroup>
  <Icon name="search" size={12} />
  <Input placeholder="Search" aria-label="Search workspace" />
</InputGroup>
<InputGroup variant="quiet">
  <Icon name="search" size={13} />
  <Input placeholder="Search models" aria-label="Search models" />
</InputGroup>
```

### Controlled

```tsx
const [query, setQuery] = useState("");

<Input aria-label="Search" value={query} onValueChange={setQuery} />;
```

## Props

### Input

Every Base UI `Input` prop passes through, except the native `size` attribute.

| Prop                           | Type                                      | Default                             | Description                  |
| ------------------------------ | ----------------------------------------- | ----------------------------------- | ---------------------------- |
| `variant`                      | `"raised" \| "quiet" \| "bare"`           | `"raised"`, `"bare"` inside a group | The frame.                   |
| `size`                         | `"sm" \| "default" \| "lg"`               | `"default"`, or the group's size    | Type size and framed height. |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming) |                                     |                              |

## Accessibility

- A native `<input>`, so all native keyboard behavior applies.
- `InputGroup` renders a `<label>`. An `aria-label` on the input still wins as its name.
- A framed input changes its border color on focus. A group does the same on `:focus-within`.
