title: Row
description: "One row of a list with a leading lane, a body, and an action lane"
---

```ts title="Import"
import { Row } from "@nyte-ai/ui/row";
```

## Usage

- The row inherits its typography.
- Clicking anywhere on the painted row activates `Row.Primary`, including padding and sibling
  `Row.Meta`. Child controls keep their own actions. Text selection and Shift-click do not activate
  the row.
- Omit `Row.Body` when there is no `Row.Description`.

## Anatomy

```tsx
<Row>
  <Row.Backdrop />
  <Row.Primary>
    <Row.Leading />
    <Row.Body>
      <Row.Label />
      <Row.Description />
    </Row.Body>
    <Row.Meta />
  </Row.Primary>
  <Row.Actions />
</Row>
```

## Props

### Row

Renders a `<div>`, or a `<button>` with `variant="nav"`, and takes that element's props plus:

| Prop                           | Type                                                   | Default  | Description                                            |
| ------------------------------ | ------------------------------------------------------ | -------- | ------------------------------------------------------ |
| `variant`                      | `"list" \| "nav"`                                      | `"list"` | `nav` is itself the button and takes no `Row.Primary`. |
| `size`                         | `"md" \| "lg"`                                         | `"md"`   | 28px or 32px, 44px on a coarse pointer.                |
| `interactive`                  | `boolean`                                              | `false`  | Paints hover, focus, and selected states.              |
| `selected`                     | `boolean`                                              | `false`  | Sets `data-selected`.                                  |
| `revealActions`                | `boolean`                                              | `false`  | Hides actions until hover or focus.                    |
| `render`                       | `ReactElement \| ((props: HTMLProps) => ReactElement)` |          |                                                        |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming)              |          |                                                        |

`RowSize` and `RowVariant` are the exported types for `size` and `variant`.

### Row.Primary

`type="button"` applies unless `render` replaces the element.

### Row.Actions

| Prop        | Type                    | Default    | Description                                               |
| ----------- | ----------------------- | ---------- | --------------------------------------------------------- |
| `placement` | `"inline" \| "overlay"` | `"inline"` | Takes space in the row, or floats over its trailing edge. |

`RowActionsPlacement` is the exported type for `placement`.

### Parts

Every part takes `render`, `className`, `style`, `xstyle`, and the props of the element it renders.

| Part              | Renders    | Data slot         | Description                         |
| ----------------- | ---------- | ----------------- | ----------------------------------- |
| `Row.Backdrop`    | `<span>`   | `row-backdrop`    | Selection layer behind the content. |
| `Row.Primary`     | `<button>` | `row-primary`     | Primary action for the painted row. |
| `Row.Leading`     | `<span>`   | `row-leading`     | Fixed-width lane.                   |
| `Row.Body`        | `<span>`   | `row-body`        | Label and description stack.        |
| `Row.Label`       | `<span>`   | `row-label`       | Ellipsized title.                   |
| `Row.Description` | `<span>`   | `row-description` | Smaller, ellipsized second line.    |
| `Row.Meta`        | `<span>`   | `row-meta`        | Trailing text with tabular figures. |
| `Row.Actions`     | `<span>`   | `row-actions`     | Action lane next to `Row.Primary`.  |

### Row state and layout

| Variable                | Default                                        | Description                                                 |
| ----------------------- | ---------------------------------------------- | ----------------------------------------------------------- |
| `--_row-padding-inline` | `row.paddingInlineMd` or `row.paddingInlineLg` | Inline padding and overlay action inset.                    |
| `--_row-fill`           | `transparent`                                  | Background. Leave `interactive` off when owning its states. |
| `--_row-meta-color`     | `role.contentSecondary`                        | Metadata color.                                             |
| `--_row-leading-color`  | `role.contentSecondary`                        | Leading lane color.                                         |

`revealActions` sets `--_row-actions-display` to `none` when hidden and `inline-flex` when
visible, and `--_row-actions-opacity` to `0` or `1`. Both are visible without hover support.

## Accessibility

- A `list` row is a `<div>` with no role.
- `Row.Primary` draws the focus ring on keyboard focus.
- `Row.Backdrop` is `aria-hidden`.
- `selected` adds no ARIA. Add `aria-current` or `aria-selected` on `Row.Primary`.
- An icon-only button inside `Row.Actions` needs `aria-label`. `revealActions` hides the lane with
  `display: none`, so hidden actions leave the tab order. Focus on the primary reveals them.
