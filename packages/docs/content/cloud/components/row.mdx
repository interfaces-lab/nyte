The same `Row` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Row } from "@nyte-ai/ui/row";
```

One row of a list. Reach for it when a list needs its items to align down a column and share one
hover, focus, and selection model.

## Usage

- The default row is 28px tall with a 6px gap, 6px inline padding, and a 15px leading lane. A list
  that measures differently sets `--nyte-row-height`, `--nyte-row-gap`, `--nyte-row-padding-inline`,
  and `--nyte-row-leading-size` on its container.
- `size="lg"` is the settings row, 44px tall with 12px of gap and padding, for a label with a
  description under it.
- Typography is inherited. The row sets no font family, size, or line height, so the surface owns
  them.
- `Row.Primary` renders a `<button type="button">` and is the click target. `Row.Actions` is its
  sibling, because a button cannot contain another.
- `interactive` paints the row's fill on hover, on focus within, and while `selected`. A surface
  that writes `--_row-fill` itself owns every state of it and leaves `interactive` off.
- `variant="nav"` makes the row itself the control, a `<button type="button">` that fills on hover
  and brightens its label, for a navigation list. It takes no `Row.Primary`.
- Omit `Row.Body` when there is only a label. Use it to stack a description under the label.

## Anatomy

```tsx
<Row>
  <Row.Backdrop />
  <Row.Primary>
    <Row.Leading />
    <Row.Body>
      <Row.Label />
      <Row.Description />
    </Row.Body>
    <Row.Meta />
  </Row.Primary>
  <Row.Actions />
</Row>
```

### A link or another trigger

`render` on `Row.Primary` swaps the button for another element or component. The row resets the
padding, border, background, and font that a `button` or an `a` brings.

```tsx
<Row interactive>
  <Row.Primary render={<a href={session.url} />}>
    <Row.Label>{session.title}</Row.Label>
  </Row.Primary>
</Row>
```

A row that opens a panel renders `Row.Primary` as a `Collapsible.Trigger` with `variant="plain"`.
See [Collapsible](/cloud/components/collapsible).

### Actions on hover

`revealActions` hides the action lane until the row is hovered or holds focus. It sets
`--_row-actions-opacity` and `--_row-actions-pointer-events`, which a surface reads to reclaim the
room in the same frame rather than repeating the conditions.

```tsx
<Row interactive revealActions>
  <Row.Primary onClick={open}>
    <Row.Label xstyle={styles.label}>{title}</Row.Label>
  </Row.Primary>
  <Row.Actions placement="overlay">
    <Button size="2xs" iconOnly icon="x" aria-label={`Stop ${title}`} onClick={stop} />
  </Row.Actions>
</Row>
```

```ts
const styles = stylex.create({
  label: { marginInlineEnd: "calc(var(--_row-actions-opacity, 0) * 44px)" },
});
```

`placement="overlay"` floats the lane over the row instead of taking space in it, so the whole row
stays clickable underneath. The surface reclaims the room itself.

### A selection layer the surface animates

`Row.Backdrop` sits behind the row's content at `z-index: -1`. The row declares `isolation: isolate`
so the backdrop lands behind the row rather than behind the list.

```tsx
<Row selected={selected}>
  <Row.Backdrop render={<motion.span layoutId="selection" />} xstyle={styles.selection} />
  <Row.Primary onClick={open}>
    <Row.Label>{title}</Row.Label>
  </Row.Primary>
</Row>
```

### Sizing from the list

```ts
const styles = stylex.create({
  list: {
    "--nyte-row-height": "24px",
    "--nyte-row-padding-inline": "4px",
    "--nyte-row-leading-size": "16px",
  },
});
```

## Props

### Row

Renders a `<div>`, or a `<button>` with `variant="nav"`. `RowProps` takes every prop of that
element, with `className` and `style` replaced by the styled versions, plus:

| Prop                           | Type                                                   | Default  | Description                                                                                       |
| ------------------------------ | ------------------------------------------------------ | -------- | ------------------------------------------------------------------------------------------------- |
| `variant`                      | `"list" \| "nav"`                                      | `"list"` | A row holding a `Row.Primary`, or a row that is itself the button.                                |
| `size`                         | `"md" \| "lg"`                                         | `"md"`   | Notion Calendar's row sizes: 28px, or 32px with room for a description.                           |
| `interactive`                  | `boolean`                                              | `false`  | Paints the row's own fill on hover and focus within, and the fill and hairline of a selected row. |
| `selected`                     | `boolean`                                              | `false`  | Marks the row current. Sets `data-selected`.                                                      |
| `revealActions`                | `boolean`                                              | `false`  | Hides the action lane until the row is hovered or holds focus.                                    |
| `render`                       | `ReactElement \| ((props: HTMLProps) => ReactElement)` |          | Replaces the element, or composes the row with another component.                                 |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming)              |          |                                                                                                   |

`RowSize` and `RowVariant` are the exported types for `size` and `variant`.

### Row.Primary

Renders a `<button type="button">` and takes every `<button>` prop, plus `render`, `className`,
`style`, and `xstyle`.

### Row.Actions

Renders a `<span>`.

| Prop        | Type                    | Default    | Description                                               |
| ----------- | ----------------------- | ---------- | --------------------------------------------------------- |
| `placement` | `"inline" \| "overlay"` | `"inline"` | Takes space in the row, or floats over its trailing edge. |

`RowActionsPlacement` is the exported type for `placement`.

### Parts

Every part takes `render`, `className`, `style`, `xstyle`, and the props of the element it renders.

| Part              | Renders    | Data slot         | Description                                                                  |
| ----------------- | ---------- | ----------------- | ---------------------------------------------------------------------------- |
| `Row.Backdrop`    | `<span>`   | `row-backdrop`    | Sits behind the row's content, for a selection layer the surface animates.   |
| `Row.Primary`     | `<button>` | `row-primary`     | The click target, wrapping whichever parts should be clickable.              |
| `Row.Leading`     | `<span>`   | `row-leading`     | A fixed lane, so labels align down the list whatever glyph each row carries. |
| `Row.Body`        | `<span>`   | `row-body`        | Stacks its children, so a label can carry a description under it.            |
| `Row.Label`       | `<span>`   | `row-label`       | The row's title. Truncates with an ellipsis.                                 |
| `Row.Description` | `<span>`   | `row-description` | A second line under the label, one step smaller. Truncates with an ellipsis. |
| `Row.Meta`        | `<span>`   | `row-meta`        | Trailing text such as a time or a count. Tabular figures, one step smaller.  |
| `Row.Actions`     | `<span>`   | `row-actions`     | Actions, a switch, or a chevron. A sibling of the primary, never a child.    |

### CSS variables

The surface sets these. The row reads them.

| Variable                    | Default                        | Description                                                              |
| --------------------------- | ------------------------------ | ------------------------------------------------------------------------ |
| `--nyte-row-height`         | `--nyte-row-height-md`         | Minimum height of the row.                                               |
| `--nyte-row-gap`            | `--nyte-row-gap`               | Gap between the row's parts.                                             |
| `--nyte-row-padding-inline` | `--nyte-row-padding-inline-md` | Inline padding, and the overlay inset.                                   |
| `--nyte-row-leading-size`   | `--nyte-glyph-box`, 15px       | Width of the leading lane.                                               |
| `--_row-fill`               | `transparent`                  | Background of the row. `interactive` sets it, so leave it off to own it. |
| `--_row-meta-color`         | `--nyte-content-secondary`     | Color of `Row.Meta`.                                                     |

`revealActions` sets the two below on the row, and `Row.Actions` reads them. A surface reads them
too, to move with the lane.

| Variable                        | Hidden | Hovered or focused within |
| ------------------------------- | ------ | ------------------------- |
| `--_row-actions-opacity`        | `0`    | `1`                       |
| `--_row-actions-pointer-events` | `none` | `auto`                    |

See [Tokens](/cloud/foundations/tokens) for the variables these fall back to.

## Accessibility

- The row is a `<div>` with no role. Meaning comes from what you render inside it.
- `Row.Primary` draws the focus ring on keyboard focus, inset by 1px because a row sits flush in a
  scroll container where an outset ring would clip. See [Focus](/cloud/foundations/focus).
- `Row.Backdrop` is `aria-hidden`. No other part is.
- `selected` sets `data-selected` and nothing else. Add `aria-current` or `aria-selected` on
  `Row.Primary`.
- An icon-only button inside `Row.Actions` needs `aria-label`. `revealActions` hides the lane with
  opacity, so it stays in the tab order, and focus anywhere in the row brings it back.
