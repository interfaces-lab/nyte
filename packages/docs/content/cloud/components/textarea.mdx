```ts title="Import"
import { Textarea } from "@nyte-ai/ui/textarea";
```

A native `<textarea>` in the frame of [Input](/cloud/components/input).

## Usage

- It resizes vertically. `resize: "none"` in `xstyle` turns that off.

## Examples

<Preview>
  <TextareaDemo />
</Preview>

```tsx
<Textarea placeholder="System prompt" aria-label="System prompt" />
```

## Props

`TextareaProps` takes every `<textarea>` prop plus:

| Prop                           | Type                                      | Default    | Description |
| ------------------------------ | ----------------------------------------- | ---------- | ----------- |
| `variant`                      | `"raised" \| "quiet"`                     | `"raised"` |             |
| `size`                         | `"md" \| "lg" \| "xl"`                    | `"md"`     |             |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming) |            |             |

## Accessibility

Focus recolors the border. `aria-invalid` turns it red.
