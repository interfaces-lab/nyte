The same `Textarea` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Textarea } from "@nyte-ai/ui/textarea";
```

A native `<textarea>` in the frame of [Input](/cloud/components/input).

## Usage

- Same naming rule as Input. Use a label, `aria-label`, or `aria-labelledby`.
- `variant` and `size` match Input's framed variants. There is no `bare` textarea.
- It starts 64px tall and resizes vertically. To stop it growing, set `resize: "none"` through
  `xstyle`.

## Props

`TextareaProps` takes every `<textarea>` prop, with `className` and `style` replaced by the styled
versions, plus:

| Prop                           | Type                                      | Default     | Description |
| ------------------------------ | ----------------------------------------- | ----------- | ----------- |
| `variant`                      | `"raised" \| "quiet"`                     | `"raised"`  | The frame.  |
| `size`                         | `"sm" \| "default" \| "lg"`               | `"default"` | Type size.  |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming) |             |             |

## Accessibility

Native. `aria-invalid` turns the border red. The border changes color on focus.
