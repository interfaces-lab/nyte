```ts title="Import"
import { Toaster, toast, toastTint } from "@nyte-ai/ui";
```

The same names are exported from their own subpath. Pick one path per file.

```ts title="Subpath"
import { Toaster, toast, toastTint } from "@nyte-ai/ui/toast";
```

`Toaster` renders the notification stack, and `toast` opens a notification in it. Reach for it
when a background task finishes or fails, such as a folder that could not open. A form's own error
stays in the form. The lifecycle comes from [sonner](https://sonner.emilkowal.ski), so the `toast`
API is sonner's.

## Usage

- Mount one `Toaster` near the app root. It stacks toasts in the bottom-right corner, 16px from
  the edges, expanded, each with a close button.
- Call `toast` from anywhere, including outside React. It is a plain function, not a hook.
- `toast.success` shows a checkmark, `toast.error` and `toast.warning` show a warning triangle,
  each tinted to match.
- The look is fixed. `Toaster` takes no `icons` or `toastOptions`. `xstyle`, `className`, and
  `style` land on the toast list.
- `tint` scopes the stack to a hue. Use `toastTint("green")` in an individual toast
  call to scope only that notification.
- Give a repeated notification a stable `id` so a second call updates the open toast instead of
  stacking another one.
- Every call that opens a toast returns its id. Pass it to `toast.dismiss` to close that one, or
  call `toast.dismiss()` with no argument to close all of them.
- The list attaches the ref from [Overlays](/cloud/foundations/overlays) while a toast is open, so
  a host can keep it above native views.

```tsx
<Button variant="outline" onClick={() => toast("Workspace saved")}>
  Default

  }

  variant="outline"

    toast.error("Could not reach the server", {
      description: "The request timed out after 30 seconds.",
    })
  }
>
  Error
</Button>
<Toaster />
```

### A toast that stays

A failure the user has to read stays until dismissed. The `id` makes a retry replace it.

```ts
toast.error("Couldn't open folder", {
  id: "workspace-open",
  duration: Infinity,
  description: reason,
});
```

### An action, and undo

```ts
toast.success("3 chats archived", {
  id: "archive",
  action: { label: "Undo", onClick: () => restore() },
  onAutoClose: () => commit(),
});
```

`action` and `cancel` take `{ label, onClick }` or a React node when you want to render the button
yourself.

### A pending operation

```ts
toast.promise(save(), {
  loading: "Saving",
  success: "Saved",
  error: (err) => err.message,
});
```

## Props

### Toaster

The close button is always shown unless an individual toast suppresses it. Its target is at least
24×24px on a fine pointer and 44×44px on a coarse pointer. Actions also grow on coarse pointers.

```tsx
<Toaster tint="gray" />
```

```ts
toast("Workspace saved", toastTint("green"));
```

| Prop                 | Type                                         | Default              | Description                                                           |
| -------------------- | -------------------------------------------- | -------------------- | --------------------------------------------------------------------- |
| `position`           | `Position`                                   | `"bottom-right"`     | Corner the stack grows from.                                          |
| `offset`             | `Offset`                                     | `16`                 | Distance from the viewport edge.                                      |
| `mobileOffset`       | `Offset`                                     | `16`                 | Same, at small viewports.                                             |
| `gap`                | `number`                                     | `8`                  | Space between stacked toasts.                                         |
| `expand`             | `boolean`                                    | `true`               | Shows the stack expanded instead of collapsed.                        |
| `tint`               | `Tint`                                       |                      | Scopes the stack to a hue.                                            |
| `containerAriaLabel` | `string`                                     | `"Notifications"`    | Names the list. Sonner appends the hotkey.                            |
| `theme`              | `"light" \| "dark" \| "system"`              | `"light"`            | Color scheme sonner marks the list with.                              |
| `visibleToasts`      | `number`                                     | `3`                  | How many toasts render at once.                                       |
| `duration`           | `number`                                     | `4000`               | Default milliseconds for every toast.                                 |
| `hotkey`             | `string[]`                                   | `["altKey", "KeyT"]` | Keys that expand the stack and move focus to it.                      |
| `swipeDirections`    | `("top" \| "right" \| "bottom" \| "left")[]` |                      | Directions a toast can be swiped away.                                |
| `dir`                | `"rtl" \| "ltr" \| "auto"`                   | document direction   | Text direction.                                                       |
| `customAriaLabel`    | `string`                                     |                      | Replaces the whole list name, hotkey included.                        |
| `id`                 | `string`                                     |                      | Names this toaster, for `toasterId` on a toast.                       |
| `xstyle`             | `XStyle`                                     |                      | Merged last onto the list. See [Theming](/cloud/foundations/theming). |
| `className`          | `string`                                     |                      | See [Theming](/cloud/foundations/theming).                            |
| `style`              | `React.CSSProperties`                        |                      | See [Theming](/cloud/foundations/theming).                            |

### toast

| Call                            | Returns                        | Description                                              |
| ------------------------------- | ------------------------------ | -------------------------------------------------------- |
| `toast(message, data?)`         | `string \| number`             | A default toast.                                         |
| `toast.message(message, data?)` | `string \| number`             | Same as calling `toast` directly.                        |
| `toast.success(message, data?)` | `string \| number`             | Success variant.                                         |
| `toast.info(message, data?)`    | `string \| number`             | Info variant.                                            |
| `toast.warning(message, data?)` | `string \| number`             | Warning variant.                                         |
| `toast.error(message, data?)`   | `string \| number`             | Error variant.                                           |
| `toast.loading(message, data?)` | `string \| number`             | Loading variant. Never auto-closes.                      |
| `toast.custom(jsx, data?)`      | `string \| number`             | Renders your own element. `jsx` receives the toast id.   |
| `toast.promise(promise, data)`  | id with `unwrap()`             | Swaps through loading, success, and error.               |
| `toast.dismiss(id?)`            | `string \| number`             | Closes one toast, or all of them with no argument.       |
| `toast.getToasts()`             | `(ToastT \| ToastToDismiss)[]` | The toasts that are open now.                            |
| `toast.getHistory()`            | `(ToastT \| ToastToDismiss)[]` | Open and dismissed toasts. Dismissed ones drop past 100. |

`message` is a React node or a function returning one. `data` is `ExternalToast`.

### ExternalToast

| Prop          | Type                                                        | Description                                                       |
| ------------- | ----------------------------------------------------------- | ----------------------------------------------------------------- |
| `id`          | `number \| string`                                          | Stable identity. A second call with the same id updates in place. |
| `description` | `React.ReactNode \| (() => React.ReactNode)`                | Second line under the title.                                      |
| `duration`    | `number`                                                    | Milliseconds before it closes on its own.                         |
| `icon`        | `React.ReactNode`                                           | Overrides the variant icon for this toast.                        |
| `action`      | `{ label, onClick, actionButtonStyle? } \| React.ReactNode` | Trailing button.                                                  |
| `cancel`      | `{ label, onClick, actionButtonStyle? } \| React.ReactNode` | Dismiss button beside the action.                                 |
| `dismissible` | `boolean`                                                   | Whether the user can swipe it away. Defaults to `true`.           |
| `closeButton` | `boolean`                                                   | Shows or hides the close button for this toast.                   |
| `onDismiss`   | `(toast: ToastT) => void`                                   | Fires when the user closes it.                                    |
| `onAutoClose` | `(toast: ToastT) => void`                                   | Fires when the duration runs out.                                 |
| `position`    | `Position`                                                  | Overrides the toaster position for this toast.                    |
| `toasterId`   | `string`                                                    | Routes the toast to a specific `Toaster`.                         |
| `testId`      | `string`                                                    | Sets `data-testid` on the toast element.                          |

### Shapes

The package exports the types `ToasterProps` and `ExternalToast`. The names below appear in those
types and are not exported.

| Name             | Shape                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| `Position`       | `"top-left" \| "top-right" \| "bottom-left" \| "bottom-right" \| "top-center" \| "bottom-center"` |
| `Offset`         | `number \| string \| { top?, right?, bottom?, left? }`                                            |
| `ToastT`         | The open toast, with its `id`, `title`, `type`, and the options it was given                      |
| `ToastToDismiss` | `{ id, dismiss }`                                                                                 |

## Accessibility

- The toaster renders a region with `aria-live="polite"`. A new toast is announced without moving
  focus.
- The region's accessible name is `containerAriaLabel` plus the hotkey, so a screen reader user
  hears how to reach the stack. `customAriaLabel` replaces that whole name.
- The hotkey expands the stack and moves focus to the list. Escape collapses it again while focus
  is still inside.
- Every close button is named "Dismiss notification". The action, cancel, and close buttons show a
  focus ring on keyboard focus.
- A loading toast carries no close button and no timer. Replace it or dismiss it by id.
- A toast is not a dialog. Do not put the only path to an action in one, since it closes on a timer.
