```ts title="Import"
import { Toaster, toast, toastTint } from "@nyte-ai/ui/toast";
```

`Toaster` renders the stack and `toast` opens a notification in it. Keep form errors in the form.

## Usage

- Mount one `Toaster` near the app root.
- Call `toast` anywhere, including outside React.
- `toastTint("green")` returns options that tint one toast. Spread it to add other options.

## Examples

<Preview>
  <ToastDemo />
</Preview>

```tsx
<Button variant="outline" onClick={() => toast("Workspace saved")}>
  Default
</Button>
<Button
  variant="outline"
  onClick={() =>
    toast.success("3 chats archived", {
      action: { label: "Undo", onClick: () => toast("Chats restored") },
    })
  }
>
  Success
</Button>
<Button
  variant="outline"
  onClick={() =>
    toast.error("Could not reach the server", {
      description: "The request timed out after 30 seconds.",
    })
  }
>
  Error
</Button>
<Toaster />
```

### A toast that stays

```ts
toast.error("Couldn't open folder", {
  id: "workspace-open",
  duration: Infinity,
  description: reason,
});
```

### An action, and undo

```ts
toast.success("3 chats archived", {
  id: "archive",
  action: { label: "Undo", onClick: () => restore() },
  onAutoClose: () => commit(),
});
```

### A pending operation

```ts
toast.promise(save(), {
  loading: "Saving",
  success: "Saved",
  error: (err) => err.message,
});
```

## Props

### Toaster

| Prop                 | Type                                         | Default              | Description                                             |
| -------------------- | -------------------------------------------- | -------------------- | ------------------------------------------------------- |
| `position`           | `Position`                                   | `"bottom-right"`     | Stack corner.                                           |
| `offset`             | `Offset`                                     | `16`                 | Viewport inset.                                         |
| `mobileOffset`       | `Offset`                                     | `16`                 | Small-viewport inset.                                   |
| `gap`                | `number`                                     | `8`                  |                                                         |
| `expand`             | `boolean`                                    | `true`               | Keeps the stack expanded.                               |
| `tint`               | `Tint`                                       |                      | Stack hue.                                              |
| `containerAriaLabel` | `string`                                     | `"Notifications"`    |                                                         |
| `theme`              | `"light" \| "dark" \| "system"`              | `"light"`            | List color scheme.                                      |
| `visibleToasts`      | `number`                                     | `3`                  | Rendered toast limit.                                   |
| `duration`           | `number`                                     | `4000`               | Default milliseconds.                                   |
| `hotkey`             | `string[]`                                   | `["altKey", "KeyT"]` | Expands and focuses the stack.                          |
| `swipeDirections`    | `("top" \| "right" \| "bottom" \| "left")[]` |                      | Allowed dismiss directions.                             |
| `dir`                | `"rtl" \| "ltr" \| "auto"`                   | document direction   |                                                         |
| `customAriaLabel`    | `string`                                     |                      |                                                         |
| `id`                 | `string`                                     |                      | Matches a toast's `toasterId`.                          |
| `xstyle`             | `XStyle`                                     |                      | List styles. See [Theming](/cloud/foundations/theming). |
| `className`          | `string`                                     |                      | See [Theming](/cloud/foundations/theming).              |
| `style`              | `React.CSSProperties`                        |                      | See [Theming](/cloud/foundations/theming).              |

### toast

| Call                            | Returns                        | Description                                              |
| ------------------------------- | ------------------------------ | -------------------------------------------------------- |
| `toast(message, data?)`         | `string \| number`             |                                                          |
| `toast.message(message, data?)` | `string \| number`             | Same as `toast`.                                         |
| `toast.success(message, data?)` | `string \| number`             |                                                          |
| `toast.info(message, data?)`    | `string \| number`             |                                                          |
| `toast.warning(message, data?)` | `string \| number`             |                                                          |
| `toast.error(message, data?)`   | `string \| number`             |                                                          |
| `toast.loading(message, data?)` | `string \| number`             |                                                          |
| `toast.custom(jsx, data?)`      | `string \| number`             | `jsx` takes the id and returns your element.             |
| `toast.promise(promise, data)`  | id with `unwrap()`             | Swaps through loading, success, and error.               |
| `toast.dismiss(id?)`            | `string \| number`             | Closes one toast, or all of them with no argument.       |
| `toast.getToasts()`             | `(ToastT \| ToastToDismiss)[]` | Open toasts.                                             |
| `toast.getHistory()`            | `(ToastT \| ToastToDismiss)[]` | Open and dismissed toasts. Dismissed ones drop past 100. |

`message` is a React node or a function returning one. `data` is `ExternalToast`.

### ExternalToast

| Prop          | Type                                                        | Description                           |
| ------------- | ----------------------------------------------------------- | ------------------------------------- |
| `id`          | `number \| string`                                          | A repeated id updates the open toast. |
| `description` | `React.ReactNode \| (() => React.ReactNode)`                | Second line.                          |
| `duration`    | `number`                                                    | Auto-close milliseconds.              |
| `icon`        | `React.ReactNode`                                           | Overrides the variant icon.           |
| `action`      | `{ label, onClick, actionButtonStyle? } \| React.ReactNode` | Trailing button.                      |
| `cancel`      | `{ label, onClick, actionButtonStyle? } \| React.ReactNode` | Dismiss button beside the action.     |
| `dismissible` | `boolean`                                                   | Swipe dismissal. Defaults to `true`.  |
| `closeButton` | `boolean`                                                   |                                       |
| `onDismiss`   | `(toast: ToastT) => void`                                   | User-close callback.                  |
| `onAutoClose` | `(toast: ToastT) => void`                                   | Timer callback.                       |
| `position`    | `Position`                                                  |                                       |
| `toasterId`   | `string`                                                    | Target `Toaster` id.                  |
| `testId`      | `string`                                                    | Sets `data-testid`.                   |

### Shapes

Only `ToasterProps` and `ExternalToast` are exported.

| Name             | Shape                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| `Position`       | `"top-left" \| "top-right" \| "bottom-left" \| "bottom-right" \| "top-center" \| "bottom-center"` |
| `Offset`         | `number \| string \| { top?, right?, bottom?, left? }`                                            |
| `ToastT`         | The open toast, with its `id`, `title`, `type`, and the options it was given                      |
| `ToastToDismiss` | `{ id, dismiss }`                                                                                 |

## Accessibility

- The toaster renders a region with `aria-live="polite"`. A new toast is announced without moving
  focus.
- The region's name is `containerAriaLabel` plus the hotkey. `customAriaLabel` replaces the whole
  name.
- Escape collapses the stack while focus is inside it.
- Every close button is named "Dismiss notification".
- A loading toast has no close button and no timer. Replace it or dismiss it by id.
- A toast closes on a timer, so its action needs another path in the app.
