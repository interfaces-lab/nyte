```ts title="Import"
import { Switch } from "@nyte-ai/ui/switch";
```

Use it for a setting that applies on change.

## Usage

- Pass `label` even when the same text sits beside the switch. It becomes the `aria-label`.

## Examples

<Preview>
  <SwitchDemo />
</Preview>

```tsx
const [wrap, setWrap] = useState(true);

<Switch label="Code block word wrap" checked={wrap} onCheckedChange={setWrap} />
<Switch label="Reduce transparency" disabled />
```

## Props

Takes every Base UI `Switch.Root` prop except `render` and `children`. The thumb is built in.

| Prop                           | Type                                      | Default | Description |
| ------------------------------ | ----------------------------------------- | ------- | ----------- |
| `label`                        | `string`                                  |         | Required.   |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming) |         |             |

## Accessibility

- The root carries `role="switch"` and `aria-checked`. Space and Enter toggle it.
- `readOnly` keeps the switch focusable but blocks changes.
- Keyboard focus shows the [focus ring](/cloud/foundations/focus).
