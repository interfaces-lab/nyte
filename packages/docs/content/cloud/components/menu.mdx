```ts title="Import"
import { Menu, MenuContent, MenuItem, MenuSeparator, MenuTrigger } from "@nyte-ai/ui/menu";
```

A list of actions that opens from a button. Every row reserves a leading icon column and a trailing
meta column, even when empty.

## Usage

- `MenuItem` and `MenuRadioItem` close on click. `MenuCheckboxItem` and `MenuSwitchItem` stay open.
  `closeOnClick` changes either.
- Use `CommandMenuContent` for a palette under a scrim, anchored near the top of the window. It has
  no trigger to name it, so pass `aria-label`.

## Anatomy

```tsx
<Menu>
  <MenuTrigger />
  <MenuContent>
    <MenuGroup>
      <MenuGroupLabel />
      <MenuItem />
      <MenuLinkItem />
      <MenuCheckboxItem />
      <MenuSwitchItem checked={false} />
    </MenuGroup>
    <MenuSeparator />
    <MenuRadioGroup>
      <MenuRadioItem value="choice" />
    </MenuRadioGroup>
    <MenuSub>
      <MenuSubTrigger />
      <MenuSubContent>
        <MenuItem />
      </MenuSubContent>
    </MenuSub>
  </MenuContent>
</Menu>
```

```tsx
import { Button } from "@nyte-ai/ui/button";
import {
  Menu,
  MenuContent,
  MenuGroup,
  MenuGroupLabel,
  MenuItem,
  MenuRadioGroup,
  MenuRadioItem,
  MenuSeparator,
  MenuSub,
  MenuSubContent,
  MenuSubTrigger,
  MenuSwitchItem,
  MenuTrigger,
} from "@nyte-ai/ui/menu";
import { useState } from "react";

function SessionMenu() {
  const [effort, setEffort] = useState("medium");
  const [pinned, setPinned] = useState(false);

  return (
    <Menu>
      <MenuTrigger render={<Button variant="outline">Session</Button>} />
      <MenuContent>
        <MenuGroup>
          <MenuGroupLabel>Session</MenuGroupLabel>
          <MenuItem icon="pencil" meta="⌘R" onClick={() => {}}>
            Rename
          </MenuItem>
          <MenuItem icon="copy" onClick={() => {}}>
            Duplicate
          </MenuItem>
          <MenuItem icon="archive" disabled disabledReason="Already archived">
            Archive
          </MenuItem>
          <MenuSwitchItem icon="pin" checked={pinned} onCheckedChange={setPinned}>
            Pinned
          </MenuSwitchItem>
        </MenuGroup>
        <MenuSeparator />
        <MenuSub>
          <MenuSubTrigger icon="bolt" value={effort}>
            Effort
          </MenuSubTrigger>
          <MenuSubContent>
            <MenuRadioGroup value={effort} onValueChange={setEffort}>
              <MenuRadioItem value="low">low</MenuRadioItem>
              <MenuRadioItem value="medium">medium</MenuRadioItem>
              <MenuRadioItem value="high">high</MenuRadioItem>
            </MenuRadioGroup>
          </MenuSubContent>
        </MenuSub>
        <MenuSeparator />
        <MenuItem icon="trash" variant="danger" onClick={() => {}}>
          Delete
        </MenuItem>
      </MenuContent>
    </Menu>
  );
}
```

```tsx
<Menu open={open} onOpenChange={setOpen}>

      Settings
    </MenuItem>
  </CommandMenuContent>

```

### MenuContent

Renders the portal, positioner, and popup. Positioning props go to the positioner and the rest,
including `ref`, to the popup.

| Prop                 | Type                                                                       | Default                                                      |
| -------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `side`               | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"`                                                   |
| `align`              | `"start" \| "center" \| "end"`                                             | `"start"`                                                    |
| `sideOffset`         | `number \| OffsetFunction`                                                 | `4`                                                          |
| `alignOffset`        | `number \| OffsetFunction`                                                 |                                                              |
| `anchor`             | `MenuContentProps["anchor"]`                                               | the trigger                                                  |
| `collisionAvoidance` | `CollisionAvoidance`                                                       | `{ side: "flip", align: "shift", fallbackAxisSide: "none" }` |
| `collisionPadding`   | `number \| Padding`                                                        | `8`                                                          |
| `tint`               | `Tint`                                                                     |                                                              |
| `matchAnchorWidth`   | `boolean`                                                                  | `false`                                                      |

The popup scrolls when it runs out of room.

## Accessibility

- The popup has `role="menu"`. Give it `aria-label` when the trigger's text does not name it.
- Items are `menuitem`, radio items are `menuitemradio`, and checkbox and switch items are
  `menuitemcheckbox` with `aria-checked`.
- Arrow Down and Up move focus and wrap. Home and End jump. Typing matches item text, or `label`
  when set. Enter and Space activate. Escape closes and returns focus to the trigger.
- Arrow Right opens a submenu. Arrow Left closes it.
- Disabled items stay reachable with the arrow keys and do not activate.
- Icons, switches, and checkmarks are hidden from assistive technology, so the label must say what
  the row does.
