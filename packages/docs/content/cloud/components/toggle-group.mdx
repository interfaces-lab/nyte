The same `ToggleGroup` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { ToggleGroup } from "@nyte-ai/ui/toggle-group";
```

A track that holds the pressed state for a row of [Toggle](/cloud/components/toggle) buttons and
moves focus between them with the arrow keys. Reach for it to pick one option in place, like a
range.

## Usage

- Every child toggle needs a `value`. The group's `value` is the array of pressed ones.
- One item at a time by default. `multiple` lets several stay pressed.
- `value` with `onValueChange` controls the group. `defaultValue` leaves it uncontrolled.
- The group draws a track around its toggles. Size them `sm`, text or `iconOnly`, so the track stands 28px.
- `orientation="vertical"` stacks the toggles and switches arrow key navigation to the vertical
  axis.

## Anatomy

```tsx
import { Toggle } from "@nyte-ai/ui/toggle";
import { ToggleGroup } from "@nyte-ai/ui/toggle-group";

<ToggleGroup>
  <Toggle value="bold" />
  <Toggle value="italic" />
</ToggleGroup>;
```

### Multiple

`multiple` allows more than one toggle to be pressed at a time.

<Preview>
  <ToggleGroupMultipleDemo />
</Preview>

```tsx
<ToggleGroup multiple defaultValue={["sidebar"]} aria-label="Panels">
  <Toggle value="sidebar" size="sm" iconOnly icon="panel-left" aria-label="Sidebar" />
  <Toggle value="terminal" size="sm" iconOnly icon="console" aria-label="Terminal" />
  <Toggle value="inspector" size="sm" iconOnly icon="panel-right" aria-label="Inspector" />
</ToggleGroup>
```

### Controlled

The value is an array even when one item is pressed at a time.

```tsx
const [range, setRange] = useState(["week"]);

<ToggleGroup value={range} onValueChange={setRange} aria-label="Usage range">
  <Toggle value="day" size="sm">
    Day
  </Toggle>
  <Toggle value="week" size="sm">
    Week
  </Toggle>
  <Toggle value="month" size="sm">
    Month
  </Toggle>
</ToggleGroup>;
```

## Accessibility

- Renders `role="group"`. Label it with `aria-label` or `aria-labelledby`.
- Arrow keys move focus between the toggles. Focus wraps at the end unless you pass
  `loopFocus={false}`.
- `disabled` on the group disables every toggle in it and sets `data-disabled`.
- Each toggle keeps its own `aria-pressed`. See [Toggle](/cloud/components/toggle).
