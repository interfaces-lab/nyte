```ts title="Import"
import { Spinner } from "@nyte-ai/ui/spinner";
```

## Usage

- The spinner is 15px and takes the text color of its parent.
- Under reduced motion it holds one phase.

## Accessibility

- The spinner is `aria-hidden`. Announce the running state with nearby text or `aria-busy` on the
  region.
