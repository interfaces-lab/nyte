`@nyte-ai/ui` is one set of styled components, built on Base UI and StyleX with `--nyte-*` tokens.
The package root exports every component. Each subpath named for a component exports the same
component, so pick one path per file.

```ts
import "@nyte-ai/ui/ui.css";
import { Button } from "@nyte-ai/ui";
import { Popover } from "@nyte-ai/ui/popover";
```

Change a component's look through `xstyle`, `className`, or `style`, covered in
[Theming](/cloud/foundations/theming). Import from `@nyte-ai/ui` rather than from
`@base-ui/react`. When `render` produces something other than a `<button>`, pass
`nativeButton={false}` so Base UI keeps button semantics.
