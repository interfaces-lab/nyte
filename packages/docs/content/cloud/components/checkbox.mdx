The same `Checkbox` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Checkbox } from "@nyte-ai/ui/checkbox";
```

A 16px box, accent when ticked. Use it for a choice that is saved with a form or applies to a set
of items. For a setting that applies the moment it changes, use [Switch](/cloud/components/switch).

## Usage

- Name the box with a `<label>` around it, `aria-label`, or `aria-labelledby`.
- `checked` with `onCheckedChange` controls the box. `defaultChecked` leaves it uncontrolled.
- `indeterminate` draws a dash instead of the tick, for a box over a list that is partly ticked.
- `size="sm"` is 14px, for a box on a line of text.
- `disabled` dims the box to half opacity.

## Examples

```tsx
const [archived, setArchived] = useState(false);

<label>
  <Checkbox checked={archived} onCheckedChange={setArchived} />
  Show archived chats
</label>;
```

A box over a list, mixed while some items are ticked.

```tsx
const [viewed, setViewed] = useState<readonly string[]>(["row.tsx"]);

<>
  <label>
    <Checkbox
      checked={viewed.length === files.length}
      indeterminate={viewed.length > 0 && viewed.length < files.length}
      onCheckedChange={(checked) => setViewed(checked ? files : [])}
    />
    All files viewed
  </label>
  {files.map((file) => (
    <label key={file}>
      <Checkbox
        size="sm"
        checked={viewed.includes(file)}
        onCheckedChange={(checked) =>
          setViewed((current) =>
            checked ? [...current, file] : current.filter((path) => path !== file),
          )
        }
      />
      {file}
    </label>
  ))}
</>;
```

## Props

Every Base UI `Checkbox.Root` prop passes through, except `render` and `children`. The indicator
is built in.

| Prop                           | Type                                      | Default     | Description    |
| ------------------------------ | ----------------------------------------- | ----------- | -------------- |
| `size`                         | `"default" \| "sm"`                       | `"default"` | 16px, or 14px. |
| `className`, `style`, `xstyle` | see [Theming](/cloud/foundations/theming) |             |                |

`CheckboxSize` is the exported type for `size`.

## Accessibility

- The root carries `role="checkbox"` and `aria-checked`, which is `"mixed"` while `indeterminate`.
  Space toggles it.
- A hidden `<input type="checkbox">` beside it takes part in form submission.
- The focus ring appears on keyboard focus. See [Focus](/cloud/foundations/focus).
