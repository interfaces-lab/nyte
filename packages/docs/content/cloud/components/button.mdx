```ts title="Import"
import { Button } from "@nyte-ai/ui";
```

The same `Button` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Button } from "@nyte-ai/ui/button";
```

A native `<button>` in Nyte styling. `primary` is a bare label or glyph that lifts on hover, and is
the one to reach for most. Use `secondary` for a framed action, `inverse` for the one action that
commits a form or a dialog, `danger` for an action that removes or discards, and `link` for an
action that sits inside running text.

## Usage

- `icon` takes an [Icon](/cloud/components/icon) name. With a text size it leads the label. With an
  icon size it is the whole content.
- An icon size requires `aria-label`, and the label doubles as the native `title`. Inside a
  [Tooltip](/cloud/components/tooltip) trigger, pass `title={undefined}` so only the tooltip shows.
- `xstyle` places the control and accepts position, inset, margin, flex, grid, order, and width
  properties. The look belongs to `variant` and `size`.
- `type` defaults to `"button"`. Say `type="submit"` when you mean it.
- A `primary` trigger takes the selected fill while its popup is open, through
  `aria-expanded="true"`.
- A `Button` can be the `render` element of any trigger or close part, such as
  `<Popover.Trigger render={<Button variant="secondary" />}>`.

## Props

Every native `<button>` attribute passes through, except `className` and `style`, which merge with
the component's own.

| Prop        | Type                                                                   | Default     | Description                                                               |
| ----------- | ---------------------------------------------------------------------- | ----------- | ------------------------------------------------------------------------- |
| `variant`   | `"primary" \| "secondary" \| "inverse" \| "danger" \| "link"`          | `"primary"` | Fill, frame, and ink.                                                     |
| `size`      | `"default" \| "condensed" \| "sm" \| "icon" \| "icon-sm" \| "icon-xs"` | `"default"` | 30, 28, or 24px tall with a label. 28, 24, or 16px square with a glyph.   |
| `icon`      | `IconName`                                                             |             | Leading glyph, drawn at 14px, 12px at `sm` and `icon-xs`, 16px at `icon`. |
| `round`     | `boolean`                                                              | `false`     | Fully rounded corners.                                                    |
| `xstyle`    | `ButtonLayout`                                                         |             | Placement only. Merged after the variant and size.                        |
| `className` | `string`                                                               |             | See [Theming](/cloud/foundations/theming).                                |
| `style`     | `React.CSSProperties`                                                  |             | See [Theming](/cloud/foundations/theming).                                |
| `type`      | `"button" \| "submit" \| "reset"`                                      | `"button"`  |                                                                           |

## Accessibility

- Renders a native `<button>`. Enter and Space activate it.
- `disabled` sets the native attribute. Most variants fade to half opacity, and `inverse` switches
  to a muted fill.
- The focus ring appears on keyboard focus. `icon-xs` draws it inset. See
  [Focus](/cloud/foundations/focus).
