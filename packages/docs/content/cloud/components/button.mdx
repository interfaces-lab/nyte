```ts title="Import"
import { Button, ButtonGroup, ButtonLink, SplitButton } from "@nyte-ai/ui";
```

The same names are exported from their own subpath. Pick one path per file.

```ts title="Subpath"
import { Button, ButtonGroup, ButtonLink, SplitButton } from "@nyte-ai/ui/button";
```

`Button` acts. `ButtonLink` navigates with a native `<a href>`. Use `ghost` for a quiet control,
`outline` for a framed action, `solid` for a filled action, `plain` for a context value, and
`text` for an action in running text. `tone` names its intent separately from its look.

## Usage

- `md` is the default size. Painted heights range from 16px to 36px and grow by 12px under a
  coarse pointer. Fine-pointer targets have an invisible 24px minimum.
- `icon` leads a visible label. An icon-only control declares `iconOnly` and `aria-label` at
  every size. A control with visible text omits `aria-label`.
- The icon-only label doubles as the native `title`. Inside a
  [Tooltip](/cloud/components/tooltip), pass `title={undefined}` to keep one tooltip on screen.
- Use `variant="solid" tone="primary"` for the committing action and
  `variant="solid" tone="danger"` for a destructive action.
- `loading` keeps the control mounted and focusable with `aria-busy`. It blocks activation
  without native disabling. Reserve `disabled` for an impossible action and give its reason
  with `disabledReason` or visible nearby text.
- `xstyle` places the control. The look belongs to `variant`, `tone`, and `size`.
- `type` defaults to `"button"`. Use `type="submit"` for a form submission.
- Popup triggers can use a `Button` as their `render` element. Put the visible text inside the
  button, such as `<Popover.Trigger render={<Button>Open</Button>} />`.
- `ButtonGroup` joins its controls with rounded outer corners and inset dividers. Give its
  parts the same size. `SplitButton.Root`, `.Main`, and `.MenuTrigger` describe an action
  beside a menu of alternatives. The menu trigger requires an action-and-target label.

## Props

### Button and ButtonLink

Native attributes pass through. `ButtonLink` requires `href` and does not take `disabled`,
`loading`, or `disabledReason`.

| Prop                 | Type                                                           | Default                                       | Description                                                |
| -------------------- | -------------------------------------------------------------- | --------------------------------------------- | ---------------------------------------------------------- |
| `variant`            | `"ghost" \| "outline" \| "solid" \| "plain" \| "text"`         | `"ghost"`                                     | Fill, frame, and ink.                                      |
| `tone`               | `"neutral" \| "primary" \| "success" \| "warning" \| "danger"` | `"primary"` for `text`, otherwise `"neutral"` | Color intent.                                              |
| `size`               | `"2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl"`                | `"md"`                                        | 16, 20, 24, 28, 32, or 36px tall.                          |
| `iconOnly`           | `boolean`                                                      | `false`                                       | Square control. Requires `aria-label`.                     |
| `icon`               | `IconName`                                                     |                                               | Leading or standalone glyph.                               |
| `children`           | `ReactNode`                                                    |                                               | Required for visible-text controls.                        |
| `round`              | `boolean`                                                      | `false`                                       | Fully rounded corners.                                     |
| `xstyle`             | `ButtonLayout`                                                 |                                               | Position, inset, margin, flex, grid, order, and width.     |
| `className`, `style` | See [Theming](/cloud/foundations/theming)                      |                                               | Merged with the component's styling.                       |
| `loading`            | `boolean`                                                      | `false`                                       | Button only. Busy, focusable, and blocked from activation. |
| `disabledReason`     | `string`                                                       |                                               | Button only. Shows and associates a disabled reason.       |
| `type`               | `"button" \| "submit" \| "reset"`                              | `"button"`                                    | Button only.                                               |
| `href`               | `string`                                                       | Required for ButtonLink                       | Navigation destination.                                    |

### ButtonGroup and SplitButton

`ButtonGroup` and `SplitButton.Root` render a `<div role="group">` and accept native `<div>`
attributes plus `xstyle`, `className`, and `style`. `SplitButton.Main` takes `ButtonProps`.
`SplitButton.MenuTrigger` takes button props except `children` and `iconOnly`. It requires
`aria-label`, defaults its glyph to `chevron-down`, and sets `aria-haspopup="menu"`.

The exported types include `ButtonProps`, `ButtonLinkProps`, `ButtonGroupProps`, `ButtonVariant`,
`ButtonTone`, `ButtonSize`, `ButtonLayout`, and `SplitButtonMenuTriggerProps`.

## Accessibility

- Enter and Space activate `Button`. Enter follows `ButtonLink`.
- `loading` preserves focus and the control's accessible name.
- `disabledReason` keeps a disabled button keyboard-reachable and associates the visible reason.
- The focus ring appears on keyboard focus. `2xs` draws it inset.
- Name a group with `aria-label` when its parts do not name it. Every part keeps its own tab stop.
