```ts title="Import"
import { Dialog } from "@nyte-ai/ui/dialog";
```

A cancellable modal that takes focus. For a required response, use
[Alert dialog](/cloud/components/alert-dialog).

## Usage

- Every dialog needs a `Dialog.Title` as its accessible name. To hide it, use `srOnly` from
  [Focus](/cloud/foundations/focus).

## Anatomy

```tsx
<Dialog.Root>
  <Dialog.Trigger />
  <Dialog.Popup>
    <Dialog.Header>
      <Dialog.Title />
      <Dialog.Description />
    </Dialog.Header>
    …
    <Dialog.Footer>
      <Dialog.Close />
    </Dialog.Footer>
  </Dialog.Popup>
</Dialog.Root>
```

## Props

| Part                 | Renders                        | Styling                      |
| -------------------- | ------------------------------ | ---------------------------- |
| `Dialog.Root`        | Nothing                        | None                         |
| `Dialog.Trigger`     | `<button>`                     | None                         |
| `Dialog.Popup`       | A portal, the scrim, a `<div>` | Bordered translucent panel   |
| `Dialog.Header`      | `<div>`                        | Stacks title and description |
| `Dialog.Title`       | `<h2>`                         | Large, semibold              |
| `Dialog.Description` | `<p>`                          | Body size, secondary text    |
| `Dialog.Footer`      | `<div>`                        | Right-aligns its buttons     |
| `Dialog.Close`       | `<button>`                     | None                         |

Except `Dialog.Root`, each part takes `xstyle`, `className`, and `style`. See
[Theming](/cloud/foundations/theming). `Dialog.Popup` takes the Base UI popup props except `ref` and
scrolls when its content is taller than the window.

## Accessibility

- The popup has `role="dialog"`, labelled by `Dialog.Title` and described by `Dialog.Description`.
- Focus moves into the popup on open and returns to the trigger on close. Tab cycles inside the
  popup.
- Escape closes. Outside press closes unless `disablePointerDismissal` is set on the root.
- While open, outside content is inert and page scroll is locked.
- `initialFocus` and `finalFocus` on the popup override where focus lands.
