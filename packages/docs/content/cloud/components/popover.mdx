```ts title="Import"
import { Popover } from "@nyte-ai/ui/popover";
```

An interactive panel anchored to its trigger.

## Usage

- With `modal` set to `true`, focus stays trapped only while a `Popover.Close` is inside
  `Popover.Popup`.

## Anatomy

```tsx
<Popover.Root>
  <Popover.Trigger />
  <Popover.Portal>
    <Popover.Backdrop />
    <Popover.Positioner>
      <Popover.Popup>
        <Popover.Arrow />
        <Popover.Viewport>
          <Popover.Title />
          <Popover.Description />
          <Popover.Close />
        </Popover.Viewport>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>
```

### Basic

```tsx
const styles = create({
  popup: { display: "flex", flexDirection: "column", gap: 2, width: 240 },
  actions: { display: "flex", justifyContent: "flex-end", marginBlockStart: 8 },
});

<Popover.Root>
  <Popover.Trigger render={<Button variant="outline">Notifications</Button>} />
  <Popover.Portal>
    <Popover.Positioner sideOffset={6}>
      <Popover.Popup xstyle={styles.popup}>
        <Popover.Title>Notifications</Popover.Title>
        <Popover.Description>You are all caught up.</Popover.Description>
        <div {...props(styles.actions)}>
          <Popover.Close
            render={
              <Button size="sm" variant="outline">
                Close
              </Button>
            }
          />
        </div>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>;
```

### Controlled with an anchor

```tsx
const [open, setOpen] = useState(false);
const anchor = useRef<HTMLDivElement>(null);

<Popover.Root open={open} onOpenChange={setOpen}>
  <Popover.Portal>
    <Popover.Positioner anchor={anchor} side="top" align="start" sideOffset={8}>
      <Popover.Popup>
        <Popover.Title>Suggestions</Popover.Title>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>;
```

### Detached triggers

```tsx
const details = Popover.createHandle<{ name: string }>();

<Popover.Trigger handle={details} payload={{ name: "Ada" }} render={<Button variant="outline">Ada</Button>} />
<Popover.Trigger handle={details} payload={{ name: "Linus" }} render={<Button variant="outline">Linus</Button>} />

<Popover.Root handle={details}>
  {({ payload }) => (
    <Popover.Portal>
      <Popover.Positioner>
        <Popover.Popup>
          <Popover.Title>{payload?.name}</Popover.Title>
        </Popover.Popup>
      </Popover.Positioner>
    </Popover.Portal>
  )}
</Popover.Root>;
```

## Accessibility

- `Popover.Title` renders an `<h2>` that labels the popup. `Popover.Description` renders a `<p>`
  that describes it.
- Escape, an outside press, and focus leaving the popup close it.
- On open, focus moves to the first tabbable element in the popup, or to the popup itself when
  opened by touch. On close, it returns to the trigger or the previously focused element.
  `initialFocus` and `finalFocus` on the popup override both.
- The popup appears without motion under `prefers-reduced-motion: reduce`.
