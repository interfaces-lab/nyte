```ts title="Import"
import { Popover } from "@nyte-ai/ui";
```

The same `Popover` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Popover } from "@nyte-ai/ui/popover";
```

A raised panel anchored to the element that opens it. Reach for it when the content is interactive
and belongs next to its trigger.

## Usage

- `Popover.Popup` paints the raised surface with 8px padding and fades in with a slight scale. Lay
  out its content with `xstyle`.
- `Popover.Title` and `Popover.Description` set the heading and body text, and name and describe the
  popup. Render them rather than writing your own ARIA.
- Render the trigger and close as buttons with `render={<Button />}`.
- `Popover.Positioner` defaults to `side="bottom"`, `align="center"`, `positionMethod="fixed"`, and
  `collisionPadding={8}`. Pass `sideOffset` for the gap between the anchor and the popup.
- `openOnHover` on the trigger opens the popup on hover after `delay`, which is 300ms. Set
  `closeDelay` to hold it open while the pointer travels.
- The popover is non-modal by default. With `modal={true}`, focus trapping turns on only when
  `Popover.Close` is rendered inside `Popover.Popup`.
- Pass `open` and `onOpenChange` on `Popover.Root` to drive it from your own state. With no trigger
  inside the root, point the positioner at an element with `anchor`.
- To open from a trigger outside the root, pass one handle from `Popover.createHandle()` to both the
  trigger and the root.
- The popup attaches the ref from [Overlays](/cloud/foundations/overlays), so a host can keep it
  above native views.

## Anatomy

```tsx
<Popover.Root>
  <Popover.Trigger />
  <Popover.Portal>
    <Popover.Backdrop />
    <Popover.Positioner>
      <Popover.Popup>
        <Popover.Arrow />
        <Popover.Viewport>
          <Popover.Title />
          <Popover.Description />
          <Popover.Close />
        </Popover.Viewport>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>
```

## Examples

### Basic

<Preview>
  <PopoverDemo />
</Preview>

```tsx
const styles = create({
  popup: { display: "flex", flexDirection: "column", gap: 2, width: 240 },
  actions: { display: "flex", justifyContent: "flex-end", marginBlockStart: 8 },
});

<Popover.Root>
  <Popover.Trigger render={<Button variant="outline">Notifications</Button>} />
  <Popover.Portal>
    <Popover.Positioner sideOffset={6}>
      <Popover.Popup xstyle={styles.popup}>
        <Popover.Title>Notifications</Popover.Title>
        <Popover.Description>You are all caught up.</Popover.Description>
        <div {...props(styles.actions)}>
          <Popover.Close
            render={
              <Button size="sm" variant="outline">
                Close
              </Button>
            }
          />
        </div>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>;
```

### Controlled with an anchor

A popup your own state opens, placed against an element outside the root.

```tsx
const [open, setOpen] = useState(false);
const anchor = useRef<HTMLDivElement>(null);

<Popover.Root open={open} onOpenChange={setOpen}>
  <Popover.Portal>
    <Popover.Positioner anchor={anchor} side="top" align="start" sideOffset={8}>
      <Popover.Popup>
        <Popover.Title>Suggestions</Popover.Title>
      </Popover.Popup>
    </Popover.Positioner>
  </Popover.Portal>
</Popover.Root>;
```

### Detached triggers

One popover driven by two triggers, each passing its own payload.

```tsx
const details = Popover.createHandle<{ name: string }>();

<Popover.Trigger handle={details} payload={{ name: "Ada" }} render={<Button  variant="outline">Ada</Button>} />
<Popover.Trigger handle={details} payload={{ name: "Linus" }} render={<Button  variant="outline">Linus</Button>} />

<Popover.Root handle={details}>
  {({ payload }) => (
    <Popover.Portal>
      <Popover.Positioner>
        <Popover.Popup>
          <Popover.Title>{payload?.name}</Popover.Title>
        </Popover.Popup>
      </Popover.Positioner>
    </Popover.Portal>
  )}
</Popover.Root>;
```

## Accessibility

- The trigger carries `data-popup-open` while the popup is open, and `data-pressed` while it is
  pressed.
- `Popover.Title` renders an `<h2>` that labels the popup. `Popover.Description` renders a `<p>`
  that describes it.
- Escape closes the popup. Outside press closes it. Focus leaving the popup closes it.
- Focus moves to the first tabbable element inside the popup on open, except when the popover was
  opened by touch, where the popup itself takes focus. `initialFocus` and `finalFocus` on the popup
  override this.
- On close, focus returns to the trigger or to the previously focused element.
- Render `Popover.Close` inside the popup when `modal` is `true` or `'trap-focus'` so touch screen
  reader users can leave it.
- The popup appears without motion under `prefers-reduced-motion: reduce`.
