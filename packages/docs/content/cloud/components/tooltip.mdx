`Hint` shows a short label beside a control on hover or keyboard focus. Reach for it to name an
icon-only control in a dense interface. `HoverPreview` is the same popup sized for a long block of
monospace text, such as a pasted snippet, and scrolls past its bounds.

## Usage

- `trigger` is the element that opens the hint. It receives the hover and focus handlers, so pass a
  real control. Do not repeat a visible label.
- Give the trigger an `aria-label` that matches `content`. The hint does not label the trigger. An
  icon-only [Button](/cloud/components/button) also sets its label as the native `title`, so pass
  `title={undefined}` to keep one tooltip on screen.
- Wrap the app in `HintProvider` to share one delay. Once one hint is visible, the next opens
  instantly, for `timeout` milliseconds after the last one closed.
- Touch and pen users can hold the trigger for 500ms to open it without activating the control.
  Keep essential instructions and disabled reasons visible or keyboard-reachable outside the hint.
- For feedback after an action, use [Toast](/cloud/components/toast).
- The popup attaches the ref from [Overlays](/cloud/foundations/overlays), so a host can keep it
  above native views.

```tsx
<Hint
  content="Copy output"
  trigger={<Button iconOnly icon="copy" aria-label="Copy output" title={undefined} />}
/>
<HoverPreview
  content={"const answer = 42;\nconsole.log(answer);"}
  trigger={<Button variant="outline">Snippet</Button>}
/>
```

Defaults are 300ms to open, 100ms to close, and a 200ms group window. Keyboard focus opens immediately.

```tsx
<HintProvider>
  <App />
</HintProvider>
```

## Props

### Hint

| Prop       | Type                                                                       | Default    | Description                                      |
| ---------- | -------------------------------------------------------------------------- | ---------- | ------------------------------------------------ |
| `content`  | `React.ReactNode`                                                          |            | The hint. Line breaks in a string are kept.      |
| `trigger`  | `React.ReactElement`                                                       |            | The element that opens it.                       |
| `side`     | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` | Side of the trigger to open on.                  |
| `align`    | `"start" \| "center" \| "end"`                                             | `"center"` | Alignment along that side.                       |
| `tint`     | `Tint`                                                                     |            | Scopes the popup to a hue.                       |
| `disabled` | `boolean`                                                                  | `false`    | Suppresses hover, focus, and long-press opening. |
| `xstyle`   | `XStyle`                                                                   |            | Merged last onto the popup.                      |

The popup sits 6px from the trigger and keeps 8px from the viewport edge.

### HoverPreview

Takes `content`, `trigger`, and `side` as `Hint` does.

### HintProvider

Our defaults replace Base UI's timing.

| Prop         | Default |
| ------------ | ------- |
| `delay`      | `300`   |
| `closeDelay` | `100`   |
| `timeout`    | `200`   |

## Accessibility

- The hint is a visual aid. Screen reader users get the trigger's `aria-label`, so write the two to
  match.
- It opens on hover, immediately on keyboard focus, or after a 500ms touch or pen hold.
- Escape closes it. Outside press and pressing the trigger close it.
- The popup can be hovered without closing.
