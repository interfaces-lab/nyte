```ts title="Import"
import { Collapsible } from "@nyte-ai/ui";
```

The same `Collapsible` is exported from its own subpath. Pick one path per file.

```ts title="Subpath"
import { Collapsible } from "@nyte-ai/ui/collapsible";
```

One trigger, one panel. Reach for it when a section of a surface is worth hiding until the reader
asks for it.

## Usage

- `defaultOpen` leaves the panel uncontrolled. `open` with `onOpenChange` controls it.
- The trigger's default `disclosure` look is a quiet inline toggle, tertiary text that brightens on
  hover. `variant="plain"` resets the button and adds nothing else, for a trigger rendered as another
  styled part such as `Row.Primary`.
- Put `Collapsible.Chevron` inside the trigger. It turns a quarter while the panel is open.
- `Collapsible.Root` and `Collapsible.Panel` bring no look of their own. Lay them out with `xstyle`.
- The closed panel unmounts unless you pass `keepMounted` or `hiddenUntilFound`.
- Animate the panel from `--collapsible-panel-height` and `--collapsible-panel-width`, which the
  panel publishes while it transitions.
- `disabled` on the root stops the trigger from opening the panel.

## Anatomy

```tsx
<Collapsible.Root>
  <Collapsible.Trigger>
    <Collapsible.Chevron />
  </Collapsible.Trigger>
  <Collapsible.Panel />
</Collapsible.Root>
```

### Controlled

```tsx
const [open, setOpen] = useState(false);

<Collapsible.Root open={open} onOpenChange={setOpen}>
  <Collapsible.Trigger>
    Earlier messages
    <Collapsible.Chevron />
  </Collapsible.Trigger>
  <Collapsible.Panel>{messages}</Collapsible.Panel>
</Collapsible.Root>;
```

### A row that opens a panel

`render` on `Row.Primary` makes the row the trigger. `variant="plain"` keeps the trigger from
restyling the row.

```tsx
<Collapsible.Root open={expanded} onOpenChange={setExpanded}>
  <Row>
    <Row.Primary render={<Collapsible.Trigger variant="plain" />}>
      <Row.Leading>
        <Icon name={expanded ? "folder-open" : "folder"} size={14} />
      </Row.Leading>
      <Row.Label>{name}</Row.Label>
    </Row.Primary>
  </Row>
  <Collapsible.Panel>{sessions}</Collapsible.Panel>
</Collapsible.Root>
```

### Hidden until found

`hiddenUntilFound` hides the closed panel with
[`hidden="until-found"`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/hidden),
so find-in-page can match its contents and open it. The panel stays in the DOM, which also makes it
indexable. Browsers without support for `hidden="until-found"` keep the panel hidden until the
trigger opens it, and find-in-page skips it.

```tsx
<Collapsible.Root>
  <Collapsible.Trigger>Environment variables</Collapsible.Trigger>
  <Collapsible.Panel hiddenUntilFound>NYTE_BIN_DIR, NYTE_INSTALL_DIR</Collapsible.Panel>
</Collapsible.Root>
```

## Props

Every part takes `xstyle`, and `className` and `style` as plain values, not functions of state.
See [Theming](/cloud/foundations/theming).

### Trigger

| Prop      | Type                      | Default        | Description                                      |
| --------- | ------------------------- | -------------- | ------------------------------------------------ |
| `variant` | `"disclosure" \| "plain"` | `"disclosure"` | The quiet inline toggle, or a bare button reset. |

`CollapsibleTriggerVariant` is the exported type for `variant`.

### Chevron

Renders a `<span>` with `aria-hidden`, holding a `chevron-right` [icon](/cloud/components/icon).
It takes every `<span>` prop, plus:

| Prop   | Type     | Default | Description                 |
| ------ | -------- | ------- | --------------------------- |
| `size` | `number` | `11`    | The icon's size, in pixels. |

## Accessibility

- The trigger renders a native `<button>` with `aria-expanded`, and `aria-controls` pointing at the
  panel while it is open. Enter and Space toggle it.
- Rendering the trigger as something other than a `<button>` needs `nativeButton={false}`.
- Open state lands on `data-panel-open` on the trigger, and `data-open` or `data-closed` on the root
  and the panel.
- The `disclosure` trigger draws the focus ring on keyboard focus. A `plain` trigger draws none, so
  the part it renders as owns it. See [Focus](/cloud/foundations/focus).
