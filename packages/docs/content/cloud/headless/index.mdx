title: Overview
description: "The eighteen Base UI namespaces @nyte-ai/ui re-exports without styling"
---

`@nyte-ai/ui/<name>` re-exports a Base UI namespace unstyled. Base UI owns the interaction model,
you own every class, StyleX style, and layout decision.

```ts
import { Popover } from "@nyte-ai/ui/popover";
```

## Rules

- Import from the subpath, never from `@base-ui/react` directly.
- When `render` produces something other than a `<button>`, pass `nativeButton={false}` so Base UI
  keeps button semantics.

## Subpaths

| Subpath         | Base UI      | Styled wrapper                                   |
| --------------- | ------------ | ------------------------------------------------ |
| `/alert-dialog` | AlertDialog  | [Alert dialog](/cloud/primitives/alert-dialog)   |
| `/autocomplete` | Autocomplete | none                                             |
| `/button`       | Button       | [Button](/cloud/primitives/button)               |
| `/collapsible`  | Collapsible  | none                                             |
| `/context-menu` | ContextMenu  | none                                             |
| `/dialog`       | Dialog       | [Dialog](/cloud/primitives/dialog)               |
| `/menu`         | Menu         | [Dropdown menu](/cloud/primitives/dropdown-menu) |
| `/number-field` | NumberField  | none                                             |
| `/popover`      | Popover      | none                                             |
| `/preview-card` | PreviewCard  | none                                             |
| `/select`       | Select       | none                                             |
| `/slider`       | Slider       | none                                             |
| `/switch`       | Switch       | none                                             |
| `/tabs`         | Tabs         | none                                             |
| `/toggle`       | Toggle       | none                                             |
| `/toggle-group` | ToggleGroup  | none                                             |
| `/toolbar`      | Toolbar      | none                                             |
| `/tooltip`      | Tooltip      | none                                             |

`@nyte-ai/ui/sonner` exports `Toaster`, `toast`, and the `ExternalToast` and `ToasterProps` types
from the `sonner` package.

## Not wrapped

Base UI parts with no subpath yet: Checkbox, CheckboxGroup, Radio, RadioGroup, Field, Fieldset,
Form, Progress, Meter, Separator, ScrollArea, Accordion, Combobox, NavigationMenu, Toast.
