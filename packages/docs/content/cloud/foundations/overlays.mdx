---
title: Overlays
description: "Telling a host which floating surfaces are open"
---

```ts title="Import"
import { OverlayRefProvider, useOverlayRef } from "@nyte-ai/ui/overlay";
```

Native layers such as web views paint above the DOM whatever the z-index. `OverlayRefProvider` tells
the host which floating elements are open so it can move those layers aside.

Every popup and backdrop in the package attaches the callback. The [Toast](/cloud/components/toast)
list attaches it while a toast is open.

## Usage

- Provide it once at the app root. Its context reaches portalled popups.
- Keep the callback stable. A new function detaches and reattaches every open popup.
- For surfaces outside the package, attach `useOverlayRef()` as the `ref`.

## Examples

```tsx
const openOverlays = new Set<Element>();

function overlayRef(element: Element | null): (() => void) | undefined {
  if (element === null) return undefined;
  openOverlays.add(element);

  return () => {
    openOverlays.delete(element);
  };
}

<OverlayRefProvider value={overlayRef}>
  <App />
</OverlayRefProvider>;
```

```tsx
function Panel({ children }: { children: ReactNode }) {
  const overlayRef = useOverlayRef();

  return <div ref={overlayRef}>{children}</div>;
}
```

## Props

### OverlayRefProvider

| Prop       | Type              | Default | Description                              |
| ---------- | ----------------- | ------- | ---------------------------------------- |
| `value`    | `OverlayRef`      |         | Attached to every open floating surface. |
| `children` | `React.ReactNode` |         |                                          |

`OverlayRef` is `(element: Element | null) => (() => void) | undefined`. `useOverlayRef()` returns
it, or `undefined` outside a provider.
