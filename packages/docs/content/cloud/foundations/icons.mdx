Nyte draws every glyph from [Central Icons](https://centralicons.com). `@nyte-ai/ui` installs two
sets under aliases and reaches both through [Icon](/cloud/components/icon).

| Alias                  | Package                                                   |
| ---------------------- | --------------------------------------------------------- |
| `central-icons`        | `@central-icons-react/round-outlined-radius-2-stroke-1.5` |
| `central-icons-filled` | `@central-icons-react/round-filled-radius-2-stroke-1.5`   |

Central Icons needs a license key at install time (`CENTRAL_LICENSE_KEY`).

## Usage

```tsx
import { Button } from "@nyte-ai/ui/button";
import { Icon } from "@nyte-ai/ui/icon";

<Icon name="folder" />
<Button size="sm" iconOnly icon="plus" aria-label="Add" />
```

- Choose a glyph by its semantic name. Do not import a glyph from the icon packages beside `Icon`,
  so one surface never mixes two geometries.
- Give an icon-only control an `aria-label`. The glyph is decorative.
- Sizes are 12, 14, or 16 inside controls.

## Stroke weight

The sets draw a 1.5-unit stroke on a 24-unit grid, which reads thin at 10 to 17px. Every `Icon`
frame carries `data-nyte-icon`, so an app can thicken the stroke in its global stylesheet.

```css
[data-nyte-icon] svg [stroke]:not([stroke="none"]) {
  stroke-width: 1.875;
}
```
