```ts
import { role, type, motion, shadow, appearance } from "@nyte-ai/ui/vars.stylex";
import { button, shape } from "@nyte-ai/ui/schema.stylex";
import { surfaceTheme, intent } from "@nyte-ai/ui/surface-theme";
```

Use a colour role inside a scope. Use component measurements for controls and shape names for
rounded containers. Ramps, the theme mapping, and size values are private.

## Usage

```tsx
import { create, props } from "@stylexjs/stylex";
import { role, type } from "@nyte-ai/ui/vars.stylex";
import { shape } from "@nyte-ai/ui/schema.stylex";
import { intent } from "@nyte-ai/ui/surface-theme";

const styles = create({
  status: {
    color: role.contentSecondary,
    backgroundColor: role.bgInteractiveSecondaryTranslucent,
    borderRadius: shape.control,
    fontSize: type.fontBase,
  },
});

export function Status() {
  return <span {...props(intent.success, styles.status)}>Saved</span>;
}
```

The default scope is neutral gray. `surfaceTheme.gray` uses the tinted mapping over gray.
`surfaceTheme.custom` follows the host's hue and intensity. Other scopes are `brown`, `orange`,
`yellow`, `green`, `blue`, `purple`, `pink`, `red`, and `teal`.

| Colour use                    | Scope                                                  | Role                                                                     |
| ----------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------ |
| Status text                   | `intent.success`, `intent.warning`, or `intent.danger` | `contentSecondary`                                                       |
| Filled action                 | `intent.primary`                                       | `buttonFill` and `contentOnInteractiveStrong`                            |
| Syntax token                  | A hue per token kind                                   | `contentSecondary`                                                       |
| Dot, file glyph, chart series | A hue per category                                     | `contentInteractiveTertiary`                                             |
| Added diff line or word       | `surfaceTheme.green`                                   | `bgInteractiveSecondaryTranslucent` or `bgInteractivePrimaryTranslucent` |
| Removed diff line or word     | `surfaceTheme.red`                                     | The same background roles                                                |
| Avatar                        | A hue per avatar                                       | `bgInteractiveSecondaryTranslucent` and `contentInteractivePrimary`      |

Apply both parts of a scope through `props(surfaceTheme.blue, styles.item)`. Applying the hue
alone leaves inherited roles resolved in the parent scope. Scope a list container when all its
items share a hue.

## Layers

| Kind       | Order                                            | Consumer API                                                                                                           |
| ---------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| Colour     | Ramps → theme → neutral or tinted roles          | `role`                                                                                                                 |
| Size       | Values → components → app layout                 | `button`, `input`, `switchControl`, `checkbox`, `row`, `menu`, `dialog`, `toast`, `glyph`, `clipboardPreview`, `shape` |
| Type       | Font inputs and derived type scale               | `type`                                                                                                                 |
| Motion     | Durations and easing                             | `motion`                                                                                                               |
| Shadow     | Size values and shadow inks → elevation          | `shadow`                                                                                                               |
| Appearance | Display, pointer, transparency, and focus inputs | `appearance`                                                                                                           |

`shape` has six names: `square`, `indicator`, `control`, `card`, `surface`, and `pill`.
Component-specific radii remain on their component handles. Component sizes grow under
`(pointer: coarse)`.

Roles resolve through `light-dark()`. Set `color-scheme` on the host or an ancestor to choose the
appearance. The focus ring is fixed blue and does not follow a hue scope.

Readable text uses `contentPrimary` or `contentSecondary`. `contentTertiary` is for placeholders,
disabled hints, and decoration. Glyphs use `contentInteractiveTertiary` or a stronger role.

Consumer styles import handles instead of writing `var(--nyte-…)`. Ramps and size primitives are
data, not custom properties. A measurement without a handle is a literal on the design scale.
Control measurements belong to components; app layout decisions build on those measurements.

## Native colours

```ts
import { platformColors, platformScopes } from "@nyte-ai/ui/platform-colors";

const page = platformColors.light.bgBase;
const status = platformScopes.light.green.contentSecondary;
```

Native colours are resolved values for each appearance. Choose a scope and a role at the native
palette boundary rather than defining a fixed status or syntax colour.

## Compiled styles

Apps that do not compile StyleX load the package stylesheet.

@import "@nyte-ai/ui/ui.css";
