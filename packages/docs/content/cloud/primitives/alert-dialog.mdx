```ts title="Import"
import {
  AlertDialog,
  AlertDialogClose,
  AlertDialogContent,
  AlertDialogDescription,
  AlertDialogFooter,
  AlertDialogTitle,
  AlertDialogTrigger,
} from "@nyte-ai/ui";
```

The [Dialog](/cloud/primitives/dialog) surface with alert semantics, built on
[`@nyte-ai/ui/alert-dialog`](/cloud/headless/alert-dialog). The two look identical, the behavior
differs.

## Usage

- Use it for a decision the user cannot back out of by clicking away. Delete, discard, overwrite,
  revoke.
- The footer needs an explicit way out, a Cancel `AlertDialogClose`. There is no ✕ and outside
  press does nothing.
- Title states the question, description states the consequence. Both are required.
- The destructive action is the last button and uses `variant="destructive"`.

## Anatomy

```tsx
<AlertDialog>
  <AlertDialogTrigger />
  <AlertDialogContent>
    {/* Portal › Backdrop › Popup */}
    <AlertDialogTitle />
    <AlertDialogDescription />
    <AlertDialogFooter>
      <AlertDialogClose /> {/* cancel */}
      <AlertDialogClose /> {/* confirm */}
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

## Accessibility

- `role="alertdialog"` and `aria-modal="true"`, labelled by the title and described by the
  description.
- Outside press does not close. Escape does. To block that, pass an `onOpenChange` that ignores
  the `escape-key` reason.
- Focus moves into the popup on open and returns to the trigger on close.
