Spacing counts 4px units the way Tailwind does: `s2` is two units, `s1_5` is one and a half.
`space.px` is 1px, the width of a hairline.

```ts
import { space, target } from "@nyte-ai/ui/styles/schema.stylex";
```

<SpaceScale />

## Rules

- Padding, margin, gap, and inset use `space.*`.
- A structural measurement, such as a sidebar width or a menu width, gets a name in a schema
  file instead of a literal.
- Controls and rows take their height from `button`, `input`, `row`, `menu`, or `target`.
- Visual size and hit area are separate. A control stays at least `target.min` to hit: 24px, or
  44px under a coarse pointer. Independent controls sit `target.gap` apart: 2px, or 8px.
- Use logical properties: `paddingInline`, `marginBlockStart`, `insetInlineEnd`.

## Hairlines

```ts
import { hairline } from "@nyte-ai/ui/styles/hairline.stylex";
```

A hairline is a 1px edge that takes no layout space, so a box keeps its height on the grid. Each
style draws an inset shadow in `strokeQuaternary`. Forced colors drop shadows, so there the edge
styles draw a border image, `hairline.ring` an inset outline and `hairline.ringAfter` a border on its
pseudo-element, which take no space either.

| Style                  | Draws                                                                                                                                          |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `hairline.blockEnd`    | The bottom edge of a bar, a header row, or a form.                                                                                             |
| `hairline.inlineStart` | The inline-start edge of a panel, the left one in left-to-right text.                                                                          |
| `hairline.tableCell`   | A rule under each table row but the body's last, and a divider after each cell but the row's last. Set it on the cells.                        |
| `hairline.ring`        | All four sides, following the box's radius.                                                                                                    |
| `hairline.ringAfter`   | All four sides on the box's `::after`, above its content, for a focusable control or a popup. The box is positioned and leaves `::after` free. |

```tsx
<div {...stylex.props(styles.toolbar, hairline.blockEnd)}>…</div>
```

- Draw a separator, a divider, or a frame with `hairline`, not a 1px border.
- A box takes one hairline style and sets no `boxShadow` of its own. A second style or its own shadow
  replaces the hairline's. A raised box sets its drop shadow as `--nyte-hairline-elevation`, which the
  hairline draws under its edge and which doesn't pass to the boxes inside.
- A box that takes a hairline sets no `borderImage` with an edge style, and no `outline` or its
  longhands with `hairline.ring`. Those replace the forced-colors edge.
