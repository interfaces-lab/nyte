Spacing counts 4px units. `s2` is two units, `s1_5` is one and a half. `space.px` is 1px.

```ts
import { space, target } from "@nyte-ai/ui/styles/schema.stylex";
```

<SpaceScale />

## Rules

- Use `space.*` for padding, margin, gap, and inset.
- Name structural measurements, such as sidebar widths, in a schema.
- Button and input heights come from `control`. Row and menu-item heights come from `row`.
  `button`, `input`, and `menu` supply other geometry.
- `target.min` is the hit-area floor, not visual height. It is 24px, or 44px under a coarse pointer.
  Separate independent controls by `target.gap`, 2px or 8px respectively.
- Use logical properties such as `paddingInline`, `marginBlockStart`, and `insetInlineEnd`.

## Hairlines

```ts
import { hairline } from "@nyte-ai/ui/styles/hairline.stylex";
```

Hairlines draw 1px edges without taking layout space. Shadow-drawn edges use `strokeQuaternary`,
except `controlRing`'s `strokeTertiary`. Forced colors use border images, outlines, or borders.
`startsAfter` and `endsAfter` use borders in both modes.

Position boxes with pseudo-element hairlines and reserve `::after`.

| Style                  | Draws                                                                       |
| ---------------------- | --------------------------------------------------------------------------- |
| `hairline.blockStart`  | Top edge                                                                    |
| `hairline.blockEnd`    | Bottom edge                                                                 |
| `hairline.inlineStart` | Inline-start edge                                                           |
| `hairline.tableCell`   | Row and cell dividers, excluding last edges. Apply to cells.                |
| `hairline.ring`        | Rounded frame                                                               |
| `hairline.ringAfter`   | Frame above content on `::after`                                            |
| `hairline.controlRing` | Control boundary. Forced-colors `::after` border uses `Highlight` on focus. |
| `hairline.startsAfter` | Block-start and inline-start edges on `::after`                             |
| `hairline.endsAfter`   | Block-end and inline-end edges on `::after`                                 |
| `hairline.pressedRing` | Forced-colors `Highlight` border on `[data-pressed]::after`                 |

```tsx
import { create, props } from "@stylexjs/stylex";
import { hairline } from "@nyte-ai/ui/styles/hairline.stylex";
import { space } from "@nyte-ai/ui/styles/schema.stylex";

const styles = create({ toolbar: { padding: space.s2 } });

export function ToolbarHeading() {
  return <div {...props(styles.toolbar, hairline.blockEnd)}>Actions</div>;
}
```

- Use `hairline`, not 1px borders, for separators and frames.
- Apply one shadow-drawing hairline per box. Do not set `boxShadow`. Set elevation through
  `--nyte-hairline-elevation`.
- Import `@nyte-ai/ui/styles/base.css` once for non-inheriting elevation and the solid border reset.
- `pressedRing` can accompany a base hairline. Avoid competing `::after` styles.
- Do not override `borderImage` on edge styles or `outline` on `hairline.ring`. They draw forced-colors edges.
