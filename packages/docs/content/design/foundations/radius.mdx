Radius names describe shapes, not sizes.

```ts
import { radius } from "@nyte-ai/ui/styles/schema.stylex";
```

## Rules

- Containers use `radius` names. Controls use size handles such as `button.radiusMd` and
  `input.radiusLg`.
- Keep nested corners concentric. The menu's 14px radius is its items' 8px plus 6px padding.
- Button and input radii grow under a coarse pointer. Checkbox, row, menu, and dialog radii
  stay fixed. Read handles rather than branching on touch.
- Use `radius.pill` for always-round ends.
