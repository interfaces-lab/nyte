[Icon](/design/icon) draws [Central Icons](https://centralicons.com) through two aliases.

| Alias                  | Package                                                   |
| ---------------------- | --------------------------------------------------------- |
| `central-icons`        | `@central-icons-react/round-outlined-radius-2-stroke-1.5` |
| `central-icons-filled` | `@central-icons-react/round-filled-radius-2-stroke-1.5`   |

Set `CENTRAL_LICENSE_KEY` to install Central Icons. Without the packages, `Icon` uses
[Lucide](https://lucide.dev), [Simple Icons](https://simpleicons.org), and generic brand fallbacks.
Override selection with `NYTE_ICONS=central` or `NYTE_ICONS=lucide`. Each new name needs a Lucide glyph.

## Usage

```tsx
import { Button } from "@nyte-ai/ui/button";
import { Icon } from "@nyte-ai/ui/icon";

export function FolderActions() {
  return (
    <>
      <Icon name="folder" />
      <Button size="sm" iconOnly icon="plus" aria-label="Add" />
    </>
  );
}
```

- Use semantic names, not direct glyph imports.
- Give icon-only controls an `aria-label`.
- `Icon` sizes run from `"2xs"` to `"lg"` (10–20px), defaulting to `"md"` (16px).
  `Button` and `Toggle` size their `icon`.
- Give standalone meaningful icons a `label`. Otherwise icons are hidden from assistive technology.
- `variant="outlined"` is default. `variant="filled"` accepts `"bubble-question"`, `"star"`, and `"warning"`.

## Stroke weight

Outlined Central and Lucide glyphs use 1.5-unit strokes on a 24-unit grid.
Filled shapes and brand paths do not all have strokes.
Override strokes through `data-nyte-icon`, including Lucide's root SVG.

```css
[data-nyte-icon] svg[stroke]:not([stroke="none"]),
[data-nyte-icon] svg [stroke]:not([stroke="none"]) {
  stroke-width: 1.875;
}
```
