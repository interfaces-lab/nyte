```ts
import { role, type, motion, shadow, appearance } from "@nyte-ai/ui/styles/vars.stylex";
import { button, radius } from "@nyte-ai/ui/styles/schema.stylex";
import { surfaceTheme, intent } from "@nyte-ai/ui/surface-theme";
```

Use colour roles inside scopes, component handles for controls, and radius names for containers.
Ramps and theme mappings have no public subpath. `styles/tokens.stylex` exports variable groups
for theme overrides.

## Usage

```tsx
import { create, props } from "@stylexjs/stylex";
import { role } from "@nyte-ai/ui/styles/vars.stylex";
import { text } from "@nyte-ai/ui/styles/text.stylex";
import { radius } from "@nyte-ai/ui/styles/schema.stylex";
import { intent } from "@nyte-ai/ui/surface-theme";

const styles = create({
  status: {
    color: role.contentSecondary,
    backgroundColor: role.fillTertiary,
    borderRadius: radius.control,
  },
});

export function Status() {
  return <span {...props(intent.success, text.base, styles.status)}>Saved</span>;
}
```

The default scope is neutral gray. `surfaceTheme.gray` applies tinted gray roles.
`surfaceTheme.custom` reads `--nyte-custom-hue` and `--nyte-custom-chroma-scale`.
Other scopes are `brown`, `orange`, `yellow`, `green`, `blue`, `purple`, `pink`, `red`, and `teal`.

| Colour use    | Scope                                               | Role                                       |
| ------------- | --------------------------------------------------- | ------------------------------------------ |
| Status        | `intent.success`, `intent.warning`, `intent.danger` | `contentSecondary`                         |
| Filled action | `intent.primary`                                    | `buttonFill`, `contentOnInteractiveStrong` |
| Dot, glyph    | Category hue                                        | `contentAccent`                            |
| Chart         | Category hue                                        | `chartSeries`                              |
| Avatar        | Avatar hue                                          | `fillTertiary`, `contentPrimary`           |

Apply scopes with `props(surfaceTheme.blue, styles.item)`. Scope a list when items share a hue.

Code highlighting uses `codeThemes` from `@nyte-ai/ui/code-themes`. Diff tints are not
`fillTertiary` or `fillSecondary`.

## Layers

| Kind                | Consumer API                                                                                                                                             |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Colour              | `role`                                                                                                                                                   |
| Size                | `control`, `button`, `input`, `switchControl`, `checkbox`, `row`, `menu`, `dialog`, `command`, `avatar`, `slider`, `glyph`, `clipboardPreview`, `radius` |
| Spacing and targets | `space`, `target`                                                                                                                                        |
| Stacking            | `layer`                                                                                                                                                  |
| Media               | `media`                                                                                                                                                  |
| Type                | `type`                                                                                                                                                   |
| Motion              | `motion`                                                                                                                                                 |
| Shadow              | `shadow`                                                                                                                                                 |
| Appearance          | `appearance`                                                                                                                                             |

`radius` names are `indicator`, `control`, `card`, `surface`, and `pill`.
Component radii use component handles.

`control.height2xs` through `control.heightXl` run from 16–36px, or 28–48px under a coarse pointer.
`row.heightMd` and `row.heightLg` enforce `target.min`, reaching 44px on touch.
Glyphs, avatars, and container radii stay fixed.

Scheme-dependent roles follow `color-scheme`. `chartSeries` and `strokeAccent` use fixed ramp steps.
Focus ignores hue scopes.

See [Colors](/design/colors) for stairs and contrast floors. `contentAccent` supplies scoped ink,
including errors under `intent.danger`.

Import handles instead of raw variables. Use scale literals when no handle exists.

## Native colours

```ts
import { platformColors, platformScopes } from "@nyte-ai/ui/platform-colors";

const page = platformColors.light.bgBase;
const status = platformScopes.light.green.contentSecondary;
```

`platformColors` snapshots neutral light/dark values at normal contrast. `platformScopes` snapshots
selected category roles for ten fixed hues, excluding `custom` and intent overrides.
Neither reacts to runtime appearance overrides.

## Compiled styles

Without a StyleX compiler, load compiled component styles and the browser baseline once.
Your own `create()` calls and source-only token modules still need compilation.

```css
@import "@nyte-ai/ui/styles/base.css";
@import "@nyte-ai/ui/ui.css";
```
