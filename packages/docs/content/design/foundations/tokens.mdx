```ts
import { role, type, motion, shadow, appearance } from "@nyte-ai/ui/styles/vars.stylex";
import { button, radius } from "@nyte-ai/ui/styles/schema.stylex";
import { surfaceTheme, intent } from "@nyte-ai/ui/surface-theme";
```

Use colour roles inside scopes, component handles for controls, and radius names for rounded
containers. Ramps, theme mappings, and size values are private.

## Usage

```tsx
import { create, props } from "@stylexjs/stylex";
import { role, type } from "@nyte-ai/ui/styles/vars.stylex";
import { radius } from "@nyte-ai/ui/styles/schema.stylex";
import { intent } from "@nyte-ai/ui/surface-theme";

const styles = create({
  status: {
    color: role.contentSecondary,
    backgroundColor: role.fillTertiary,
    borderRadius: radius.control,
    fontSize: type.fontBase,
  },
});

export function Status() {
  return <span {...props(intent.success, styles.status)}>Saved</span>;
}
```

The default scope is neutral gray. `surfaceTheme.gray` applies tinted roles over gray, and
`surfaceTheme.custom` takes its hue from `--nyte-custom-hue` and `--nyte-custom-chroma-scale`. Other
scopes are `brown`, `orange`,
`yellow`, `green`, `blue`, `purple`, `pink`, `red`, and `teal`.

| Colour use                    | Scope                                                  | Role                                                              |
| ----------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------- |
| Status text                   | `intent.success`, `intent.warning`, or `intent.danger` | `contentSecondary`                                                |
| Filled action                 | `intent.primary`                                       | `buttonFill` and `contentOnInteractiveStrong`                     |
| Syntax token                  | A hue per token kind                                   | `contentSecondary`                                                |
| Dot, file glyph, chart series | A hue per category                                     | `contentAccent`                                                   |
| Added diff line or word       | `surfaceTheme.green`                                   | `fillTertiary` for the line, `fillSecondary` over it for the word |
| Removed diff line or word     | `surfaceTheme.red`                                     | The same fill roles                                               |
| Avatar                        | A hue per avatar                                       | `fillTertiary` and `contentPrimary`                               |

Apply a scope with `props(surfaceTheme.blue, styles.item)`. Scope the list when every item shares a
hue.

## Layers

| Kind       | Order                                            | Consumer API                                                                                                                       |
| ---------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| Colour     | Ramps → theme → neutral or tinted roles          | `role`                                                                                                                             |
| Size       | Values → components → app layout                 | `control`, `button`, `input`, `switchControl`, `checkbox`, `row`, `menu`, `dialog`, `toast`, `glyph`, `clipboardPreview`, `radius` |
| Type       | Font inputs and derived type scale               | `type`                                                                                                                             |
| Motion     | Durations and easing                             | `motion`                                                                                                                           |
| Shadow     | Size values and shadow inks → elevation          | `shadow`                                                                                                                           |
| Appearance | Display, pointer, transparency, and focus inputs | `appearance`                                                                                                                       |

`radius` has five names: `indicator`, `control`, `card`, `surface`, and `pill`.
Component radii stay on their component handles. Component sizes grow under `(pointer: coarse)`.

`control` is the one control-height scale: `height2xs` to `heightXl`, 16 to 36px, and 28 to
48px under a coarse pointer. Buttons, inputs, and toggles take a step. `row.heightMd` and
`row.heightLg` take the `md` and `lg` steps but never fall below `target.min`, so a row or menu
item is 44px on touch.

Roles resolve through `light-dark()`, so `color-scheme` on an ancestor picks the appearance. The
focus ring ignores hue scopes.

Content, fills, and strokes are stairs. Each step has one job, each content step keeps a contrast
floor on every surface, and hover moves up one step. See [Colors](/design/colors) for every step
and the rules.
`contentAccent` is the scope's hue as ink. Under `intent.danger` it is the error colour; under a
category scope it is that hue.

Import handles instead of writing `var(--nyte-…)`. Use a design-scale literal when no handle
exists.

## Native colours

```ts
import { platformColors, platformScopes } from "@nyte-ai/ui/platform-colors";

const page = platformColors.light.bgBase;
const status = platformScopes.light.green.contentSecondary;
```

Native colours contain resolved values for each appearance. Use a scope and role instead of a
fixed status or syntax colour.

## Compiled styles

Without a StyleX compiler, load the package stylesheet.

```css
@import "@nyte-ai/ui/ui.css";
```
