## The ring

`focus` draws a 1px `appearance.focusRing` outline on `:focus-visible`, independent of hue scopes.
Menus use `data-highlighted`. The ring is blue, or `Highlight` in forced colors.

```ts title="Import"
import { focus, srOnly } from "@nyte-ai/ui/styles/a11y.stylex";
```

| Style             | Use                            |
| ----------------- | ------------------------------ |
| `focus.ring`      | Standalone control             |
| `focus.ringInset` | Rows where an outer ring clips |
| `srOnly`          | Visually hidden label          |

```tsx
import { create, props } from "@stylexjs/stylex";
import { focus } from "@nyte-ai/ui/styles/a11y.stylex";
import { role } from "@nyte-ai/ui/styles/vars.stylex";
import { text } from "@nyte-ai/ui/styles/text.stylex";

const styles = create({ link: { color: role.contentAccent } });

export function SettingsLink() {
  return (
    <a href="/settings" {...props(text.base, styles.link, focus.ring)}>
      Settings
    </a>
  );
}
```

`Input` and `Textarea` replace outlines with `appearance.focusColor` borders on `:focus`.
Invalid borders can remain error-colored. `Input`'s `bare` variant has no focus indicator.
`InputGroup` uses `:focus-within`.

## Focus modality

Apply a `focusModality` theme to the document for pointer focus.

```ts title="pointer-focus.stylex.ts"
import { createTheme } from "@stylexjs/stylex";
import { focusModality } from "@nyte-ai/ui/styles/tokens.stylex";

export const pointerFocus = createTheme(focusModality, {
  "--nyte-focus-ring": "transparent",
});
```

Start in pointer mode. Switch to keyboard mode on Tab inside text fields, or any non-modifier
key elsewhere. Listen during capture. Remove the override for keyboard focus. Input borders remain.

## Keyboard defaults

| Component            | Keys                                                                                                     |
| -------------------- | -------------------------------------------------------------------------------------------------------- |
| Button, Toggle       | Enter and Space activate                                                                                 |
| Dialog, Alert dialog | Focus enters, stays inside, then returns. Escape requests closing. Alert dialog ignores outside presses. |
| Menu                 | Arrows move, Home/End jump, typing matches labels, Enter/Space activate, Escape closes                   |
| Input                | Native                                                                                                   |

## Disabled

Disabled buttons, toggles, and menu items use `role.contentDisabled`. Loading buttons retain normal ink.
