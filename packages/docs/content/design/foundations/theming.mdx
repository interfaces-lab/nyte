| Layer         | Owns                                                      |
| ------------- | --------------------------------------------------------- |
| Base UI       | Interaction, focus, ARIA, state attributes                |
| `@nyte-ai/ui` | Component styling through StyleX [tokens](/design/tokens) |
| App           | Layout, typography, identity, composites                  |

## Colour scopes

Pass scopes to `props()` for tinted roles. Use `intent` for meaning, `surfaceTheme` for categories.

```tsx
import { create, props } from "@stylexjs/stylex";
import { surfaceTheme } from "@nyte-ai/ui/surface-theme";
import { role } from "@nyte-ai/ui/styles/vars.stylex";

const styles = create({
  panel: { backgroundColor: role.fillTertiary },
});

export function PreviewPanel() {
  return <section {...props(surfaceTheme.blue, styles.panel)}>Preview</section>;
}
```

## Measurements

Read geometry from `@nyte-ai/ui/styles/schema.stylex`. `control` supplies heights, `button` and
`input` padding and radii. `row` heights enforce `target.min`. Use scale literals when no handle exists.

## Styling a component

Choose appearance through `size`, `variant`, and `tone`.

| Prop        | Takes                                                  |
| ----------- | ------------------------------------------------------ |
| `xstyle`    | `create()` styles within the part's `Restyle` contract |
| `className` | String or supported state function                     |
| `style`     | `CSSProperties` or supported state function            |

State functions require a Base UI-backed part. Check its prop type.
`xstyle` merges last. Classes follow cascade order. Inline styles override ordinary stylesheet declarations.
Set each property through one channel.

`Button` and `Toggle` accept `ButtonLayout`, including placement and `borderRadius`, not padding,
height, or colors.

## Dark mode

Use `applyDisplayMode` with `"light"` or `"dark"`. Resolve system preference yourself.

```ts
import { applyDisplayMode } from "@nyte-ai/ui/appearance";

applyDisplayMode("dark");
```

A custom `.dark` class must set `color-scheme: dark`.
