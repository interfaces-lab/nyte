UI sizes derive from `--nyte-font-size-base`, defaulting to 13px. Code uses
`--nyte-font-size-code`, defaulting to 12px. Text presets pair size, line box, and tracking.
`text.code` sets monospace. Other presets inherit family. All inherit weight.

```tsx
import { create, props } from "@stylexjs/stylex";
import { text } from "@nyte-ai/ui/styles/text.stylex";
import { type } from "@nyte-ai/ui/styles/vars.stylex";

const styles = create({ label: { fontWeight: type.weightMedium } });

export function Label() {
  return <p {...props(text.sm, styles.label)}>Workspace</p>;
}
```

## Families

| Handle          | Default                                     |
| --------------- | ------------------------------------------- |
| `type.fontSans` | Inter Variable, then system UI              |
| `type.fontMono` | System monospace, optionally JetBrains Mono |

Select families through `type.uiFontInter`, `type.uiFontSystem`, `type.codeFontJetbrainsMono`,
and `type.codeFontSystem`. Presets do not load fonts.

## Rules

- Use `text.*`, or pair `type.font*` with its matching `type.leading*`.
- Line heights round up to whole pixels.
- 13px Inter needs at least `text.baseCompact`'s 16px line box to avoid clipped descenders.
- Reserve `lineHeight: 1` for glyphs.
- `type.weight*` provides 400, 500, and 600. `b` and `strong` use `bolder`.
- `text.lg`, `text.xl`, `text["2xl"]`, and `text["3xl"]` track at `-0.016em`, smaller UI presets at `0em`,
  and `text.code` at `normal`.
