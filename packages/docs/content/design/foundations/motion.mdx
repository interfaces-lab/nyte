## Rules

- Read durations and curves from `motion`.
- Set reduced-motion overrides on styles. Duration tokens do not change automatically.
  Keep the final state without travel.
- Guard hover with `@media (hover: hover) and (pointer: fine)`. Keep actions keyboard- and touch-reachable.
- Use Base UI's `data-starting-style` and `data-ending-style` for popups.
  Native CSS entry transitions use `@starting-style` and `transitionBehavior: "allow-discrete"`.
