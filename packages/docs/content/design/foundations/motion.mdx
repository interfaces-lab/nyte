## Rules

- Transitions read a duration and a curve from `motion` instead of writing milliseconds.
- Every transition has a reduced-motion path that ends in the same state without the travel.
- Hover is an enhancement: guard it with `@media (hover: hover) and (pointer: fine)`, and keep
  every action reachable by keyboard and touch.
- CSS owns what CSS can resolve. Entry animations use `@starting-style` and
  `transitionBehavior: allow-discrete`, not React state and `requestAnimationFrame`.
