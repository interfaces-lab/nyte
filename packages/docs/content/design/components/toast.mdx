```ts title="Import"
import {
  ToastGlyph,
  ToastProvider,
  ToastStack,
  toast,
  toastHolds,
  useHeldToasts,
  useToasts,
} from "@nyte-ai/ui/toast";
```

`ToastStack` renders the toasts `ToastProvider` holds, and `toast.add` opens one. Keep form errors in the form.

## Usage

- Wrap the app in one `ToastProvider` and render one `ToastStack` inside it before calling `toast.add`. Calls can come from outside React.
- The stack drops from the element whose CSS `anchor-name` matches its `anchor`, aligned to that element's end edge, or from the window's top end corner without one. It folds into a deck and spreads while pointed at or focused.
- A toast without an `id` gets one from what it says, so a repeat lands on the live copy, shows ×2, and restarts its timer.
- Warnings and errors hold. One that leaves the stack before anyone answers it, by its timer, its close button, a swipe or `toast.hold`, waits in `useHeldToasts` until `toast.close` ends it.
- `useToasts` and `useHeldToasts` feed a view of your own, such as a list behind the anchor. Pass `hidden` to the stack while that view shows them, and draw their marks with `ToastGlyph`.
- Error toasts with a string title get a Copy error button. A string description joins the copied text on a new line.
- Action buttons use `actionProps`. Call `toast.close(id)` in the handler to close the notification.

### A toast that stays

```ts
const id = toast.add({
  type: "error",
  title: "Couldn't open folder",
  id: "workspace-open",
  timeout: 0,
  description: `${reason}\nTry opening the folder again. If it still fails, copy the error details.`,
});

toast.close(id);
```

### An action and undo

`onClose` runs for every close, including the timer and `toast.close`. Mark the action as undone before closing it.

```ts
const action = { undone: false };

toast.add({
  type: "success",
  title: "3 chats archived",
  id: "archive",
  actionProps: {
    children: "Undo",
    onClick: () => {
      action.undone = true;
      restore();
      toast.close("archive");
    },
  },
  onClose: () => {
    if (!action.undone) commit();
  },
});
```

### A pending operation

```ts
await toast.promise(save(), {
  loading: "Saving",
  success: "Saved",
  error: (cause: unknown) => ({
    title: "Couldn’t confirm the save",
    description: [
      cause instanceof Error ? cause.message : "The save request failed.",
      "Check whether your changes were saved before saving again. If you still need help, copy the error details.",
    ].join("\n"),
  }),
});
```

Each state accepts a string or an options object. `success` and `error` also accept a function returning either. The returned promise resolves with the operation's result or rejects with its error.

## Props

### ToastProvider

| Prop       | Type        | Default  | Description                           |
| ---------- | ----------- | -------- | ------------------------------------- |
| `children` | `ReactNode` | Required |                                       |
| `limit`    | `number`    | `3`      | Older toasts are hidden, not removed. |

### ToastStack

| Prop     | Type      | Default | Description                                         |
| -------- | --------- | ------- | --------------------------------------------------- |
| `anchor` | `string`  |         | A dashed ident, the `anchor-name` to drop from.     |
| `hidden` | `boolean` | `false` | Keeps the stack out of sight; the toasts stay live. |

### useToasts and useHeldToasts

`useToasts` returns `readonly ToastItem[]`, newest first, including toasts playing their exit. `ToastItem` is a toast whose `data` is `ToastData`: `at`, when `toast.add` last stamped it, and `count`, how many times it said the same thing.

`useHeldToasts` returns `readonly HeldToast[]`, newest first: the `id`, `type`, `title`, `description`, `actionProps` and `data` of each toast that holds and left the stack unanswered. `toastHolds(item)` says whether a toast holds.

### ToastGlyph

| Prop   | Type                  | Default  | Description                                          |
| ------ | --------------------- | -------- | ---------------------------------------------------- |
| `type` | `string \| undefined` | Required | A spinner for `"loading"`, info for an unknown type. |

### toast

| Call                                                  | Returns          | Description                                   |
| ----------------------------------------------------- | ---------------- | --------------------------------------------- |
| `toast.add(options)`                                  | `string`         | Opens or updates by id. Refreshes timer.      |
| `toast.close(id?)`                                    | `void`           | Ends it, held or live. Omit id to end all.    |
| `toast.hold(id)`                                      | `void`           | Takes it out of the stack; a hold waits held. |
| `toast.update(id, options)`                           | `void`           | Also accepts a function of the current toast. |
| `toast.promise(promise, { loading, success, error })` | `Promise<Value>` | Tracks the operation.                         |

### Toast options

`ToastOptions` types `toast.add` options. `toast.add` sets their `data`.
`toast.update` accepts partial options without `id` or `transitionStatus`.

| Option             | Type                                    | Description                                                                  |
| ------------------ | --------------------------------------- | ---------------------------------------------------------------------------- |
| `title`            | `ReactNode`                             |                                                                              |
| `type`             | `string`                                | `"success"`, `"error"`, `"warning"` show icons. `"loading"` shows a spinner. |
| `description`      | `ReactNode`                             |                                                                              |
| `id`               | `string`                                | Generated when omitted.                                                      |
| `timeout`          | `number`                                | Auto-close milliseconds. Defaults to provider. `0` stays open.               |
| `actionProps`      | `ComponentPropsWithoutRef<"button">`    |                                                                              |
| `onClose`          | `() => void`                            | Runs on every close.                                                         |
| `onRemove`         | `() => void`                            | Runs after exit animation.                                                   |
| `priority`         | `"low" \| "high"`                       | Polite or urgent. Defaults to `"low"`.                                       |
| `data`             | `Data`                                  |                                                                              |
| `positionerProps`  | `ToastOptions<Data>["positionerProps"]` | Unused by `Toaster`.                                                         |
| `transitionStatus` | `"starting" \| "ending"`                | `toast.add` overwrites with `"starting"`. Unavailable in `toast.update`.     |

## Accessibility

- `priority: "high"` announces urgently without moving focus.
- F6 focuses the stack. Hover or focus pauses automatic dismissal.
- Loading toasts have no timer but can still be closed.
