```ts title="Import"
import { Toolbar } from "@nyte-ai/ui/toolbar";
```

Groups related buttons, toggles, and popup triggers, such as the panel toggles above a view.

## Usage

- Without `render`, pass [Button props](/design/button#props) to `Toolbar.Button`.
- With `render`, put appearance props and `xstyle` on the rendered `Button`, `Toggle`, or popup trigger.
- Put `disabled` on `Toolbar.Button`. Keep the rendered control's disabled and focusable behavior consistent.

## Anatomy

```tsx
<Toolbar.Root>
  <Toolbar.Button>Action</Toolbar.Button>
  <Toolbar.Separator />
  <Toolbar.Group>
    <Toolbar.Button>Action</Toolbar.Button>
    <Toolbar.Button>Action</Toolbar.Button>
  </Toolbar.Group>
</Toolbar.Root>
```

### With a tooltip

```tsx
import { Button } from "@nyte-ai/ui/button";
import { Tooltip, TooltipContent, TooltipTrigger } from "@nyte-ai/ui/tooltip";

<Toolbar.Root aria-label="Changes">
  <Tooltip>
    <TooltipTrigger
      render={
        <Toolbar.Button
          render={<Button iconOnly icon="refresh" aria-label="Refresh" title={undefined} />}
        />
      }
    />
    <TooltipContent>Refresh</TooltipContent>
  </Tooltip>
</Toolbar.Root>;
```

## Props

`Root`, `Group`, and `Separator` accept Base UI `className` and `style` state callbacks.

| Part                | Prop     | Type                           |
| ------------------- | -------- | ------------------------------ |
| `Toolbar.Root`      | `xstyle` | `Restyle<"Toolbar.Root">`      |
| `Toolbar.Group`     | `xstyle` | `Restyle<"Toolbar.Group">`     |
| `Toolbar.Separator` | `xstyle` | `Restyle<"Toolbar.Separator">` |

Without `render`, `Toolbar.Button` defaults `focusableWhenDisabled` to `true`. Its styling callbacks
receive button state. With `render`, it passes through Base UI toolbar-button props and state unstyled.

## Accessibility

- Label `Toolbar.Root` with `aria-label` or `aria-labelledby`.
- Arrow keys move focus, including disabled buttons by default. Set `loopFocus={false}` to stop wrapping.
- Root `orientation` sets arrow-key direction. The separator defaults to the opposite orientation.
