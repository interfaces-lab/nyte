import { Textarea } from "@nyte-ai/ui/textarea";

A native `<textarea>` framed like [Input](/design/input).

## Usage

- Disable resizing with `style={{ resize: "none" }}`, not `xstyle`.

```tsx
<Textarea placeholder="System prompt" aria-label="System prompt" />
```

## Props

Native `<textarea>` props. `className` and `style` take plain values.

| Prop                           | Type                           | Default    |
| ------------------------------ | ------------------------------ | ---------- |
| `variant`                      | `"raised" \| "quiet"`          | `"raised"` |
| `size`                         | `"md" \| "lg" \| "xl"`         | `"md"`     |
| `className`, `style`, `xstyle` | see [Theming](/design/theming) |            |

## Accessibility

Name it with a `<label>` or `aria-label`.
