```ts title="Import"
import { Command } from "@nyte-ai/ui/command";
```

A dialog near the top of the window with inline [Autocomplete](/design/autocomplete).

## Usage

- Filter rows yourself from `onValueChange`. Pass their values to `items` in render order.
- Keep `Command.Empty` mounted. Change its text for loading, failure, and no match.
- Name the palette with `title` on `Command.Popup`.
- `value` is the query. Use `onItemHighlighted` for the highlighted row.

## Anatomy

```tsx
<Command.Root>
  <Command.Trigger />
  <Command.Popup items={["action"]}>
    <Command.Input aria-label="Search commands" />
    <Command.List>
      <Command.Empty />
      <Command.Group>
        <Command.Item value="action" />
      </Command.Group>
      <Command.Separator />
    </Command.List>
    <Command.Close />
  </Command.Popup>
</Command.Root>
```

## Examples

```tsx
const [open, setOpen] = useState(false);
const [query, setQuery] = useState("");
const matches = commands.filter((command) =>
  command.label.toLowerCase().includes(query.toLowerCase()),
);

<Command.Root open={open} onOpenChange={setOpen}>
  <Command.Trigger render={<Button variant="outline">Search</Button>} />
  <Command.Popup
    title="Search commands"
    items={matches.map((command) => command.id)}
    value={query}
    onValueChange={setQuery}
  >
    <Command.Input aria-label="Search" placeholder="Search…" trailing={<Kbd keys={["⌘", "K"]} />} />
    <Command.List>
      <Command.Empty>No commands match "{query}"</Command.Empty>
      <Command.Group heading="Commands">
        {matches.map((command) => (
          <Command.Item
            key={command.id}
            value={command.id}
            leading={<Icon name={command.icon} size="md" />}
            meta={<Kbd keys={command.keys} plain />}
            onClick={() => {
              setOpen(false);
              command.run();
            }}
          >
            {command.label}
          </Command.Item>
        ))}
      </Command.Group>
    </Command.List>
    <Command.Close>Close</Command.Close>
  </Command.Popup>
</Command.Root>;
```

## Props

| Part                | Renders                                |
| ------------------- | -------------------------------------- |
| `Command.Trigger`   | `<button>`                             |
| `Command.Popup`     | Portal, scrim, popup, list root        |
| `Command.Input`     | Search glyph and `<input>`             |
| `Command.List`      | `<div role="listbox">`                 |
| `Command.Group`     | `<div role="group">`, optional heading |
| `Command.Separator` | `<div role="separator">`               |
| `Command.Item`      | `<div role="option">`                  |
| `Command.Empty`     | `<div role="status">`                  |
| `Command.Close`     | `<button>`                             |

Except `Command.Root`, each part takes `xstyle`, `className`, and `style`. `className` and `style`
accept plain values or functions of the underlying Base UI part's state. See [Theming](/design/theming).

## Accessibility

- Give `Command.Input` an accessible name.
- Enter runs the highlighted row's `onClick`. Close the palette there when appropriate.
- Include a reachable `Command.Close` for touch screen readers.
- Put the action name in the row label, not its hidden leading glyph.
- `initialFocus` and `finalFocus` override focus targets.
