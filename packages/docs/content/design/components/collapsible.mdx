title: Collapsible
description: "A panel that a trigger opens and closes"
---

```ts title="Import"
import { Collapsible } from "@nyte-ai/ui/collapsible";
```

Shows and hides detail such as tool output or earlier messages.

## Usage

- `defaultOpen` leaves the panel uncontrolled. `open` with `onOpenChange` controls it.
- Use `variant="plain"` when another styled part, such as `Row.Primary`, renders the trigger.
- Lay out `Collapsible.Root` and `Collapsible.Preview` with `xstyle`. Style content inside the animated panel.
- To unmount closed panels, pass `hiddenUntilFound={false}` and `keepMounted={false}`.
- Use `Collapsible.Preview` for content with its own controls that stays visible while closed.

## Anatomy

```tsx
<Collapsible.Root>
  <Collapsible.Trigger>
    <Collapsible.Chevron />
  </Collapsible.Trigger>
  <Collapsible.Panel />
  <Collapsible.Preview />
</Collapsible.Root>
```

### Controlled

```tsx
const [open, setOpen] = useState(false);

<Collapsible.Root open={open} onOpenChange={setOpen}>
  <Collapsible.Trigger>
    Earlier messages
    <Collapsible.Chevron />
  </Collapsible.Trigger>
  <Collapsible.Panel>{messages}</Collapsible.Panel>
</Collapsible.Root>;
```

### A row that opens a panel

```tsx
<Collapsible.Root open={expanded} onOpenChange={setExpanded}>
  <Row>
    <Row.Primary render={<Collapsible.Trigger variant="plain" />}>
      <Row.Leading>
        <Icon name={expanded ? "folder-open" : "folder"} size="sm" />
      </Row.Leading>
      <Row.Label>{name}</Row.Label>
    </Row.Primary>
  </Row>
  <Collapsible.Panel>{sessions}</Collapsible.Panel>
</Collapsible.Root>
```

### A preview that opens on press

```tsx
const [open, setOpen] = useState(false);

<Collapsible.Root open={open} onOpenChange={setOpen}>
  <Collapsible.Trigger>
    Working
    <Collapsible.Chevron />
  </Collapsible.Trigger>
  <Collapsible.Preview>{steps}</Collapsible.Preview>
</Collapsible.Root>;
```

## Props

`Root`, `Trigger`, and `Panel` preserve Base UI's `className` and `style` state callbacks.
`Preview` and `Chevron` take plain strings and `React.CSSProperties` objects instead.
See [Theming](/design/theming).

| Part                                  | Prop     | Type                             |
| ------------------------------------- | -------- | -------------------------------- |
| `Root`, `Trigger`, `Panel`, `Preview` | `xstyle` | `XStyle`                         |
| `Chevron`                             | `xstyle` | `Restyle<"Collapsible.Chevron">` |

### Trigger

| Prop      | Type                      | Default        | Description                           |
| --------- | ------------------------- | -------------- | ------------------------------------- |
| `variant` | `"disclosure" \| "plain"` | `"disclosure"` | Full-width disclosure or bare button. |

### Panel

| Prop               | Type      | Default | Description                                                                      |
| ------------------ | --------- | ------- | -------------------------------------------------------------------------------- |
| `hiddenUntilFound` | `boolean` | `true`  | Keeps closed content searchable in supporting browsers. Overrides `keepMounted`. |

### Chevron

Takes native `<span>` props.

| Prop   | Type        | Default |
| ------ | ----------- | ------- |
| `size` | `GlyphSize` | `"2xs"` |

### Preview

Renders a `<div>` and takes every `<div>` prop.

## Accessibility

- Enter and Space toggle the panel.

- Rendering the trigger as something other than a `<button>` needs `nativeButton={false}`.
- `disclosure` draws a focus ring. With `plain`, the rendered part owns focus styling.
- Keep a keyboard-accessible trigger alongside the preview.
