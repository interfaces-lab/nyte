```ts title="Import"
import { Message, MessageContent } from "@nyte-ai/ui/message";
```

Parts for message content and metadata.

## Usage

- Use plain `className` and `style` values, not `xstyle`. Parts have no default layout.
- `align` only sets `data-align`.

## Anatomy

| Part             | Element | Parent                           |
| ---------------- | ------- | -------------------------------- |
| `MessageGroup`   | `div`   | Optional group                   |
| `Message`        | `div`   | `MessageGroup` or your container |
| `MessageAvatar`  | `div`   | `Message`                        |
| `MessageContent` | `div`   | `Message`                        |
| `MessageHeader`  | `div`   | `MessageContent`                 |
| `MessageFooter`  | `div`   | `MessageContent`                 |

## Examples

```tsx
<Message align="end">
  <MessageContent>Can you inspect this file?</MessageContent>
</Message>
```

## Props

Parts take native props and refs and set a matching `data-slot`.

| Part      | Prop        | Type                  | Default   |
| --------- | ----------- | --------------------- | --------- |
| All       | `className` | `string`              | None      |
| All       | `style`     | `React.CSSProperties` | None      |
| `Message` | `align`     | `"start" \| "end"`    | `"start"` |

## Accessibility

Message parts add no role, label or live region.
