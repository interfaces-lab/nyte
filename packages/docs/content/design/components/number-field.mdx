title: Number field
description: "A compact stepper with decrement and increment buttons"
---

```ts title="Import"
import {
  NumberField,
  NumberFieldDecrement,
  NumberFieldGroup,
  NumberFieldIncrement,
  NumberFieldInput,
} from "@nyte-ai/ui/number-field";
```

For a small bounded value, such as a font size.

## Usage

- Both value callbacks can receive `null` for an empty input.
- Save in `onValueCommitted`, not on every keystroke.
- The buttons default to "−" and "+". Pass children to replace them.

## Anatomy

```tsx
<NumberField>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

  <NumberFieldDemo />

```tsx
<NumberField defaultValue={13} min={12} max={16}>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput aria-label="UI font size" />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

```tsx
<NumberField
  defaultValue={settings.uiFontSize}
  min={12}
  max={16}
  onValueCommitted={(uiFontSize) => {
    if (uiFontSize !== null) save({ uiFontSize });
  }}
>
  …
</NumberField>
```
