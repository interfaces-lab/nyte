```ts title="Import"
import { Tabs } from "@nyte-ai/ui/tabs";
```

A row of tabs with one panel visible at a time. Without panels, the list is a switcher whose
`onValueChange` drives your own view.

## Usage

- Set `variant` on the root to style the list and tabs.
- Match each `Tabs.Tab` and `Tabs.Panel` by `value`.
- `value` with `onValueChange` controls the root. `value={null}` leaves no tab active.
- Pass `keepMounted` to preserve an inactive panel in the DOM. Preserve its `hidden` behavior
  when adding styles.
- `Tabs.Root` and `Tabs.Panel` bring no look of their own. Lay them out with `xstyle`.
- Give `Tabs.Indicator` a class for its fill. Its `xstyle` only allows placement.

## Anatomy

```tsx
<Tabs.Root>
  <Tabs.List>
    <Tabs.Tab value="overview">Overview</Tabs.Tab>
    <Tabs.Indicator />
  </Tabs.List>
  <Tabs.Panel value="overview" />
</Tabs.Root>
```

## Props

Every part preserves Base UI's `className` and `style` state callbacks. See [Theming](/design/theming).

| Part            | Prop     | Type                                                    |
| --------------- | -------- | ------------------------------------------------------- |
| `Root`, `Panel` | `xstyle` | `XStyle`                                                |
| `List`          | `xstyle` | `Restyle<"Tabs.List">`                                  |
| `Tab`           | `xstyle` | `Restyle<"Tabs.Tab">` or `XStyle` with `variant="bare"` |
| `Indicator`     | `xstyle` | `Restyle<"Tabs.Indicator">`                             |

| Part   | Prop              | Type                                              | Default                                   | Description                                                               |
| ------ | ----------------- | ------------------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------- |
| `Root` | `variant`         | `"plain" \| "segmented" \| "underline" \| "pill"` | `"plain"`                                 |                                                                           |
| `List` | `activateOnFocus` | `boolean`                                         | `true` for `segmented`, otherwise `false` |                                                                           |
| `Tab`  | `variant`         | `"bare"`                                          |                                           | Removes tab appearance, not target sizing, disabled state, or focus ring. |

## Accessibility

- Label `Tabs.List` with `aria-label` or `aria-labelledby`.
- Arrow keys move focus along the list. Set `loopFocus={false}` on `Tabs.List` to stop focus wrapping.
- Enter and Space activate the focused tab. With `activateOnFocus`, focus activates it. `segmented`
  turns `activateOnFocus` on by default.
- A disabled first tab is skipped. Server rendering cannot skip it, so set `defaultValue` or `value`
  to an enabled tab.
