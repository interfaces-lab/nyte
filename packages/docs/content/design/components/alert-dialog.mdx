```ts title="Import"
import { AlertDialog, ConfirmDialog } from "@nyte-ai/ui/alert-dialog";
```

A [Dialog](/design/dialog) with alert semantics. `ConfirmDialog` is a prebuilt destructive
confirmation.

## Usage

- Start with `ConfirmDialog`. Use the parts for other content or actions.
- Include a Cancel `AlertDialog.Close`.
- Title and `confirmLabel` name the same action and noun.
- Put the destructive action last with `variant="solid" tone="danger"`.

## Anatomy

```tsx
<AlertDialog.Root>
  <AlertDialog.Trigger />
  <AlertDialog.Popup>
    <AlertDialog.Header>
      <AlertDialog.Title />
      <AlertDialog.Description />
    </AlertDialog.Header>
    <AlertDialog.Footer>
      <AlertDialog.Close /> {/* cancel */}
      <AlertDialog.Close /> {/* confirm */}
    </AlertDialog.Footer>
  </AlertDialog.Popup>
</AlertDialog.Root>
```

### Confirm dialog

```tsx
const [open, setOpen] = useState(false);

<Button variant="solid" tone="danger" onClick={() => setOpen(true)}>
  Delete chat
</Button>
<ConfirmDialog
  open={open}
  title="Delete chat" confirmLabel="Delete chat"
  description="This permanently deletes the chat and its entire history. You can't undo this."
  onOpenChange={setOpen}
  onConfirm={() => setOpen(false)}
/>
```

```tsx
<ConfirmDialog
  open={open}
  pending={signOut.isPending}
  error={signOut.isError ? "Sign-out failed. Try again." : undefined}
  finalFocus={signOutRef}
  title="Sign out"
  description="Other apps using this login are signed out too."
  confirmLabel="Sign out"
  pendingLabel="Signing out…"
  onOpenChange={setOpen}
  onConfirm={() => signOut.mutate(undefined, { onSuccess: () => setOpen(false) })}
/>
```

## Props

### ConfirmDialog

| Prop           | Type                                    | Default | Description                                               |
| -------------- | --------------------------------------- | ------- | --------------------------------------------------------- |
| `open`         | `boolean`                               |         | Required.                                                 |
| `title`        | `string`                                |         | Required accessible name.                                 |
| `description`  | `ReactNode`                             |         | Required consequence.                                     |
| `confirmLabel` | `string`                                |         | Required.                                                 |
| `pendingLabel` | `string`                                |         | Status announcement while pending.                        |
| `pending`      | `boolean`                               | `false` | Makes actions busy. Blocks closing.                       |
| `error`        | `string`                                |         | Announced as an alert.                                    |
| `finalFocus`   | As `AlertDialog.Popup`                  |         | Focus target on close.                                    |
| `onOpenChange` | `(open: boolean, eventDetails) => void` |         | Cancel or Escape requests closing. Ignored while pending. |
| `onConfirm`    | `() => void`                            |         | Danger-button handler. Close the dialog yourself.         |
| `tint`         | `Tint`                                  |         | Popup hue. Scrim stays neutral.                           |

### Parts

| Part                      | Renders              |
| ------------------------- | -------------------- |
| `AlertDialog.Trigger`     | `<button>`           |
| `AlertDialog.Popup`       | Portal, scrim, popup |
| `AlertDialog.Header`      | `<div>`              |
| `AlertDialog.Title`       | `<h2>`               |
| `AlertDialog.Description` | `<p>`                |
| `AlertDialog.Footer`      | `<div>`              |
| `AlertDialog.Close`       | `<button>`           |

Except `AlertDialog.Root`, each part takes `xstyle`, `className`, and `style`.
`className` and `style` accept state functions on Base UI parts, plain values on Header and Footer.
See [Theming](/design/theming).

## Accessibility

- Use `AlertDialog.Title` and `AlertDialog.Description` to name and describe the popup.
- To block Escape, call `details.cancel()` in `onOpenChange` when `details.reason` is `escape-key`.
- `initialFocus` and `finalFocus` override focus targets.
