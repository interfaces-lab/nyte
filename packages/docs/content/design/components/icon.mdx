```ts title="Import"
import { ControlGlyphs, Icon, IconSwap, PanelToggleIcon, SplitPreviewIcon } from "@nyte-ai/ui/icon";
```

Named glyphs.

## Usage

- Animate glyph changes with `IconSwap`.
- Wrap custom controls in `ControlGlyphs` for inherited color and full opacity.

## Examples

<Preview>
  <IconDemo />
</Preview>

```tsx
<Icon name="folder" />
<Icon name="warning" variant="filled" />
<Icon name="warning" size="sm" label="Warning" />
<Icon name="sparkle" size="xs" />
```

### Panel toggle

<Preview>
  <PanelToggleIconDemo />
</Preview>

```tsx
const [visible, setVisible] = useState(true);

<Button
  iconOnly
  aria-label={visible ? "Hide sidebar" : "Show sidebar"}
  onClick={() => setVisible(!visible)}
>
  <PanelToggleIcon side="left" visible={visible} />
</Button>;
```

### Split preview

The pane a split would open fills while the button holding the glyph is pointed at or focused.

<Preview>
  <SplitPreviewIconDemo />
</Preview>

```tsx
<Button iconOnly aria-label="Split Down">
  <SplitPreviewIcon side="down" />
</Button>
```

## Props

### Icon and IconSwap

| Prop        | Type                           | Default      | Description                                                  |
| ----------- | ------------------------------ | ------------ | ------------------------------------------------------------ |
| `name`      | `IconName` or `FilledIconName` | Required     | Use `FilledIconName` for filled icons, `IconName` otherwise. |
| `size`      | `GlyphSize`                    | `"md"`       |                                                              |
| `variant`   | `"outlined" \| "filled"`       | `"outlined"` |                                                              |
| `label`     | `string`                       |              | Announced as `role="img"`. Omit to hide.                     |
| `xstyle`    | `Restyle<"Icon">`              |              |                                                              |
| `className` | `string`                       |              |                                                              |
| `style`     | `React.CSSProperties`          |              |                                                              |

### ControlGlyphs

| Prop       | Type        | Default  |
| ---------- | ----------- | -------- |
| `children` | `ReactNode` | Required |

### PanelToggleIcon

| Prop      | Type                | Default |
| --------- | ------------------- | ------- |
| `side`    | `"left" \| "right"` |         |
| `visible` | `boolean`           |         |
| `size`    | `GlyphSize`         | `"md"`  |

### SplitPreviewIcon

| Prop   | Type                | Default |
| ------ | ------------------- | ------- |
| `side` | `"right" \| "down"` |         |
| `size` | `GlyphSize`         | `"md"`  |

### GlyphSize

| Step    | Size at the default UI size |
| ------- | --------------------------- |
| `"2xs"` | 10px                        |
| `"xs"`  | 12px                        |
| `"sm"`  | 14px                        |
| `"md"`  | 16px                        |
| `"lg"`  | 20px                        |
