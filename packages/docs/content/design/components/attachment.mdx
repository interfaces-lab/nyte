title: Attachment

```ts title="Import"
import { Attachment, AttachmentContent, AttachmentTitle } from "@nyte-ai/ui/attachment";
```

Your app handles uploads, previews and removal.

## Usage

- Style with `className` and `style`, not `xstyle`.
- For Trigger and Action, set `nativeButton={false}` when `render` produces a non-button element.

## Anatomy

| Part                    | Default element | Parent                              |
| ----------------------- | --------------- | ----------------------------------- |
| `AttachmentGroup`       | `div`           | Your container                      |
| `Attachment`            | `div`           | `AttachmentGroup` or your container |
| `AttachmentMedia`       | `div`           | `Attachment`                        |
| `AttachmentContent`     | `div`           | `Attachment`                        |
| `AttachmentTitle`       | `span`          | `AttachmentContent`                 |
| `AttachmentDescription` | `span`          | `AttachmentContent`                 |
| `AttachmentTrigger`     | `button`        | `Attachment`                        |
| `AttachmentActions`     | `div`           | `Attachment`                        |
| `AttachmentAction`      | Base UI button  | `AttachmentActions`                 |

## Examples

```tsx
<Attachment state="done">
  <AttachmentContent>
    <AttachmentTitle>report.pdf</AttachmentTitle>
  </AttachmentContent>
</Attachment>
```

## Props

Parts take native props and refs.

| Part               | Prop          | Type                                                                                         | Default        | Description                 |
| ------------------ | ------------- | -------------------------------------------------------------------------------------------- | -------------- | --------------------------- |
| `Attachment`       | `state`       | `"idle" \| "uploading" \| "processing" \| "error" \| "done"`                                 | `"done"`       | Sets `data-state`.          |
| `Attachment`       | `size`        | `"default" \| "sm" \| "xs" \| null`                                                          | `"default"`    |                             |
| `Attachment`       | `orientation` | `"horizontal" \| "vertical" \| null`                                                         | `"horizontal"` |                             |
| `AttachmentMedia`  | `variant`     | `"icon" \| "image" \| null`                                                                  | `"icon"`       |                             |
| `AttachmentAction` | `variant`     | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link" \| null`        | `"ghost"`      | `null` uses ghost styling.  |
| `AttachmentAction` | `size`        | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg" \| null` | `"icon-xs"`    | `null` uses default sizing. |

Only Trigger and Action accept `className` and `style` callbacks receiving `{ disabled: boolean }`.

Trigger and Action take Base UI button props.

## Accessibility

Name the preview and icon-only action buttons, and give images alt text. Upload and error states are not announced.
