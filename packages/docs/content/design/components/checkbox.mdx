```ts title="Import"
import { Checkbox, CheckboxField } from "@nyte-ai/ui/checkbox";
```

For settings that apply on change, use [Switch](/design/switch).

## Usage

- Use `indeterminate` for a partly ticked list.

## Anatomy

`CheckboxField` contains `Checkbox`, label text, and an optional description. The indicator is built in. Do not pass children.

## Examples

```tsx
const [archived, setArchived] = useState(false);

<label>
  <Checkbox checked={archived} onCheckedChange={setArchived} />
  Show archived chats
</label>;
```

```tsx
const [viewed, setViewed] = useState<readonly string[]>(["row.tsx"]);

<>
  <label>
    <Checkbox
      checked={viewed.length === files.length}
      indeterminate={viewed.length > 0 && viewed.length < files.length}
      onCheckedChange={(checked) => setViewed(checked ? files : [])}
    />
    All files viewed
  </label>
  {files.map((file) => (
    <label key={file}>
      <Checkbox
        checked={viewed.includes(file)}
        onCheckedChange={(checked) =>
          setViewed((current) =>
            checked ? [...current, file] : current.filter((path) => path !== file),
          )
        }
      />
      {file}
    </label>
  ))}
</>;
```

### Field

```tsx
const [archived, setArchived] = useState(false);

<CheckboxField
  label="Show archived chats"
  description="Archived chats appear below the active ones"
  checked={archived}
  onCheckedChange={setArchived}
/>;
```

## Props

### Checkbox

Takes Base UI `Checkbox.Root` props except `children`. `className` and `style` accept values or checkbox-state functions.

| Prop                           | Type                           | Default | Description             |
| ------------------------------ | ------------------------------ | ------- | ----------------------- |
| `attention`                    | `boolean`                      | `false` | Warning border and dot. |
| `size`                         | `"md" \| "lg"`                 | `"md"`  |                         |
| `className`, `style`, `xstyle` | see [Theming](/design/theming) |         |                         |

### CheckboxField

Takes `Checkbox` props except `aria-label`, `aria-labelledby`, and `nativeButton`.
`className`, `style`, and `xstyle` style the row. Callbacks receive Base UI `Field.Root` state.

| Prop                           | Type                           | Description      |
| ------------------------------ | ------------------------------ | ---------------- |
| `label`                        | `string`                       | Required.        |
| `description`                  | `string`                       | Below the label. |
| `className`, `style`, `xstyle` | see [Theming](/design/theming) |                  |

## Accessibility

`CheckboxField` connects `label` through `aria-labelledby` and `description` through `aria-describedby`.
