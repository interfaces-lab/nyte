```ts title="Import"
import { Spinner } from "@nyte-ai/ui/spinner";
```

## Usage

- `Spinner` means AI is working: a running chat, turn, subagent, or tool call. Any other loading
  shows a [Loader](/design/loader).
- The spinner fills a 16px glyph slot and takes the text color of its parent.
- Under reduced motion it holds one phase.

## Accessibility

- The spinner is `aria-hidden`. Announce the running state with nearby text or `aria-busy` on the
  region.
