```ts title="Import"
import { Spinner } from "@nyte-ai/ui/spinner";
```

A dithered moon for a running chat, turn, subagent, or tool call. It inherits text color in a 16px glyph slot.

## Usage

- Use `Spinner` for AI work and [Loader](/design/loader) for other loading.

## Props

| Prop        | Type                  |
| ----------- | --------------------- |
| `xstyle`    | `Restyle<"Spinner">`  |
| `className` | `string`              |
| `style`     | `React.CSSProperties` |

## Accessibility

- The spinner is `aria-hidden`. Announce the running state with nearby text or `aria-busy` on the
  region.
