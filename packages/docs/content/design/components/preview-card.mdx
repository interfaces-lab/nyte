A card with more about its trigger. For one line, use [Tooltip](/design/tooltip).

## Usage

- Keep essential content available without the card.
- Give a list of triggers one card through a handle. A root per item opens a card per item, and they stack while the pointer crosses the list.

## Anatomy

```tsx
<PreviewCard>
  <PreviewCardTrigger />
  <PreviewCardContent />
</PreviewCard>
```

```tsx
import { Button } from "@nyte-ai/ui/button";
import { Icon } from "@nyte-ai/ui/icon";
import { PreviewCard, PreviewCardContent, PreviewCardTrigger } from "@nyte-ai/ui/preview-card";
import { glyph } from "@nyte-ai/ui/styles/schema.stylex";
import { role, type } from "@nyte-ai/ui/styles/vars.stylex";
import { create, props } from "@stylexjs/stylex";

const styles = create({
  title: { fontWeight: 500 },
  detail: {
    display: "grid",
    gridTemplateColumns: `${glyph.sm} minmax(0, 1fr)`,
    alignItems: "center",
    gap: 6,
    marginBlockStart: 6,
    color: role.contentSecondary,
    fontSize: type.fontSm,
    lineHeight: type.leadingSm,
  },
  detailIcon: { display: "grid", placeItems: "center", color: role.contentTertiary },
});

<PreviewCard>
  <PreviewCardTrigger render={<Button variant="outline">Fix flaky tests</Button>} />
  <PreviewCardContent side="right" align="start" aria-label="Details for Fix flaky tests">
    <span {...props(styles.title)}>Fix flaky tests</span>
    <span {...props(styles.detail)}>
      <span {...props(styles.detailIcon)}>
        <Icon name="git-branch" size="sm" />
      </span>
      <span>nyte-ai/nyte</span>
    </span>
    <span {...props(styles.detail)}>
      <span {...props(styles.detailIcon)}>
        <Icon name="folder" size="sm" />
      </span>
      <span>~/Developer/nyte</span>
    </span>
  </PreviewCardContent>
</PreviewCard>;
```

### One card for a list

```tsx
import {
  createPreviewCardHandle,
  PreviewCard,
  PreviewCardContent,
  PreviewCardTrigger,
} from "@nyte-ai/ui/preview-card";
import { useState } from "react";

const [handle] = useState(createPreviewCardHandle<string>);

<>
  {chats.map((chat) => (
    <PreviewCardTrigger key={chat} handle={handle} payload={chat} render={<Row />} />
  ))}
  <PreviewCard handle={handle}>
    {({ payload }) => <PreviewCardContent side="right">{payload}</PreviewCardContent>}
  </PreviewCard>
</>;
```

### Controlled

```tsx
import { PreviewCard, PreviewCardContent, PreviewCardTrigger } from "@nyte-ai/ui/preview-card";
import { useState } from "react";

const [open, setOpen] = useState(false);

<PreviewCard open={open} onOpenChange={setOpen}>
  <PreviewCardTrigger href="https://nyte.sh">Nyte</PreviewCardTrigger>
  <PreviewCardContent>More about Nyte</PreviewCardContent>
</PreviewCard>;
```

## Props

`PreviewCardContent` takes `xstyle`, `className`, and `style`. Its `className` and `style` accept
plain values or functions of popup state. See [Theming](/design/theming).

`PreviewCard` and `PreviewCardTrigger` pass through Base UI unstyled. `createPreviewCardHandle` is Base UI's `PreviewCard.createHandle`.

### PreviewCardContent

Only the positioning props in this table are accepted. `ref`, `className`, and `style` target the popup.

| Prop                 | Type                                                                                                           | Default                       |
| -------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| `side`               | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"`                                     | `"bottom"`                    |
| `align`              | `"start" \| "center" \| "end"`                                                                                 | `"center"`                    |
| `sideOffset`         | `number \| OffsetFunction`                                                                                     | `4`                           |
| `alignOffset`        | `number \| OffsetFunction`                                                                                     | `0`                           |
| `anchor`             | `Element \| VirtualElement \| RefObject<Element \| null> \| (() => Element \| VirtualElement \| null) \| null` | the trigger                   |
| `collisionAvoidance` | `CollisionAvoidance`                                                                                           | `{ fallbackAxisSide: "end" }` |
| `tint`               | `Tint`                                                                                                         |                               |
