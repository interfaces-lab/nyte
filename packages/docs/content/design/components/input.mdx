```ts title="Import"
import { Input, InputGroup } from "@nyte-ai/ui/input";
```

`InputGroup` frames an `Input` with the icons or controls beside it. For multi-line text, use
[Textarea](/design/textarea).

## Usage

- Inside `InputGroup`, set `size` and `variant` on the group.

## Anatomy

```tsx
<InputGroup>
  <Icon name="search" size="xs" />
  <Input />
</InputGroup>
```


### Controlled

```tsx
const [query, setQuery] = useState("");

<Input aria-label="Search" value={query} onValueChange={setQuery} />;
```

## Props

### Input

Takes Base UI `Input` props except native `size`. `className` and `style` accept values or input-state functions.

| Prop                           | Type                                      | Default                             |
| ------------------------------ | ----------------------------------------- | ----------------------------------- |
| `variant`                      | `"raised" \| "quiet" \| "code" \| "bare"` | `"raised"`, `"bare"` inside a group |
| `size`                         | `"md" \| "lg" \| "xl"`                    | `"md"`, or the group's size         |
| `className`, `style`, `xstyle` | see [Theming](/design/theming)            |                                     |

### InputGroup

Takes native `<label>` attributes. `className` and `style` accept plain values only.

| Prop                           | Type                           | Default    | Description             |
| ------------------------------ | ------------------------------ | ---------- | ----------------------- |
| `variant`                      | `"raised" \| "quiet"`          | `"raised"` |                         |
| `size`                         | `"md" \| "lg" \| "xl"`         | `"md"`     | Group and input height. |
| `className`, `style`, `xstyle` | see [Theming](/design/theming) |            |                         |

## Accessibility

- `InputGroup` renders a `<label>`. The input's `aria-label` overrides it.
- Supply a focus indicator for `variant="bare"` outside `InputGroup`.
