```ts title="Import"
import { Menu, MenuContent, MenuItem, MenuSeparator, MenuTrigger } from "@nyte-ai/ui/menu";
```

Actions opened from a button. For a control showing the current choice, use [Select](/design/select).

## Usage

- `MenuItem` and `MenuRadioItem` close on click. `MenuCheckboxItem` and `MenuSwitchItem` stay open.
  `closeOnClick` changes either.
- For a searchable palette under a scrim, use [Command](/design/command).
- To search a menu, wrap `Menu` in `MenuFilterProvider`, put `MenuInput` in the popup, and put the
  items in `MenuList`. The input keeps focus while the arrow keys move the highlight.

## Anatomy

```tsx
<Menu>
  <MenuTrigger />
  <MenuContent>
    <MenuGroup>
      <MenuGroupLabel />
      <MenuItem />
      <MenuLinkItem />
      <MenuCheckboxItem />
      <MenuSwitchItem />
    </MenuGroup>
    <MenuSeparator />
    <MenuRadioGroup>
      <MenuRadioItem value="choice" />
    </MenuRadioGroup>
    <MenuSub>
      <MenuSubTrigger />
      <MenuSubContent>
        <MenuItem />
      </MenuSubContent>
    </MenuSub>
  </MenuContent>
</Menu>
```

A searchable menu adds three parts:

```tsx
<MenuFilterProvider>
  <Menu>
    <MenuTrigger />
    <MenuContent>
      <MenuInput aria-label="Search" />
      <MenuList>
        <MenuItem />
      </MenuList>
    </MenuContent>
  </Menu>
</MenuFilterProvider>
```

## Examples

<Preview>
  <MenuDemo />
</Preview>

```tsx
import { Button } from "@nyte-ai/ui/button";
import {
  Menu,
  MenuContent,
  MenuGroup,
  MenuGroupLabel,
  MenuItem,
  MenuRadioGroup,
  MenuRadioItem,
  MenuSeparator,
  MenuSub,
  MenuSubContent,
  MenuSubTrigger,
  MenuSwitchItem,
  MenuTrigger,
} from "@nyte-ai/ui/menu";
import { useState } from "react";

function SessionMenu() {
  const [effort, setEffort] = useState("medium");
  const [pinned, setPinned] = useState(false);

  return (
    <Menu>
      <MenuTrigger render={<Button variant="outline">Session</Button>} />
      <MenuContent>
        <MenuGroup>
          <MenuGroupLabel>Session</MenuGroupLabel>
          <MenuItem icon="pencil" meta="⌘R" onClick={() => {}}>
            Rename
          </MenuItem>
          <MenuItem icon="copy" onClick={() => {}}>
            Duplicate
          </MenuItem>
          <MenuItem icon="archive" disabled>
            Archive
          </MenuItem>
          <MenuSwitchItem icon="pin" checked={pinned} onCheckedChange={setPinned}>
            Pinned
          </MenuSwitchItem>
        </MenuGroup>
        <MenuSeparator />
        <MenuSub>
          <MenuSubTrigger icon="bolt" value={effort}>
            Effort
          </MenuSubTrigger>
          <MenuSubContent>
            <MenuRadioGroup value={effort} onValueChange={setEffort}>
              <MenuRadioItem value="low">low</MenuRadioItem>
              <MenuRadioItem value="medium">medium</MenuRadioItem>
              <MenuRadioItem value="high">high</MenuRadioItem>
            </MenuRadioGroup>
          </MenuSubContent>
        </MenuSub>
        <MenuSeparator />
        <MenuItem icon="trash" variant="danger" onClick={() => {}}>
          Delete
        </MenuItem>
      </MenuContent>
    </Menu>
  );
}
```

## Props

The styled popup and row parts take `xstyle`, `className`, and `style`. `className` and `style`
accept plain values or functions of the underlying Base UI part's state. See [Theming](/design/theming).

`Menu`, `MenuTrigger`, `MenuRadioGroup`, `MenuGroup`, `MenuSub`, and `MenuFilterProvider`
pass through Base UI unstyled.

The reference tables below come from Base UI, MIT, © Material-UI SAS.

### MenuContent

Only the positioning props in this table are accepted. `ref`, `className`, and `style` target the popup.

| Prop                 | Type                                                                                                           | Default                                                      |
| -------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `side`               | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"`                                     | `"bottom"`                                                   |
| `align`              | `"start" \| "center" \| "end"`                                                                                 | `"start"`                                                    |
| `sideOffset`         | `number \| OffsetFunction`                                                                                     | `4`                                                          |
| `alignOffset`        | `number \| OffsetFunction`                                                                                     | `0`                                                          |
| `anchor`             | `Element \| VirtualElement \| RefObject<Element \| null> \| (() => Element \| VirtualElement \| null) \| null` | the trigger                                                  |
| `collisionAvoidance` | `CollisionAvoidance`                                                                                           | `{ side: "flip", align: "shift", fallbackAxisSide: "none" }` |
| `collisionPadding`   | `number \| Padding`                                                                                            | `8`                                                          |
| `tint`               | `Tint`                                                                                                         |                                                              |
| `matchAnchorWidth`   | `boolean`                                                                                                      | `false`                                                      |
| `footer`             | `ReactNode`                                                                                                    |                                                              |

`footer` stays below the scrollable body, after a separator.

### MenuSubContent

Takes `MenuContent` props except `matchAnchorWidth` and `footer`. Defaults to `side="inline-end"`,
`align="start"`, and `collisionAvoidance={{ fallbackAxisSide: "end" }}`.

| Prop          | Default                           |
| ------------- | --------------------------------- |
| `sideOffset`  | `6`                               |
| `alignOffset` | `0` when centered, otherwise `-4` |

## Accessibility

- Give the popup `aria-label` when the trigger text does not name it.
- Put the action in the row label. Icons, switches, and checkmarks are hidden from assistive technology.
