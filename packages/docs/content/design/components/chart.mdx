```ts title="Import"
import { BarChart, Sparkline } from "@nyte-ai/ui/chart";
import type { ChartSeries, ChartBucket } from "@nyte-ai/ui/chart";
```

`BarChart` compares stacked values across buckets. Use `Sparkline` for a row's trend, with its numbers in nearby text.

## Usage

- Give series and buckets stable `key` values. Match bucket `values` to `series` order using nonnegative, finite numbers. Missing entries render as zero.
- `BarChart` fills its container's width. Allow 20px below `height` for labels.
- Pass `format` for readout values and totals.
- Use an integer of at least `2` for `ticks`.
- Give `Sparkline` nonnegative, finite values. Each scales independently, so line heights are not comparable.

## Anatomy

| Component   | Element                  | Parent         |
| ----------- | ------------------------ | -------------- |
| `BarChart`  | `div` containing an SVG  | Your container |
| `Sparkline` | `span` containing an SVG | Your container |

## Examples

### Stacked bars

```tsx
const series = [
  { key: "input", label: "Input", tint: "blue" },
  { key: "output", label: "Output", tint: "purple" },
] satisfies readonly ChartSeries[];

const buckets = [
  { key: "mon", label: "Mon", values: [1200, 400] },
  { key: "tue", label: "Tue", values: [1800, 600] },
  { key: "wed", label: "Wed", values: [900, 300] },
] satisfies readonly ChartBucket[];

<BarChart
  label="Daily token usage, Monday to Wednesday"
  series={series}
  buckets={buckets}
  format={(value) => `${value.toLocaleString()} tokens`}
  ticks={3}
/>;
```

### A row's trend

```tsx
<div>
  <span>Requests this week: 42</span>
  <Sparkline values={[2, 8, 4, 6, 10, 5, 7]} tint="blue" />
</div>
```

### A named sparkline

```tsx
<Sparkline
  values={[2, 8, 4, 6, 10, 5, 7]}
  label="Daily requests this week, peaking at 10"
  width={96}
  height={24}
/>
```

## Props

### BarChart

| Prop        | Type                        | Default  | Description                          |
| ----------- | --------------------------- | -------- | ------------------------------------ |
| `label`     | `string`                    | Required | Accessible name.                     |
| `series`    | `readonly ChartSeries[]`    | Required | Bottom-to-top layers.                |
| `buckets`   | `readonly ChartBucket[]`    | Required | Left-to-right bars.                  |
| `format`    | `(value: number) => string` | Required | Readout values and total.            |
| `height`    | `number`                    | `88`     | Pixels, excluding labels.            |
| `ticks`     | `number`                    | `5`      | Label count, capped at bucket count. |
| `xstyle`    | `Restyle<"BarChart">`       | None     | Container placement and width.       |
| `className` | `string`                    |          |                                      |
| `style`     | `React.CSSProperties`       |          |                                      |

### ChartSeries

| Field   | Type     | Description             |
| ------- | -------- | ----------------------- |
| `key`   | `string` | Readout identity.       |
| `label` | `string` | Readout name.           |
| `tint`  | `Tint`   | Layer and swatch color. |

### ChartBucket

| Field    | Type                | Description                      |
| -------- | ------------------- | -------------------------------- |
| `key`    | `string`            | Caller identity, not plot order. |
| `label`  | `string`            | Readout and plot label.          |
| `values` | `readonly number[]` | Series-order values.             |

### Sparkline

| Prop        | Type                   | Default  | Description                           |
| ----------- | ---------------------- | -------- | ------------------------------------- |
| `values`    | `readonly number[]`    | Required | Left-to-right points.                 |
| `tint`      | `Tint`                 |          | Overrides secondary content color.    |
| `label`     | `string`               |          | Accessible name. Omit for decoration. |
| `width`     | `number`               | `72`     | Pixels.                               |
| `height`    | `number`               | `20`     | Pixels.                               |
| `xstyle`    | `Restyle<"Sparkline">` | None     | Wrapper placement and width.          |
| `className` | `string`               |          |                                       |
| `style`     | `React.CSSProperties`  |          |                                       |

`Tint` accepts `"gray"`, `"brown"`, `"orange"`, `"yellow"`, `"green"`, `"blue"`, `"purple"`,
`"pink"`, `"red"`, `"teal"`, and `"custom"`. See [Theming](/design/theming)
for `xstyle`, `className`, and `style`. `className` and `style` take plain values. Neither component forwards arbitrary native props or refs.

## Accessibility

The bar readout is pointer-only. Repeat figures in nearby text or a table. Give sparklines a `label` unless decorative.
