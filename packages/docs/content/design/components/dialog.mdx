```ts title="Import"
import { Dialog } from "@nyte-ai/ui/dialog";
```

A cancellable modal that takes focus. For a required response, use
[Alert dialog](/design/alert-dialog).

## Usage

- Name the dialog with `Dialog.Title`. To hide it, apply `srOnly` from [Focus](/design/focus)
  to a native wrapper, not the title.
- Include a `Dialog.Close` inside modal popups so touch screen readers can leave them.

## Anatomy

```tsx
<Dialog.Root>
  <Dialog.Trigger />
  <Dialog.Popup>
    <Dialog.Header>
      <Dialog.Title />
      <Dialog.Description />
    </Dialog.Header>
    …
    <Dialog.Footer>
      <Dialog.Close />
    </Dialog.Footer>
  </Dialog.Popup>
</Dialog.Root>
```

```tsx
<Dialog.Root>
  <Dialog.Trigger render={<Button variant="outline">Rename Session</Button>} />
  <Dialog.Popup>
    <Dialog.Header>
      <Dialog.Title>Rename Session</Dialog.Title>
      <Dialog.Description>
        The name shows in the sidebar and in the window title.
      </Dialog.Description>
    </Dialog.Header>
    <Dialog.Footer>
      <Dialog.Close render={<Button variant="outline">Cancel</Button>} />
      <Dialog.Close
        render={
          <Button variant="solid" tone="primary">
            Save
          </Button>
        }
      />
    </Dialog.Footer>
  </Dialog.Popup>
</Dialog.Root>
```

```tsx
const [open, setOpen] = useState(false);

<Dialog.Root open={open} onOpenChange={setOpen}>
  <Dialog.Popup>
    <Dialog.Title>Rename Session</Dialog.Title>
    <form
      onSubmit={async (event) => {
        event.preventDefault();
        await save();
        setOpen(false);
      }}
    >
      …
    </form>
    <Dialog.Close>Cancel</Dialog.Close>
  </Dialog.Popup>
</Dialog.Root>;
```

Inside `Dialog.Root`.

```tsx
import { Dialog } from "@nyte-ai/ui/dialog";
import { srOnly } from "@nyte-ai/ui/styles/a11y.stylex";
import { create, props } from "@stylexjs/stylex";

const styles = create({
  popup: { gap: 0, width: "min(610px, calc(100vw - 48px))", padding: 0 },
});

<Dialog.Popup xstyle={styles.popup}>
  <div {...props(srOnly)}>
    <Dialog.Title>Search</Dialog.Title>
  </div>
  …<Dialog.Close>Close</Dialog.Close>
</Dialog.Popup>;
```

## Props

| Part                 | Renders              |
| -------------------- | -------------------- |
| `Dialog.Trigger`     | `<button>`           |
| `Dialog.Popup`       | Portal, scrim, popup |
| `Dialog.Header`      | `<div>`              |
| `Dialog.Title`       | `<h2>`               |
| `Dialog.Description` | `<p>`                |
| `Dialog.Footer`      | `<div>`              |
| `Dialog.Close`       | `<button>`           |

Except `Dialog.Root`, each part takes `xstyle`, `className`, and `style`.
`className` and `style` accept state functions on Base UI parts, plain values on Header and Footer.
See [Theming](/design/theming).

## Accessibility

- `Dialog.Description` describes the popup.
- `initialFocus` and `finalFocus` override focus targets.
