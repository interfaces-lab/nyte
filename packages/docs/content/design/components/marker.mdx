```ts title="Import"
import { Marker, MarkerContent } from "@nyte-ai/ui/marker";
```

A transcript row for a status, boundary or annotation.

## Usage

- Use plain `className` and `style` values, not `xstyle`. `variant` adds classes but draws no lines or borders.
- With `render`, put element-specific props such as `href` on the rendered element.

Spread `render` callback props onto your element.

## Anatomy

| Part            | Default element | Parent         |
| --------------- | --------------- | -------------- |
| `Marker`        | `div`           | Your container |
| `MarkerIcon`    | `span`          | `Marker`       |
| `MarkerContent` | `span`          | `Marker`       |

## Examples

```tsx
<Marker role="status">
  <MarkerContent>Waiting for input</MarkerContent>
</Marker>
```

## Props

Parts take native props and refs.

| Part         | Prop          | Type                                           | Default     |
| ------------ | ------------- | ---------------------------------------------- | ----------- |
| All          | `className`   | `string`                                       | None        |
| All          | `style`       | `React.CSSProperties`                          | None        |
| `Marker`     | `variant`     | `"default" \| "separator" \| "border" \| null` | `"default"` |
| `Marker`     | `render`      | `ReactElement \| render callback`              | `div`       |
| `MarkerIcon` | `aria-hidden` | `boolean \| "true" \| "false"`                 | `"true"`    |

A `null` variant omits its class and attribute.

`markerVariants({ variant, className })` returns the marker classes plus yours.

## Accessibility

Use `role="status"` or `role="alert"` for announcements. Avoid `role="separator"` on labeled boundaries to preserve text semantics.
