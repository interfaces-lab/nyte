```ts title="Import"
import { Bubble, BubbleContent } from "@nyte-ai/ui/bubble";
```

A container for message content and reactions.

## Usage

- Use plain `className` and `style` values, not `xstyle`.
- With `render`, `BubbleContent` props and refs stay typed for a `div`.

Spread `render` callback props onto your element.

## Anatomy

| Part              | Default element | Parent                          |
| ----------------- | --------------- | ------------------------------- |
| `BubbleGroup`     | `div`           | Optional group                  |
| `Bubble`          | `div`           | `BubbleGroup` or your container |
| `BubbleContent`   | `div`           | `Bubble`                        |
| `BubbleReactions` | `div`           | `Bubble`                        |

## Examples

```tsx
<Bubble align="end">
  <BubbleContent>Inspect the latest change.</BubbleContent>
</Bubble>
```

```tsx
<BubbleContent render={<button type="button" />}>Edit message</BubbleContent>
```

## Props

Parts take native props and refs.

| Part              | Prop        | Type                                                                                               | Default     |
| ----------------- | ----------- | -------------------------------------------------------------------------------------------------- | ----------- |
| All               | `className` | `string`                                                                                           | None        |
| All               | `style`     | `React.CSSProperties`                                                                              | None        |
| `Bubble`          | `variant`   | `"default" \| "secondary" \| "muted" \| "tinted" \| "outline" \| "ghost" \| "destructive" \| null` | `"default"` |
| `Bubble`          | `align`     | `"start" \| "end"`                                                                                 | `"start"`   |
| `BubbleContent`   | `render`    | `ReactElement \| render callback`                                                                  | `div`       |
| `BubbleReactions` | `side`      | `"top" \| "bottom"`                                                                                | `"bottom"`  |
| `BubbleReactions` | `align`     | `"start" \| "end"`                                                                                 | `"end"`     |

A `null` variant omits its class and attribute.

## Accessibility

Bubble parts add no role or focus styles. Give reaction controls accessible names.
