```ts title="Import"
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@nyte-ai/ui/tooltip";
```

A visible label and optional shortcut for a control with an accessible name. For longer content,
use [Preview card](/design/preview-card).

## Usage

- Pass the control to `TooltipTrigger` through `render`. Name icon-only controls with `aria-label`;
  visible text names text-labeled controls. The tooltip does not supply the accessible name.
- An icon-only [Button](/design/button) also sets its label as the native `title`. Pass
  `title={undefined}` so only one tooltip appears.
- Pass `shortcut` as one string per key, not label text.
- Wrap the app once in `TooltipProvider`. A trigger's own `delay` or `closeDelay` overrides it.
- Keep instructions and disabled reasons visible outside the tooltip.

## Anatomy

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger />
    <TooltipContent />
  </Tooltip>
</TooltipProvider>
```

```tsx
import { Button } from "@nyte-ai/ui/button";
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@nyte-ai/ui/tooltip";

<TooltipProvider>
  <Tooltip>
    <TooltipTrigger
      render={<Button iconOnly icon="copy" aria-label="Copy output" title={undefined} />}
    />
    <TooltipContent>Copy output</TooltipContent>
  </Tooltip>
  <Tooltip>
    <TooltipTrigger
      render={<Button iconOnly icon="trash" aria-label="Delete session" title={undefined} />}
    />
    <TooltipContent shortcut={["⌘", "⌫"]}>Delete session</TooltipContent>
  </Tooltip>
</TooltipProvider>;
```

## Props

`TooltipContent` takes `xstyle`, `className`, and `style`. Its `className` and `style` accept
plain values or functions of popup state. See [Theming](/design/theming).

The reference tables below come from Base UI, MIT, © Material-UI SAS.

### Tooltip

`Tooltip` passes through Base UI's root unstyled. No handle factory is exported.

### TooltipTrigger

Unstyled, without `xstyle`. Clears `title`. `className` and `style` accept state functions.

<include>../../base-ui-reference/tooltip/Trigger.md</include>

### TooltipContent

Only the positioning props in this table are accepted. `ref`, `className`, and `style` target the popup.

| Prop          | Type                                                                       | Default    |
| ------------- | -------------------------------------------------------------------------- | ---------- |
| `side`        | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"` | `"bottom"` |
| `align`       | `"start" \| "center" \| "end"`                                             | `"center"` |
| `sideOffset`  | `number \| OffsetFunction`                                                 | `6`        |
| `alignOffset` | `number \| OffsetFunction`                                                 | `0`        |
| `tint`        | `Tint`                                                                     |            |
| `shortcut`    | `readonly string[]`                                                        | `[]`       |

## Accessibility

- Keep an accessible name on the control. The tooltip describes it.
