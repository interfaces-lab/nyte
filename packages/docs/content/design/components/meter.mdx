title: Meter

```ts title="Import"
import { Meter } from "@nyte-ai/ui/meter";
```

Displays a measurement such as storage use or a quota.

## Usage

- Pass the current `value` to `Meter.Root`. The range defaults to `0` through `100`.
- Nest `Meter.Label` and `Meter.Value` inside the root, then put `Meter.Indicator` inside
  `Meter.Track`.
- Without `format`, `Meter.Value` displays the percentage of the range. Pass
  `Intl.NumberFormatOptions` to `format` on the root to display the measurement instead.
- Set `locale` on the root when the number needs a specific locale. Otherwise it uses the
  runtime locale.

## Anatomy

```tsx
<Meter.Root value={64}>
  <Meter.Label />
  <Meter.Value />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
</Meter.Root>
```

## Examples

### A percentage

```tsx
<Meter.Root value={64}>
  <Meter.Label>Storage used</Meter.Label>
  <Meter.Value />
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
</Meter.Root>
```

### A measurement with units

```tsx
<Meter.Root
  value={180}
  min={0}
  max={500}
  locale="en-US"
  format={{ maximumFractionDigits: 0 }}
  getAriaValueText={(formattedValue) => `${formattedValue} of 500 GB used`}
>
  <Meter.Label>Storage used</Meter.Label>
  <Meter.Value>{(formattedValue) => `${formattedValue} GB`}</Meter.Value>
  <Meter.Track>
    <Meter.Indicator />
  </Meter.Track>
</Meter.Root>
```

## Props

All five parts add `xstyle` and preserve Base UI's `className` and `style` callbacks.
In the table, `State` is the state of the corresponding Base UI part, and `Part` is
`"Meter.Root"`, `"Meter.Label"`, `"Meter.Value"`, `"Meter.Track"`, or `"Meter.Indicator"`.

| Prop        | Type                                                                          |
| ----------- | ----------------------------------------------------------------------------- |
| `xstyle`    | `Restyle<Part>`                                                               |
| `className` | `string \| ((state: State) => string \| undefined)`                           |
| `style`     | `React.CSSProperties \| ((state: State) => React.CSSProperties \| undefined)` |

## Accessibility

- Name the meter with `Meter.Label` or `aria-label` on the root.
- Set `getAriaValueText` or `aria-valuetext` on the root when announcements need units or context.
