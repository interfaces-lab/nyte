```ts title="Import"
import { Loader } from "@nyte-ai/ui/loader";
```

A turning ring for a loading page, account, download, or process. It inherits text color in a 16px glyph slot.

## Usage

- Use `Loader` for non-AI loading and [Spinner](/design/spinner) for running AI work.
- Set `loading` on `Button` for a built-in loader that keeps its accessible name.

| `className` | `string`              |
| `style`     | `React.CSSProperties` |

## Accessibility

- The loader is `aria-hidden`. Announce what is loading with nearby text or `aria-busy` on the
  region.
