```ts title="Import"
import { Avatar, AvatarFallback, AvatarImage } from "@nyte-ai/ui/avatar";
```

An image that falls back to initials while it loads or when it fails.

## Usage

- Include `AvatarFallback` with two-character initials.
- Choose `tone` for identity, not status.
- `AvatarImage` needs `alt`. Use `alt=""` beside a visible name.

## Anatomy

```tsx
<Avatar>
  <AvatarImage alt="" />
  <AvatarFallback />
</Avatar>
```

## Props

All three parts accept Base UI state callbacks for `className` and `style`.

| Part             | Prop     | Type                        |
| ---------------- | -------- | --------------------------- |
| `Avatar`         | `xstyle` | `Restyle<"Avatar">`         |
| `AvatarImage`    | `xstyle` | `Restyle<"AvatarImage">`    |
| `AvatarFallback` | `xstyle` | `Restyle<"AvatarFallback">` |

### Avatar

| Prop                           | Type                                                     | Default     | Description          |
| ------------------------------ | -------------------------------------------------------- | ----------- | -------------------- |
| `size`                         | `"xs" \| "sm" \| "md" \| "lg"`                           | `"md"`      | 20, 24, 28, or 36px. |
| `corners`                      | `"circle" \| "rounded"`                                  | `"circle"`  |                      |
| `tone`                         | `"neutral" \| "orange" \| "blue" \| "violet" \| "green"` | `"neutral"` |                      |
| `className`, `style`, `xstyle` | see [Theming](/design/theming)                           |             |                      |

## Accessibility

- Name the fallback with visible text or `role="img"` and `aria-label`. Image `alt` is unavailable
  during fallback. Hide redundant initials with `aria-hidden`.
