```ts title="Import"
import { Row } from "@nyte-ai/ui/row";
```

A list or navigation row where the painted row is one target and actions sit beside it.

## Usage

- Put the main action in `Row.Primary` and sibling controls in `Row.Actions`.
- Use `variant="nav"` without `Row.Primary` when the row itself is the button. Do not nest other
  controls inside that button.
- With `variant="bare"`, supply layout, states, and focus styling through `xstyle`.
- Omit `Row.Body` when there is no `Row.Description`.

## Anatomy

```tsx
<Row>
  <Row.Backdrop />
  <Row.Primary>
    <Row.Leading />
    <Row.Body>
      <Row.Label />
      <Row.Description />
    </Row.Body>
    <Row.Meta />
  </Row.Primary>
  <Row.Actions />
</Row>
```

### Actions on hover

```tsx
<Row interactive revealActions>
  <Row.Primary onClick={open}>
    <Row.Label xstyle={styles.label}>{title}</Row.Label>
  </Row.Primary>
  <Row.Actions placement="overlay">
    <Button size="2xs" iconOnly icon="x" aria-label={`Stop ${title}`} onClick={stop} />
  </Row.Actions>
</Row>
```

## Props

### Row

Renders a `<div>`, or a `<button>` with `variant="nav"`, and takes its native props.

| Prop                           | Type                                                              | Default  | Description                                                          |
| ------------------------------ | ----------------------------------------------------------------- | -------- | -------------------------------------------------------------------- |
| `variant`                      | `"list" \| "nav" \| "bare"`                                       | `"list"` | `bare` omits standard sizing, fill, action reveal, and focus styles. |
| `size`                         | `"md" \| "lg"`                                                    | `"md"`   |                                                                      |
| `interactive`                  | `boolean`                                                         | `false`  | Enables hover, focus-within, and selected fill.                      |
| `selected`                     | `boolean`                                                         | `false`  | Sets `data-selected`.                                                |
| `revealActions`                | `boolean`                                                         | `false`  |                                                                      |
| `render`                       | `ReactElement \| ((props: HTMLProps, state: {}) => ReactElement)` |          |                                                                      |
| `className`, `style`, `xstyle` | see [Theming](/design/theming)                                    |          |                                                                      |

### Row.Actions

| Prop        | Type                    | Default    | Description                        |
| ----------- | ----------------------- | ---------- | ---------------------------------- |
| `placement` | `"inline" \| "overlay"` | `"inline"` | In flow or over the trailing edge. |

### Parts

Every part takes `render`, plain `className` and `style`, `xstyle`, and its default element's native
props. `Row.Primary`, `Row.Backdrop`, and bare `Row` accept unrestricted `XStyle`.

| Part              | Renders    | Data slot         | Description                  |
| ----------------- | ---------- | ----------------- | ---------------------------- |
| `Row.Backdrop`    | `<span>`   | `row-backdrop`    | Selection layer.             |
| `Row.Primary`     | `<button>` | `row-primary`     |                              |
| `Row.Leading`     | `<span>`   | `row-leading`     | Fixed-width lane.            |
| `Row.Body`        | `<span>`   | `row-body`        | Label and description stack. |
| `Row.Label`       | `<span>`   | `row-label`       | Ellipsized.                  |
| `Row.Description` | `<span>`   | `row-description` | Smaller, ellipsized.         |
| `Row.Meta`        | `<span>`   | `row-meta`        | Tabular figures.             |
| `Row.Actions`     | `<span>`   | `row-actions`     |                              |

### Row state and layout

| Variable                | Default                                        | Description                                 |
| ----------------------- | ---------------------------------------------- | ------------------------------------------- |
| `--_row-padding-inline` | `row.paddingInlineMd` or `row.paddingInlineLg` | Overlay inset.                              |
| `--_row-fill`           | `transparent`                                  | Leave `interactive` off when owning states. |
| `--_row-meta-color`     | `role.contentSecondary`                        |                                             |

## Accessibility

- Enter and Space activate `Row.Primary` and `nav` buttons.
- Name icon-only controls in `Row.Actions` with `aria-label`.

- `selected` adds no ARIA. Use `aria-current` on `Row.Primary` or a `nav` row for the current page.
  Use `aria-selected` only with a role that supports it, not on a plain button.
