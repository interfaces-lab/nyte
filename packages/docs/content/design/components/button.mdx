```ts title="Import"
import { Button, ButtonGroup, ButtonLink, PickerTrigger, SplitButton } from "@nyte-ai/ui/button";
```

`Button` acts. `ButtonLink` navigates with a native `<a href>`.

## Usage

- An icon-only control needs `iconOnly` and `aria-label`. A control with visible text omits
  `aria-label`.
- The icon-only label doubles as the native `title`. Inside a
  [Tooltip](/design/tooltip), pass `title={undefined}` to keep one tooltip on screen.
- Reserve `disabled` for an impossible action. Give the reason with `disabledReason` or nearby text.
- `Button` defaults to `type="button"`. Pass `type="submit"` to submit a form.
- In a popup trigger's `render`, put the text inside the `Button`, as in
  `<Popover.Trigger render={<Button>Open</Button>} />`.
- Give every `ButtonGroup` part the same size. `SplitButton.MenuTrigger` needs a label that names
  the action and its target.

## Anatomy

```tsx
<SplitButton.Root>
  <SplitButton.Main>Commit</SplitButton.Main>
  <SplitButton.MenuTrigger aria-label="More commit actions" />
</SplitButton.Root>
```

Wrap `SplitButton.MenuTrigger` in the menu's trigger. See [Joined actions](#joined-actions).

## Props

### Button and ButtonLink

`Button` takes Base UI props with the `iconOnly` restrictions below. `className` and `style` accept
Base UI button-state callbacks. `ButtonLink` takes native `<a>` attributes and plain styling values.

| Prop                 | Type                                                                          | Default                                       | Description                                            |
| -------------------- | ----------------------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------ |
| `variant`            | `"ghost" \| "outline" \| "solid" \| "plain" \| "quiet" \| "text" \| "inline"` | `"ghost"`                                     | `quiet` is `plain` with 4px inline padding.            |
| `tone`               | `"neutral" \| "primary" \| "success" \| "warning" \| "danger"`                | `"primary"` for `text`, otherwise `"neutral"` |                                                        |
| `size`               | `"2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl"`                               | `"md"`                                        |                                                        |
| `iconOnly`           | `boolean`                                                                     | `false`                                       |                                                        |
| `pill`               | `boolean`                                                                     | `false`                                       | Fully rounded ends.                                    |
| `icon`               | `IconName`                                                                    |                                               | Leading or standalone glyph.                           |
| `children`           | `ReactNode`                                                                   |                                               | Required for visible-text controls.                    |
| `xstyle`             | `ButtonLayout`                                                                |                                               | Placement, width, and border radius.                   |
| `className`, `style` | See [Theming](/design/theming)                                                |                                               |                                                        |
| `loading`            | `boolean`                                                                     | `false`                                       | Button only. Shows a `Loader` and disables activation. |
| `disabledReason`     | `string`                                                                      |                                               | Button only. Shown as the `title` while `disabled`.    |
| `aria-label`         | `string`                                                                      | Required when `iconOnly`                      | Not accepted on visible-text controls.                 |
| `href`               | `string`                                                                      | Required for ButtonLink                       |                                                        |

### ButtonGroup and SplitButton

`ButtonGroup` and `SplitButton.Root` render `<div role="group">` and take native `<div>` props.
`SplitButton.Main` is a `Button`. `SplitButton.MenuTrigger` is icon-only, requires `aria-label`,
rejects `children`, and defaults `icon` to `chevron-down`.

| Prop        | Type                     |
| ----------- | ------------------------ |
| `xstyle`    | `Restyle<"ButtonGroup">` |
| `className` | `string`                 |
| `style`     | `React.CSSProperties`    |

### PickerTrigger

An outline, medium button with an ellipsized value and trailing chevron. Takes Base UI button props
and styling callbacks.

| Prop     | Type                   | Default      | Description                          |
| -------- | ---------------------- | ------------ | ------------------------------------ |
| `width`  | `"standard" \| "wide"` | `"standard"` | Maximum width of 180px or 100%.      |
| `xstyle` | `ButtonLayout`         |              | Placement, width, and border radius. |

### Base UI button props

Applies to `Button`, `SplitButton.Main`, `SplitButton.MenuTrigger`, and `PickerTrigger`, with the
restrictions above.

## Accessibility

- Enter and Space activate `Button`. Enter follows `ButtonLink`.
- `focusableWhenDisabled` defaults to `true` while loading or disabled with `disabledReason`.
  `disabledReason` alone does not disable a button.
- `loading` sets `aria-busy` and keeps the accessible name.

- Name a group with `aria-label` when its parts do not name it. Every part keeps its own tab stop.
