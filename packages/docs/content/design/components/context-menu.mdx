---
title: Context menu
description: "A menu that opens at the pointer on right click or long press"
---

```ts title="Import"
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
  ContextMenuTrigger,
} from "@nyte-ai/ui/context-menu";
```

Right-click or long-press shortcuts to actions that also have visible controls.

## Usage

- Name `ContextMenuContent` with `aria-label`.

## Anatomy

```tsx
<ContextMenu>
  <ContextMenuTrigger />
  <ContextMenuContent>
    <ContextMenuGroup>
      <ContextMenuGroupLabel />
      <ContextMenuItem />
      <ContextMenuLinkItem />
      <ContextMenuCheckboxItem />
    </ContextMenuGroup>
    <ContextMenuSeparator />
    <ContextMenuRadioGroup>
      <ContextMenuRadioItem value="choice" />
    </ContextMenuRadioGroup>
    <ContextMenuSub>
      <ContextMenuSubTrigger />
      <ContextMenuSubContent>
        <ContextMenuItem />
      </ContextMenuSubContent>
    </ContextMenuSub>
  </ContextMenuContent>
</ContextMenu>
```

## Props

Every styled part takes `xstyle`, `className`, and `style`. `className` and `style` accept plain
values or functions of the underlying Base UI part's state. See [Theming](/design/theming).

`ContextMenu`, `ContextMenuTrigger`, `ContextMenuRadioGroup`, `ContextMenuGroup`, and `ContextMenuSub`
pass through Base UI unstyled.

The reference tables below come from Base UI, MIT, © Material-UI SAS.

### ContextMenu

`onItemHighlighted` accepts `(item: HTMLElement | undefined, eventDetails) => void`.
Details include `label` and `reason` (`"keyboard"`, `"pointer"`, or `"none"`).

### ContextMenuContent

Only the positioning props in this table are accepted. `ref`, `className`, and `style` target the popup.

| Prop                 | Type                                                                                                           | Default                                                                  |
| -------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `side`               | `"top" \| "bottom" \| "left" \| "right" \| "inline-start" \| "inline-end"`                                     | `"bottom"`                                                               |
| `align`              | `"start" \| "center" \| "end"`                                                                                 | `"start"`                                                                |
| `sideOffset`         | `number \| OffsetFunction`                                                                                     | `-5` when `side` is omitted and alignment is not centered, otherwise `0` |
| `alignOffset`        | `number \| OffsetFunction`                                                                                     | `2` when `side` is omitted and alignment is not centered, otherwise `0`  |
| `anchor`             | `Element \| VirtualElement \| RefObject<Element \| null> \| (() => Element \| VirtualElement \| null) \| null` | the pointer                                                              |
| `collisionAvoidance` | `CollisionAvoidance`                                                                                           | `{ fallbackAxisSide: "none" }`                                           |
| `collisionPadding`   | `number \| Padding`                                                                                            | `8`                                                                      |
| `tint`               | `Tint`                                                                                                         |                                                                          |

### ContextMenuSubContent

Takes `ContextMenuContent` props. Defaults to `side="inline-end"`, `align="start"`, the trigger anchor,
and `collisionAvoidance={{ fallbackAxisSide: "end" }}`.

| Prop          | Default                           |
| ------------- | --------------------------------- |
| `sideOffset`  | `6`                               |
| `alignOffset` | `0` when centered, otherwise `-4` |

### ContextMenuItem

| Prop       | Type                               | Default     | Description                                                      |
| ---------- | ---------------------------------- | ----------- | ---------------------------------------------------------------- |
| `icon`     | `IconName`                         |             |                                                                  |
| `leading`  | `ReactNode`                        |             | Non-nullish content replaces `icon` in `menu` layout.            |
| `meta`     | `ReactNode`                        |             | Binds no key.                                                    |
| `variant`  | `"default" \| "danger" \| "quiet"` | `"default"` |                                                                  |
| `layout`   | `"menu" \| "plain" \| "action"`    | `"menu"`    | `plain` removes leading content. `action` centers a compact row. |
| `children` | `ReactNode`                        |             |                                                                  |

## Accessibility

- Enter and Space activate. Escape closes. `finalFocus` chooses where focus returns.
