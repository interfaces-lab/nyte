```ts title="Import"
import { Questionnaire, QuestionnaireItem, QuestionnaireChoice } from "@nyte-ai/ui/questionnaire";
```

A form that shows one question at a time. Your app handles persistence and submission.

## Usage

- Give items unique `name` values and choices unique `value` values within their item.
- For server rendering, keep `items` names, choice order, `disabled` and `required` synchronized with rendered parts.
- Control steps with `item` and `onItemChange`.
- Read `FormData` in `onSubmit`, using `getAll(name)` for multiple answers. Skipped answers are excluded.
- Keep items mounted. Next requires an answer. Use Skip for unanswered optional items.

| -------------------------------- | --------------- | --------------- |

| `QuestionnaireSubmit`            | `button`        | Actions         |

## Examples

```tsx
<Questionnaire items={[{ name: "timing", choices: [{ value: "now" }] }]}>
  <QuestionnaireItem name="timing" aria-label="When?">
    <QuestionnaireChoice value="now">Now</QuestionnaireChoice>
  </QuestionnaireItem>
</Questionnaire>
```

### Rendering

`render` accepts `ReactElement | ((props: Record<string, unknown>, state) => ReactElement | null)` on these parts. Spread callback props onto your element. Input and navigation use Nyte styles unless replaced.

| Part               | Callback state                                                                                                                |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| Progress           | `{ current: number; first: boolean; last: boolean; total: number }`                                                           |
| Title, Description | `Record<string, unknown>`                                                                                                     |
| Choices            | `{ shortcuts: "letters" \| "numbers" \| null }`                                                                               |
| Choice             | `{ checked: boolean; disabled: boolean; invalid: boolean; shortcut: string \| null; type: "checkbox" \| "radio" }`            |
| Input              | `{ disabled: boolean; filled: boolean; invalid: boolean }`                                                                    |
| Error              | `{ invalid: boolean }`                                                                                                        |
| Navigation         | `{ disabled: boolean; shortcut: "Enter" \| null; status: "unanswered" \| "answered" \| "skipped" \| null; visible: boolean }` |

## Accessibility

- Name each fieldset with Title or `aria-label`.
- Ctrl+Enter or Cmd+Enter validates and advances or submits. Choice shortcuts require `shortcuts`.
- With `render`, preserve native labels, inputs and buttons or equivalent keyboard and naming behavior.
