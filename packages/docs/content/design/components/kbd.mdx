```ts title="Import"
import { Kbd } from "@nyte-ai/ui/kbd";
```

Shows the shortcut for a command, one key cap per key, beside the command's label.

## Usage

- Pass one string per key in display order.
- Show a shortcut on hover or in a [Tooltip](/design/tooltip) (`shortcut`), not beside every
  idle row.

## Examples

<Preview>
  <KbdDemo />
</Preview>

```tsx
<Kbd keys={["⌘", "K"]} />
<Kbd keys={["⇧", "⌘", "D"]} />
<Kbd keys={["⌘", "N"]} plain />
```

## Props

Native `<kbd>` attributes pass through.

| Prop        | Type                  | Default | Description                     |
| ----------- | --------------------- | ------- | ------------------------------- |
| `keys`      | `readonly string[]`   |         |                                 |
| `plain`     | `boolean`             | `false` | No fill, edge, or padding.      |
| `keycap`    | `boolean`             | `false` | One square key.                 |
| `held`      | `boolean`             | `false` | The key is pressed.             |
| `xstyle`    | `XStyle`              |         | See [Theming](/design/theming). |
| `className` | `string`              |         | See [Theming](/design/theming). |
| `style`     | `React.CSSProperties` |         | See [Theming](/design/theming). |

## Accessibility

- Renders a `<kbd>` with one `<span>` per key.
