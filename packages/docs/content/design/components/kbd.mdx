```ts title="Import"
import { Kbd } from "@nyte-ai/ui/kbd";
```

Shows a command's shortcut in one shared key cap.

## Usage

- Pass one string per key in display order.
- Show a shortcut on hover or in a [Tooltip](/design/tooltip) (`shortcut`), not beside every
  idle row.

## Examples

<Preview>
  <KbdDemo />
</Preview>

```tsx
<Kbd keys={["⌘", "K"]} />
<Kbd keys={["⇧", "⌘", "D"]} />
<Kbd keys={["⌘", "N"]} plain />
```

## Props

Native `<kbd>` attributes pass through except `children`, which comes from `keys`.

| Prop        | Type                  | Default  | Description                        |
| ----------- | --------------------- | -------- | ---------------------------------- |
| `keys`      | `readonly string[]`   | Required |                                    |
| `plain`     | `boolean`             | `false`  | No fill, edge, or padding.         |
| `keycap`    | `boolean`             | `false`  | Unpadded, glyph-sized minimum box. |
| `held`      | `boolean`             | `false`  | Appearance only.                   |
| `xstyle`    | `Restyle<"Kbd">`      |          |                                    |
| `className` | `string`              |          |                                    |
| `style`     | `React.CSSProperties` |          |                                    |

## Accessibility

- Does not register shortcuts.
