```ts title="Import"
import { Slider } from "@nyte-ai/ui/slider";
```

A single-value or range slider.

## Usage

- For server rendering, give each range thumb an explicit `index`.

## Anatomy

```tsx
<Slider.Root>
  <Slider.Label />
  <Slider.Value />
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>
```

## Examples

### A labeled slider

<Preview>
  <SliderDemo />
</Preview>

```tsx
<Slider.Root defaultValue={40} thumbAlignment="edge">
  <div>
    <Slider.Label>Intensity</Slider.Label>
    <Slider.Value />
  </div>
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>
```

### Controlled

```tsx
const [volume, setVolume] = useState(0.5);

<Slider.Root value={volume} onValueChange={setVolume} min={0} max={1} step={0.1}>
  <Slider.Label>Volume</Slider.Label>
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>;
```

### A range

```tsx
<Slider.Root defaultValue={[25, 75]} thumbCollisionBehavior="swap">
  <Slider.Label>Price range</Slider.Label>
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb index={0} aria-label="Minimum price" />
      <Slider.Thumb index={1} aria-label="Maximum price" />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>
```

### Thumb alignment

```tsx
<Slider.Root thumbAlignment="center" />
```

### In a form

```tsx
<Slider.Root name="volume">
  <Slider.Label>Volume</Slider.Label>
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>
```

## Props

Every part adds `xstyle`. `className` and `style` accept values or Base UI part-state functions.
See [Theming](/design/theming).

The reference tables below come from Base UI, MIT, © Material-UI SAS.

### Root

| Prop             | Type                                       | Default  |
| ---------------- | ------------------------------------------ | -------- |
| `thumbAlignment` | `"center" \| "edge" \| "edge-client-only"` | `"edge"` |
| `xstyle`         | `XStyle`                                   |          |

`value` and `defaultValue` accept a number or number array. Callbacks preserve that shape.
`Orientation` is `"horizontal" | "vertical"`.

## Accessibility

- `Slider.Label` names every thumb. In a range, or without a visible label, give each thumb an
  `aria-label`.
- `aria-valuetext` replaces the announced number. `getAriaValueText` overrides it.
