```ts title="Import"
import { Switch, SwitchField } from "@nyte-ai/ui/switch";
```

For settings that apply on change.

## Usage

- `Switch.label` becomes its `aria-label`. Use `SwitchField` for visible text.

## Anatomy

`SwitchField` contains label text, an optional description, then the switch. The thumb is built in. Do not pass children.

## Examples

  <SwitchDemo />

```tsx
const [wrap, setWrap] = useState(true);

<Switch label="Code block word wrap" checked={wrap} onCheckedChange={setWrap} />
<Switch label="Reduce transparency" disabled />
```

### Field

```tsx
const [wrap, setWrap] = useState(true);

<SwitchField
  label="Code block word wrap"
  description="Long lines wrap instead of scrolling"
  checked={wrap}
  onCheckedChange={setWrap}
/>;
```

## Props

### Switch

Takes Base UI `Switch.Root` props except `children`. `className` and `style` accept values or switch-state functions.

| Prop                           | Type                           | Description |
| ------------------------------ | ------------------------------ | ----------- |
| `label`                        | `string`                       | Required.   |
| `className`, `style`, `xstyle` | see [Theming](/design/theming) |             |

### SwitchField

Takes `Switch` props except `aria-label`, `aria-labelledby`, and `nativeButton`.
`className`, `style`, and `xstyle` style the row. Callbacks receive Base UI `Field.Root` state.

| Prop                           | Type                           | Description      |
| ------------------------------ | ------------------------------ | ---------------- |
| `label`                        | `string`                       | Required.        |
| `description`                  | `string`                       | Below the label. |
| `className`, `style`, `xstyle` | see [Theming](/design/theming) |                  |

## Accessibility

`SwitchField` connects `label` through `aria-labelledby` and `description` through `aria-describedby`.
