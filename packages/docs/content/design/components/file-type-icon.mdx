---
title: File type icon
description: "The icon for a file's language or format, tinted to match"
---

```ts title="Import"
import { FileTypeIcon, FileTypeIconSprite } from "@nyte-ai/ui/file-type-icon";
```

Marks a file by its name and extension. Unknown types get a gray file icon.

## Usage

- Render `FileTypeIconSprite` once per document.
- Pass the file path to `FileTypeIcon`. There are no size, color, or styling props.

## Examples

```tsx
<FileTypeIconSprite />
<FileTypeIcon path="src/app.ts" />
<FileTypeIcon path="README.md" />
```

## Props

### FileTypeIcon

| Prop   | Type     | Default  | Description                     |
| ------ | -------- | -------- | ------------------------------- |
| `path` | `string` | Required | Backslashes work as separators. |

### FileTypeIconSprite

No props.

## Accessibility

- Both render `aria-hidden`. Name the file in the text beside the icon.
