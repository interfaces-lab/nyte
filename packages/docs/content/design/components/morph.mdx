```ts title="Import"
import { Morph } from "@nyte-ai/ui/morph";
```

Expand a preview from its trigger without losing its place.

## Usage

- Control `open` and `onOpenChange` on `Morph.Root`.
- Give the trigger and popup matching content. Keep controls outside the popup's layout box if only the preview should expand.
- Include `Morph.Title` and a reachable `Morph.Close` inside the popup.
- Place `Morph.Backdrop` and `Morph.Popup` inside `Morph.Portal`.
- Use `initialFocus` and `finalFocus` to choose the controls focused on open and close.

## Anatomy

```tsx
<Morph.Root open={open} onOpenChange={setOpen}>
  <Morph.Trigger />
  <Morph.Portal>
    <Morph.Backdrop />
    <Morph.Popup>
      <Morph.Title />
      <Morph.Description />
      <Morph.Close />
    </Morph.Popup>
  </Morph.Portal>
</Morph.Root>
```

## Examples

```tsx
import { useState } from "react";
import { Morph } from "@nyte-ai/ui/morph";

function Preview() {
  const [open, setOpen] = useState(false);

  return (
    <Morph.Root open={open} onOpenChange={setOpen}>
      <Morph.Trigger>Open preview</Morph.Trigger>
      <Morph.Portal>
        <Morph.Backdrop />
        <Morph.Popup>
          <Morph.Title>Preview</Morph.Title>
          <Morph.Description>A closer look at the selection.</Morph.Description>
          <Morph.Close>Close</Morph.Close>
        </Morph.Popup>
      </Morph.Portal>
    </Morph.Root>
  );
}
```

## Props

| Part                | Styling                        |
| ------------------- | ------------------------------ |
| `Morph.Root`        | Controlled `open`              |
| `Morph.Trigger`     | Button                         |
| `Morph.Portal`      | Retains popup through exit     |
| `Morph.Backdrop`    | Fixed scrim                    |
| `Morph.Popup`       | Centered, content-sized dialog |
| `Morph.Close`       | Unstyled button                |
| `Morph.Title`       | Unstyled heading               |
| `Morph.Description` | Unstyled paragraph             |

Except `Morph.Root` and `Morph.Portal`, each part accepts `xstyle`, `className`, and `style`.
`className` and `style` accept plain values or state functions. Trigger, Backdrop, and Popup
ignore caller-supplied `render`.
