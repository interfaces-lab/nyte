title: receipt.stop

Stops the work behind a receipt. For a send, that withdraws the message while it is queued, stops
the run it started once it landed, or abandons a start still being decided. A batch stops between
files. It answers `requested`, `settled` with the outcome when the receipt had already settled, or
`missing`.

## When to call it

When the user cancels one message rather than the whole chat.

## Access

Any principal with `participant` authority. Session scope, or `session` `null` for a batch receipt.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "receipt": "7c1e9a3b-2d4f-4a6c-8e0b-1f3d5a7c9e2b"
}
```

Response:

```json
{ "kind": "requested" }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
