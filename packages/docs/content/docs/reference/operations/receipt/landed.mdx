---
title: receipt.landed
description: Waits until a sent message lands or fails and returns where it landed.
---

Waits until a sent message has its place in history and answers where: `landed` with its commit,
the run it started, and the message it replaced, if any. It answers `withdrawn` when the message
was stopped first, or `stale`, `busy`, `pending-input`, `missing-target` or `summary-failed` when
an edit couldn't land.

## When to call it

After [`head.send`](/docs/reference/operations/head/send), to know the message is in the transcript
before the run ends. It is a wait, safe to call again after a lost connection.

## Access

Any principal with `participant` authority. Session scope. Only a send's receipt lands, so
`session` can't be `null`.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "receipt": "7c1e9a3b-2d4f-4a6c-8e0b-1f3d5a7c9e2b"
}
```

Response:

```json
{
  "kind": "landed",
  "commit": "c5e7a9b1d3f5a7c9e1b3d5f7a9c1e3b5d7f9a1c3e5b7d9f1a3c5e7b9d1f3a5c7",
  "run": "4e2a6c8f-1b3d-4f5a-9c7e-0a2b4d6f8c1e",
  "replaced": null
}
```

## Errors

- `invalid` when `session` is `null`: `Only a send's receipt has landed.`
- `unknown` when no receipt has the id.
