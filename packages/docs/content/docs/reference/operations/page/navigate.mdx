Loads a URL in a page. Like every page action, it answers an outcome: `applied` with a fresh
snapshot, `stale` with the current revision, `refused` with a reason (`unknown-ref`, `occluded`,
`not-visible` or `policy`), or `closed` with a reason (`released`, `reclaimed` or `crashed`).

## When to call it

When the user enters an address, or a client sends a page somewhere.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7",
  "url": "http://localhost:5173/cart"
}
```

Response, with the snapshot shortened:

```json
{ "kind": "applied", "snapshot": { "revision": "15", "nodes": [] } }
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
