---
title: page.click
description: Clicks a node on a page.
---

Clicks the node `ref` from the page's latest snapshot, with the `left` button by default, or a
double click with `double`. With `expect`, it acts only while the document revision still matches,
and answers `stale` otherwise. It answers a page outcome as
[`page.navigate`](/docs/reference/operations/page/navigate) does; `refused` says why the node
couldn't be clicked.

## When to call it

To drive a page, after reading its nodes with
[`page.snapshot`](/docs/reference/operations/page/snapshot). Don't resend after a lost answer: the
click may already have happened.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7",
  "ref": "e12",
  "expect": "14"
}
```

Response:

```json
{ "kind": "stale", "revision": "15" }
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
