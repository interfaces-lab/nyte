title: page.wait
description: Waits until a page loads, text appears or disappears, or a delay passes.
---

Waits until a page finishes loading, until text appears (`present: true`) or disappears
(`present: false`), or until a delay in milliseconds passes. It answers a page outcome as
[`page.navigate`](/docs/reference/operations/page/navigate) does.

## When to call it

After an action that loads or changes the page, before reading its snapshot.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7",
  "condition": { "kind": "text", "text": "Order placed", "present": true }
}
```

Response, with the snapshot shortened:

```json
{ "kind": "applied", "snapshot": { "revision": "19", "nodes": [] } }
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
