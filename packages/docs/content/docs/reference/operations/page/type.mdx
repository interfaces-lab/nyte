---
title: page.type
description: Types text into a node on a page.
---

Types text into the node `ref`. `clear` empties the field first and `submit` presses Enter after.
With `expect`, it acts only while the document revision still matches. It answers a page outcome as
[`page.navigate`](/docs/reference/operations/page/navigate) does.

## When to call it

To fill a form field found with [`page.snapshot`](/docs/reference/operations/page/snapshot). Don't
resend after a lost answer: the text may already have been typed.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7",
  "ref": "e15",
  "text": "SPRING10",
  "clear": true,
  "submit": true
}
```

Response, with the snapshot shortened:

```json
{ "kind": "applied", "snapshot": { "revision": "15", "nodes": [] } }
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
