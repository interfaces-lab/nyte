Reads a page's URL, title, whether it is loading, whether it can go back or forward, and its
document revision.

## When to call it

To show a page's address bar state once. To keep it current, use
[`page.watch`](/docs/reference/operations/page/watch).

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability. A page
the caller doesn't hold yet is adopted first.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7"
}
```

Response:

```json
{
  "id": "page-7",
  "url": "http://localhost:5173/cart",
  "title": "Cart · Shop",
  "loading": false,
  "revision": "14",
  "canGoBack": true,
  "canGoForward": false
}
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
