---
title: page.close
description: Closes a page.
---

Releases the caller's hold on a page. The browser closes the page once no holder is left, so a page
an agent or another client still holds stays open. Closing a page the caller doesn't hold does
nothing.

## When to call it

When the user closes a page tab, or a client is done driving a page.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7"
}
```

Response:

```json
null
```

## Errors
