---
title: page.press
description: Presses a key or chord on a page or one of its nodes.
---

Presses a key or chord, such as `Enter` or `Control+a`, on the page or on the node `ref`. It
answers a page outcome as [`page.navigate`](/docs/reference/operations/page/navigate) does.

## When to call it

For keyboard input that isn't text, such as closing a dialog with `Escape`. Don't resend after a
lost answer.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7",
  "key": "Escape"
}
```

Response, with the snapshot shortened:

```json
{ "kind": "applied", "snapshot": { "revision": "16", "nodes": [] } }
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
