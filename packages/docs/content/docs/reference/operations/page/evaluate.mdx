---
title: page.evaluate
description: Runs a JavaScript expression in a page and returns its value or error.
---

Runs a JavaScript expression in a page, or with the node `ref` as `this`, and answers `value` with
its result as JSON, or `threw` with the error's message.

## When to call it

To read something the accessibility tree doesn't show, such as a value in page state. Don't resend
after a lost answer: the expression may have side effects.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability. The
expression runs with the page's own privileges.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7",
  "expression": "document.querySelectorAll('.cart-item').length"
}
```

Response:

```json
{ "kind": "value", "value": 3 }
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
