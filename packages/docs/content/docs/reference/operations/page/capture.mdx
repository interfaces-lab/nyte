Streams a screenshot of a page as image bytes; the desktop browser answers a PNG.

## When to call it

To show what a page looks like, such as a thumbnail or a visual check after an action.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7"
}
```

The answer is the image's bytes, with `X-Nyte-Mime: image/png`.

## Errors

- `unknown` when no open page has the id.
- `unavailable` when the page couldn't be captured, or the workspace doesn't offer a browser.
