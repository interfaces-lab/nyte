---
title: page.snapshot
description: Returns a page's accessibility tree, or the subtree under one node.
---

Returns a page's accessibility tree, or the subtree under the node `ref`, with its document
revision. Each node has a `ref` to act on, a role, an accessible name, and whether it is editable.

## When to call it

Before acting on a node, read its `ref` from a snapshot. [`page.click`](/docs/reference/operations/page/click)
and [`page.type`](/docs/reference/operations/page/type) also accept the snapshot's `revision` as
optional `expect` to reject a stale document. [`page.press`](/docs/reference/operations/page/press)
and [`page.scroll`](/docs/reference/operations/page/scroll) accept node refs but do not accept `expect`.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "page": "page-7"
}
```

Response:

```json
{
  "revision": "14",
  "nodes": [
    { "ref": "e12", "role": "button", "name": "Check out", "editable": false, "depth": 0 },
    { "ref": "e15", "role": "textbox", "name": "Coupon code", "editable": true, "depth": 0 }
  ]
}
```

## Errors

- `unknown` when no open page has the id.
- `unavailable` or `denied` when the workspace doesn't offer a browser.
