---
title: connection.watch
description: Streams the host's state, including its model catalog, each time it changes.
---

Streams the host's state: its name, platform and version, the catalog generation, loaded plugins
and their issues, settings, part views, the default workspace, and the caller's principal and
authority. The first frame is the current state; another follows each time any of it changes.

## When to call it

Open it once per connection and keep it open. It is how a client learns that plugins reloaded,
a setting changed or the model catalog moved: `catalog` changes whenever saved models, logins or
listings do, and a client then reads [`models.list`](/docs/reference/operations/models/list) again.

## Access

Any principal with `participant` authority. Host scope: the input is empty. The frame's
`authority` and `principal` describe the connection that asked, so two clients see different
values.

## Example

Request body:

```json
{}
```

First frame, with `plugins`, `settings` and `views` shortened to empty lists:

```json
{
  "id": "3f6c2a1e-8d4b-4c1e-9a77-0b2d5e8f1c43",
  "link": { "kind": "connected" },
  "name": "studio-mac",
  "platform": "darwin",
  "version": "0.0.24",
  "catalog": "6d2f8a1c-3b5e-4f7a-9c1d-2e4b6a8c0f13",
  "plugins": [],
  "settings": [],
  "views": [],
  "defaultWorkspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "authority": ["participant", "owner"],
  "principal": "token"
}
```
