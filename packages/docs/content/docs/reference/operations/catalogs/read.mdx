---
title: catalogs.read
description: Reads the commands, settings, skills, agents and tools of a chat's catalog by the id its session rows carry.
---

Reads a chat's catalog: the commands, settings, skills, agents and tools its plugins offer. A
session's rows carry only the catalog's id, the first 16 hex digits of the SHA-256 of its JSON, and
this operation returns the content behind it. The host stores each catalog once under its id and
never changes it, so chats with the same plugins share one catalog and a client can keep what it
read for as long as it stays connected.

## When to call it

When a session's `catalog` row from [`head.read`](/docs/reference/operations/head/read) or a
`change` event names an id the client hasn't read yet. A catalog survives a host restart, so a
client reads it without the chat's plugins running.

## Access

Any principal with `participant` authority. Host scope: catalogs belong to the host's store and
are shared by every chat that has the same one.

## Example

Request body:

```json
{ "id": "3f8a1c2b9d0e4f71" }
```

Response:

```json
{
  "commands": [
    {
      "name": "hello",
      "owner": "greeter",
      "side": "core",
      "title": "Hello",
      "description": "Says hi.",
      "takesText": false,
      "completes": false
    }
  ],
  "settings": [],
  "skills": [],
  "agents": [],
  "tools": []
}
```

## Errors

- `unknown` when no catalog has the id: `No catalog has the id <id>.`
