---
title: models.setDefault
description: Sets the model new chats use by default.
---

Saves the model that new chats use when they don't name one. It answers `unknown-model` when the
catalog has no such model, and saves nothing.

## When to call it

From a settings screen's default model control. A person's client that starts a chat or
configures a head with `owner` authority also saves its choice, so most clients don't call this
directly.

## Access

Needs `owner` authority. Host scope.

## Example

Request body:

```json
{ "ref": { "provider": "anthropic", "id": "claude-sonnet-4-5" } }
```

Response:

```json
{ "kind": "set" }
```

## Errors

- `unavailable` when the host was built without models. An unknown model is the `unknown-model`
  outcome, not an error.
