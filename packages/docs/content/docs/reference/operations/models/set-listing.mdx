Shows, hides or favorites models in the model list. `shown` clears a listing; `hidden` and
`favorite` are saved per model. Every ref must name a model in the catalog, or nothing changes.

## When to call it

From a model picker's hide and favorite controls. The listing comes back in each provider's
`listings` from [`models.list`](/docs/reference/operations/models/list).

## Access

Needs `owner` authority. Host scope.

## Example

Request body:

```json
{
  "refs": [{ "provider": "anthropic", "id": "claude-sonnet-4-5" }],
  "listing": "favorite"
}
```

Response:

```json
{ "kind": "set" }
```

## Errors

- `unavailable` when the host was built without models. A ref the catalog doesn't have answers
  `unknown-model`.
