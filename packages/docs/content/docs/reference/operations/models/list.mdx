title: models.list
description: Lists saved models, the default selection and each provider's last known credentials.

Reads the model catalog: each provider with its models, login methods, limits, listings and last
known credential state, plus the default model and the catalog generation. It reads what is saved
and doesn't wait for a provider to answer.

## When to call it

To fill a model picker, and again whenever the `catalog` generation on
[`connection.watch`](/docs/reference/operations/connection/watch) changes. A provider's `credential`
is the last state the host knew: `unknown`, `missing`, `configured`, `verified` or `failed`.

## Access

Any principal with `participant` authority. Host scope. Changing the catalog takes `owner`.

## Example

Request body:

```json
{}
```

Response, with one provider and its models list emptied:

```json
{
  "generation": "6d2f8a1c-3b5e-4f7a-9c1d-2e4b6a8c0f13",
  "default": { "provider": "anthropic", "id": "claude-sonnet-4-5" },
  "providers": [
    {
      "id": "anthropic",
      "name": "Anthropic",
      "credential": "configured",
      "methods": [{ "kind": "oauth" }, { "kind": "key" }],
      "limits": [],
      "models": [],
      "listings": {}
    }
  ]
}
```

`default` is the model saved with `models.setDefault`. Without one, it is the first model of the
first provider with working credentials, or `null`.

## Errors

- `unavailable` when the host was built without models: `models is not provided`.
