title: workspace.command
description: Runs a workspace command without a chat, with the text typed after it.
---

Runs a command from [`workspace.catalog`](/docs/reference/operations/workspace/catalog) without a
chat, with the text typed after it (`""` for none). A command that returns text answers `ran`. A
command that answers with a prompt runs nothing more: the `prompt` outcome carries the first
message of the chat it asks to start, which the client passes to
[`sessions.start`](/docs/reference/operations/sessions/start).

## When to call it

When the user runs a slash command in the composer of a chat that hasn't started.

## Access

Any principal with `participant` authority. Workspace scope.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "name": "review",
  "text": "src/app.ts"
}
```

Response:

```json
{ "kind": "prompt", "content": "Review src/app.ts for bugs and missing tests." }
```

`unknown` answers that no command has the name; `failed` carries the message of a command that
threw.

## Errors

- `unknown` when no workspace has the id.
