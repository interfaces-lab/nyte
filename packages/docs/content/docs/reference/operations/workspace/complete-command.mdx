---
title: workspace.completeCommand
description: Returns completions for the text after a workspace command.
---

Asks a command from [`workspace.catalog`](/docs/reference/operations/workspace/catalog) what may
follow the text typed after it so far, as
[`session.completeCommand`](/docs/reference/operations/session/complete-command) does in a chat.

## When to call it

While the user types after a slash command in the composer of a chat that hasn't started.

## Access

Any principal with `participant` authority. Workspace scope.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "name": "review",
  "prefix": "src/a"
}
```

Response:

```json
[{ "value": "src/app.ts", "label": "app.ts", "description": "src" }]
```

## Errors

- `unknown` when no workspace has the id.
