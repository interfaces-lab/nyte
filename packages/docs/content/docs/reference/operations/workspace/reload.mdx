title: workspace.reload

Reads the workspace's project files again and reloads the plugins of its live sessions. It answers
`updated`, or `missing` when no workspace has the id.

## When to call it

After editing a project plugin, skill or prompt file, when the change should apply without
waiting for the file watcher.

## Access

Needs `owner` authority. Workspace scope.

## Example

Request body:

```json
{ "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0" }
```

Response:

```json
{ "kind": "updated" }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
