---
title: workspace.watch
description: Streams the workspace's info each time it changes.
---

Streams one workspace's info, the same value as
[`workspace.info`](/docs/reference/operations/workspace/info), first as it is and again each time
it changes, such as when a session starts or a run begins writing. The stream ends when the
workspace is forgotten, and at once, without a frame, for an id the host doesn't have.

## When to call it

To keep a workspace header current, such as its trust state and active writers.

## Access

Any principal with `participant` authority. Workspace scope.

## Example

Request body:

```json
{ "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0" }
```

Each frame is a workspace info object, as in the `workspace.info` example.

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
