---
title: workspace.update
description: Sets whether the workspace's folder trusts its project files.
---

Records the user's trust decision for the workspace's folder: `true` loads its project files
(plugins, skills, `.nyte/SYSTEM.md`, `.nyte/APPEND_SYSTEM.md`, `.nyte/mcp.json`), `false` skips
them, and `null` forgets the decision so the nearest folder above with one, or the host's
`workspaceTrust` mode, applies.

The decision belongs to the folder, not the workspace: every workspace there and every folder
below without its own follows it, and it outlives the workspace. A worktree's goes to the folder it
was made from. Live sessions reload with the change. It answers `updated`, or `missing` when no
workspace has the id.

## When to call it

From a trust prompt the first time a folder with project files opens, or from workspace settings.

## Access

Needs `owner` authority. Workspace scope.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "patch": { "projectResources": true }
}
```

Response:

```json
{ "kind": "updated" }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
