Streams the bytes of a file on the host machine by its absolute path. The answer carries
`Content-Length`, the file's type in `X-Nyte-Mime`, and its version in `X-Nyte-Version`, as
[`files.bytes`](/docs/reference/operations/files/bytes) does.

## When to call it

To show an image or PDF, or to download a file that
[`documents.read`](/docs/reference/operations/documents/read) reports as binary or large.

## Access

Only a principal with `owner` authority, since the path can be anywhere on the host machine. Host
scope: it needs no workspace. The host answers it only when it runs the built-in local provider.

## Example

Request body:

```json
{ "path": "/Users/ada/Desktop/screenshot.png" }
```

The answer is the file's bytes, with `X-Nyte-Mime: image/png`.

## Errors

- `invalid` when the path is relative.
- `unknown` when no file is at the path.
- `denied` without owner authority.
- `not_supported` when the host doesn't serve files by absolute path.
