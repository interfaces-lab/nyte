title: project.update
description: Edits a project's name, brief, goal, worker model or archived state.
---

Edits a project's `name`, `brief`, `until`, `worker` or `archived` flag by compare-and-set and
returns the project as stored. A field left out keeps its value; `worker` of `null` runs units on
the lead's model. A patch that changes nothing succeeds without writing. An edited brief reaches the
project's chats from their next request. `lead`, `workspace`, `id` and `createdAt` are the host's
and can't be patched.

## When to call it

From a project's settings, and to archive or restore a project.

## Access

Any principal with `participant` authority. Host scope.

## Example

Request body:

```json
{
  "project": "5f0c6a1e-3b2d-4c7e-8f9a-1b2c3d4e5f60",
  "patch": { "brief": "Read nyte-styles and better-ui before any UI fix.", "worker": null }
}
```

Response: the project as stored after the edit.

## Errors

- `unknown` when no project has the id.
- `invalid` when the patch names a field it can't set, such as `lead`.
- `stale` when the project kept changing under eight tries.
