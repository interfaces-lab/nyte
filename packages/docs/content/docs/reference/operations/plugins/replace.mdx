---
title: plugins.replace
description: Replaces the loaded plugins, for the whole host or one session.
---

Replaces the host's plugins with the plugin files at the given paths, or one session's plugins
when `scope` names it. Live sessions reload. A plugin that fails its checks keeps its previous
version (`kept-previous`) or is left out (`rejected`); the report lists each plugin's outcome and
issues, with the new catalog generation.

## When to call it

From developer tools that reload plugins while they are being written. Most clients never call it.

## Access

Needs `maintenance` authority, which only the host's own processes hold. Host scope; with `scope`,
the change applies to that session alone.

## Example

Request body:

```json
{ "plugins": [{ "path": "/Users/ada/.nyte/plugins/review.ts" }] }
```

Response:

```json
{
  "generation": "a41c7e2b-9d3f-4b6a-8e1c-5f7d9b2a4c60",
  "plugins": [{ "kind": "activated", "id": "review", "issues": [] }]
}
```

## Errors

- `unavailable` when the host has no plugin loader: `plugin files: this host has no plugin loader`.
- `unknown` when `scope` names no session.
