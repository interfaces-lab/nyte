Loads plugin files and checks them without activating anything. Each plugin answers `activated`
when it would load, or `rejected` with its issues, and `collisions` lists what two plugins both
register.

## When to call it

Before [`plugins.replace`](/docs/reference/operations/plugins/replace), or in a plugin author's
tools to show problems before reloading.

## Access

Needs `maintenance` authority. Host scope.

## Example

Request body:

```json
{
  "plugins": [
    { "path": "/Users/ada/.nyte/plugins/review.ts" },
    { "path": "/Users/ada/.nyte/plugins/lint.ts" }
  ]
}
```

Response:

```json
{
  "plugins": [
    { "kind": "activated", "id": "review", "issues": [] },
    { "kind": "activated", "id": "lint", "issues": [] }
  ],
  "collisions": [
    {
      "severity": "warning",
      "path": ["commands", "review"],
      "message": "review from lint collides with the one from review.",
      "source": { "plugin": "lint" }
    }
  ]
}
```

## Errors

- `unavailable` when the host has no plugin loader.
