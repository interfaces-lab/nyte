Writes, removes, moves and copies files and folders under one receipt. The host first checks every entry's `expect`;
if any is out of date, nothing is written and the batch settles `stale` with those paths. Otherwise
it applies the entries in order. A `put` takes its contents as a string, or as a blob from
[`files.upload`](/docs/reference/operations/files/upload). A `move`, `copy` or `mkdir` entry does
what [`files.move`](/docs/reference/operations/files/move),
[`files.copy`](/docs/reference/operations/files/copy) and
[`files.mkdir`](/docs/reference/operations/files/mkdir) do, with `path` as the source and `to` as
the destination; any answer other than `done` stops the batch as `partial`. A `remove` entry
permanently deletes its path without creating a trash token.

The outcome comes from [`receipt.settled`](/docs/reference/operations/receipt/settled) with
`session` `null`: `applied` with a snapshot and the paths written, `stale`, `partial` with what was
applied, what remains and why it stopped, or `stopped` with what was applied before a
[`receipt.stop`](/docs/reference/operations/receipt/stop). `partial` and `stopped` leave changes
already applied in place; stopping does not roll them back. A `put` naming a missing blob settles
`partial`, with `reason` identifying the blob, earlier successful entries in `applied`, and the
failed entry included in `remaining`.

## When to call it

To apply a multi-file change, such as accepting a suggested refactor. Include permanent removals in
the change review before applying it. Pass `id` so a retry with the same workspace and entries
returns the same receipt while the host retains it. This host process keeps the most recent 256
batch receipts; after eviction or a host restart, inspect the files before resubmitting, since the
batch may run again.

## Access

Any principal with `participant` authority. Workspace scope, with the `files` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "id": "3a5c7e9b-1d2f-4a6c-8e0b-2d4f6a8c0e1b",
  "entries": [
    {
      "kind": "put",
      "path": "src/date.ts",
      "contents": "export const today = () => new Date(Date.now());\n",
      "expect": "4b7d9f1a3c5e7b9d1f3a5c7e9b1d3f5a7c9e1b3d5f7a9c1e3b5d7f9a1c3e5b7d"
    },
    {
      "kind": "remove",
      "path": "src/old-date.ts",
      "expect": "2c4e6a8b0d1f3a5c7e9b1d3f5a7c9e1b3d5f7a9c1e3b5d7f9a1c3e5b7d9f1a3c"
    }
  ]
}
```

Response:

```json
{ "receipt": "3a5c7e9b-1d2f-4a6c-8e0b-2d4f6a8c0e1b" }
```

## Errors

- `invalid` when the receipt id was used for different input.
- `unavailable` or `denied` when the workspace doesn't offer files.
