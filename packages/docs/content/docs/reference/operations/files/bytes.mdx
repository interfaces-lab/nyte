Streams a file's bytes. The answer carries `Content-Length`, the file's type in `X-Nyte-Mime`, and
its version in `X-Nyte-Version`.

## When to call it

To show an image or PDF, or to download a file that [`files.read`](/docs/reference/operations/files/read)
reports as binary or large.

## Access

Any principal with `participant` authority. Workspace scope, with the `files` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "docs/screenshot.png"
}
```

The answer is the file's bytes, with `X-Nyte-Mime: image/png`.

## Errors

- `unknown` when nothing is at the path.
- `unavailable` or `denied` when the workspace doesn't offer files.
