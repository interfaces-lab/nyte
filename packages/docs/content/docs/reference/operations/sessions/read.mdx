---
title: sessions.read
description: "Reads the host's sessions table: the ids a filter selects and every row changed since a seq."
---

Reads the host's sessions table at one seq of the host scope. `ids` are the sessions `parents` and
`limit` select, newest activity first. `rows` holds each of them changed since `resume.seq`, or all
of them without `resume`. `seq` is the host seq the answer is current through.

## When to call it

To attach to the sessions table, or to catch up after a dropped connection. A first read sends no
`resume` and keeps the answer's `seq`. A resume sends that `seq` back: the client keeps its rows
for the ids it already holds, replaces the ones in `rows`, drops the ones no longer in `ids`, and
reads [`session.info`](/docs/reference/operations/session/info) for an id it holds no row for. Pass
`parents` to filter as [`sessions.watch`](/docs/reference/operations/sessions/watch) does, and
`limit` for the window (50 by default).

## Access

Any principal with `participant` authority. Host scope. `unread` in each head is the calling
principal's.

## Example

Request body:

```json
{ "limit": 2, "resume": { "seq": 41 } }
```

Response, with the row shortened:

```json
{
  "seq": 42,
  "ids": ["0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f", "5c1e9a7b-2d3f-4e8a-9b6c-1d2e3f4a5b6c"],
  "rows": [
    {
      "id": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
      "name": "Fix the flaky test",
      "parent": null,
      "call": null,
      "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
      "pinned": false,
      "archived": false,
      "activation": { "kind": "active" },
      "heads": [],
      "createdAt": 1767240000000,
      "lastActivityAt": 1767240300000
    }
  ]
}
```

## Errors

None of its own.
