Streams the workspace's open pages, the same list as
[`browser.list`](/docs/reference/operations/browser/list), each time it changes.

## When to call it

To keep a list of open pages current.

## Access

Any principal with `participant` authority. Workspace scope, with the `browser` capability.

## Example

Request body:

```json
{ "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0" }
```

Each frame is a page list, as in the `browser.list` example.

## Errors

- `unavailable` or `denied` when the workspace doesn't offer a browser.
