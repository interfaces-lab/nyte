---
title: settings.apply
description: Sets a setting to a new value and returns whether it was applied.
---

Sets a setting declared by the host or a loaded plugin to a new value. The value is checked
against the setting's schema and saved as the host's value. It answers `applied`, `invalid` with issues, or `unknown` when no
setting has the id.

## When to call it

From a settings screen. The settings and their schemas come from `settings` on
[`connection.watch`](/docs/reference/operations/connection/watch).

## Access

Needs `owner` authority. Host scope: the value applies host-wide. To change a session's settings,
use [`head.configure`](/docs/reference/operations/head/configure).

## Example

Request body:

```json
{ "id": "worktrees.idleDays", "value": 14 }
```

Response:

```json
{ "kind": "applied" }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors). A value the schema rejects is the `invalid` outcome.
