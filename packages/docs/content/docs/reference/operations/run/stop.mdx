---
title: run.stop
description: Stops a run.
---

Asks a run to stop. It answers `requested` once the stop is recorded, `settled` with how the run
ended when it had already ended, or `missing`. Child runs the run was waiting on stop too.

## When to call it

From a stop control on one run. Wait with [`run.settled`](/docs/reference/operations/run/settled)
to know when it ended.

## Access

Any principal with `participant` authority. Session scope.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "run": "4e2a6c8f-1b3d-4f5a-9c7e-0a2b4d6f8c1e"
}
```

Response:

```json
{ "kind": "requested" }
```

## Errors

- `stale` when the write lost to concurrent writes several times in a row.
