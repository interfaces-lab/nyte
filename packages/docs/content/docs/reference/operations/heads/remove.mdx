---
title: heads.remove
description: Deletes a named head.
---

Deletes a named head and its prompt override. Commits another head can still reach stay in the
session's tree. It answers
`removed`, `is-main` for main, `missing` when there is no head with the name, or `busy` while a run
is live on it.

## When to call it

When the user drops a branch they don't want, or after merging it.

## Access

Any principal with `participant` authority. Session scope.

## Example

Request body:

```json
{ "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f", "name": "try-sqlite" }
```

Response:

```json
{ "kind": "removed" }
```

## Errors

- `unknown` when no session has the id.
- `stale` when `expect` doesn't match the head's revision: `Head <name> moved since <revision>.`
