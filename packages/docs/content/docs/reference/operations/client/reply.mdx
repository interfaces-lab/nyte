---
title: client.reply
description: Answers an action another client asked this one to perform, with a result or an error.
---

Answers a request another client made of this one with
[`client.perform`](/docs/reference/operations/client/perform). `call` is the id the `perform` event
carried. Send exactly one of `result`, any JSON value the requester receives as its answer, or
`error`, `{ code, message }`, which the requester's call fails with. The host then delivers the next
request waiting in this client's queue.

## When to call it

Once for each `perform` event the client receives, after it has acted or decided not to.

## Access

Any principal with `participant` authority, and only on the WebSocket, from the client the request
was delivered to; over HTTP it answers `invalid`.

## Example

Input:

```json
{ "call": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f", "result": { "opened": true } }
```

Output:

```json
null
```

## Errors

- `invalid` with both `result` and `error`, or neither: `A reply carries exactly one of result and
error.`
- `unknown` for a call this client doesn't hold, such as one that already timed out.
