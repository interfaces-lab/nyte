---
title: git.discard
description: Discards local changes to the given files.
---

Discards the working tree changes to the given paths, and deletes untracked ones. This can't be
undone. Outcomes are as for [`git.stage`](/docs/reference/operations/git/stage).

## When to call it

From a discard action, after the user confirms. Pass `expect` so a change made after the user looked
isn't thrown away unseen.

## Access

Needs `owner` authority. Workspace scope, with the `git` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "paths": ["test/tz.test.ts"],
  "options": { "expect": "c1e3b5d7f9a1c3e5b7d9f1a3c5e7b9d1f3a5c7e9b1d3f5a7c9e1b3d5f7a9c1e3" }
}
```

Response:

```json
{
  "kind": "stale",
  "revision": "f9a1c3e5b7d9f1a3c5e7b9d1f3a5c7e9b1d3f5a7c9e1b3d5f7a9c1e3b5d7f9a1"
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer git.
