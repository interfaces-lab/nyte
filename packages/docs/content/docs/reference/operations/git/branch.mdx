---
title: git.branch
description: Creates a branch and optionally checks it out; checkout fails while a run is live.
---

Creates a branch from HEAD, and checks it out when `checkout` is true. Checking out answers `busy`
with the runs writing to the workspace while any are live, since switching would change files under
them. Otherwise it answers `applied`, `stale` or `rejected` with git's message.

## When to call it

From a "new branch" action.

## Access

Needs `owner` authority. Workspace scope, with the `git` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "input": { "name": "fix-date-test", "checkout": true }
}
```

Response:

```json
{ "kind": "busy", "runs": ["4e2a6c8f-1b3d-4f5a-9c7e-0a2b4d6f8c1e"] }
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer git.
