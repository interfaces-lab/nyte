Streams the files changed in a scope, the same value as
[`git.changes`](/docs/reference/operations/git/changes), first as it is and again each time the
status revision moves.

## When to call it

To keep a changes list current while the user or an agent edits files.

## Access

Any principal with `participant` authority. Workspace scope, with the `git` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "scope": { "kind": "worktree" }
}
```

Each frame is a change set, as in the `git.changes` example.

## Errors

- `unavailable` outside a repository, or when the workspace doesn't offer git.
