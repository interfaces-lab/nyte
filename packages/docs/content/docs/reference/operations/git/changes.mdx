---
title: git.changes
description: Lists the files changed in a scope, such as the worktree, staged files or a commit.
---

Lists the files changed in a scope, with each file's status, line stats, and the path it was renamed
from. Scopes are `worktree` (HEAD to the working tree), `staged` (HEAD to the index), `unstaged`
(the index to the working tree), `commit` (its parent to it), and `branch` (the merge base with
`base` to HEAD). Untracked files join `worktree` and `unstaged`. `ignoreWhitespace` affects the line stats, not which files
are listed.

## When to call it

To list a diff's files, such as a review of a branch or of one commit. Read the patches with
[`git.patches`](/docs/reference/operations/git/patches).

## Access

Any principal with `participant` authority. Workspace scope, with the `git` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "scope": { "kind": "branch", "base": "main" }
}
```

Response:

```json
{
  "revision": "c1e3b5d7f9a1c3e5b7d9f1a3c5e7b9d1f3a5c7e9b1d3f5a7c9e1b3d5f7a9c1e3",
  "files": [
    {
      "path": "src/date.ts",
      "status": "modified",
      "stat": { "kind": "text", "added": 1, "removed": 1 }
    }
  ]
}
```

## Errors

- `unavailable` outside a repository, or when the workspace doesn't offer git.
