---
title: language.inlayHints
description: Lists the inlay hints, such as parameter names and inferred types, in a range.
---

Lists the inlay hints in a range in position order: parameter names for Go and TypeScript calls with literal arguments, and Go constant values. A file no server handles, or whose server is `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

When a range of a document comes into view.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "main.go",
  "range": { "start": { "line": 0, "utf16Column": 0 }, "end": { "line": 38, "utf16Column": 0 } }
}
```

Response:

```json
[
  {
    "position": { "line": 13, "utf16Column": 36 },
    "label": "parent:",
    "kind": "parameter",
    "padLeft": false,
    "padRight": true
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
