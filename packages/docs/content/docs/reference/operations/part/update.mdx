---
title: part.update
description: Replaces a part's state.
---

Replaces a part's state. Pass `options.version` to make the update conditional on the version you
read. It answers `updated` with the new version, `invalid` with issues when the state fails the
kind's schema or the part is a built-in one, `stale` when the version moved, or `missing`.

## When to call it

When the part's owner changes what it shows, such as a progress card moving to its next step.

## Access

Any principal with `participant` authority. Session scope. Built-in parts can't be changed from a
client.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "part": "b2d4f6a8-0c1e-4b3d-9f5a-7c9e1b3d5f7a",
  "next": { "environment": "production", "commit": "3e1f9a2" },
  "options": { "version": 1 }
}
```

Response:

```json
{ "kind": "updated", "version": 2 }
```

## Errors

- `stale` when the write lost to concurrent writes several times in a row.
