title: part.watch
description: Streams a part's view each time it changes.
---

Streams one part's view each time it changes: kind, placement, state, version, status and owner,
from whichever head holds it. A frame is `null` while the session has no such part, such as after
it closed.

## When to call it

To render a single part outside its chat, such as a modal over the app. Inside a chat the head's
view already carries its parts.

## Access

Any principal with `participant` authority. Session scope.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "part": "b2d4f6a8-0c1e-4b3d-9f5a-7c9e1b3d5f7a"
}
```

First frame:

```json
{
  "id": "b2d4f6a8-0c1e-4b3d-9f5a-7c9e1b3d5f7a",
  "partKind": "deploy-approval",
  "placement": { "kind": "modal" },
  "state": { "environment": "staging", "commit": "3e1f9a2" },
  "version": 1,
  "status": { "kind": "live", "run": null },
  "owner": "deploy"
}
```

## Errors

- `unknown` when no session has the id; the host checks before the first frame.
