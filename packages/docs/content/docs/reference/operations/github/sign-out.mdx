---
title: github.signOut
description: Signs the host machine out of GitHub, or cancels a sign-in still waiting for its code.
---

Ends a sign-in still waiting for its code; otherwise removes the GitHub CLI's github.com login. It
answers the account state after.

## When to call it

From a "disconnect GitHub" button, or to cancel a sign-in.

## Access

Needs `owner` authority. Host scope: it signs out the whole machine.

## Example

Request body:

```json
{}
```

Response:

```json
{ "kind": "signed_out" }
```

## Errors

- `unavailable` when the host serves no GitHub login.
