Reads the GitHub account the host machine's GitHub CLI (`gh`) is signed in as on github.com. It
answers `ready` with the login, `signed_out`, `signing_in` with the one-time code while a sign-in
waits, `cli_missing` when `gh` isn't on the `PATH`, or `error` with what to do next.

## When to call it

To show GitHub's connection state in settings. One login serves every workspace on the machine.

## Access

Any principal with `participant` authority. Host scope.

## Example

Request body:

```json
{}
```

Response:

```json
{ "kind": "ready", "account": { "login": "ada", "name": "Ada Lovelace" } }
```

## Errors

- `unavailable` when the host serves no GitHub login: `This host has no GitHub CLI login to serve.`
