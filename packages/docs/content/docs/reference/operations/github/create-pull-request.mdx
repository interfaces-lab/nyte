---
title: github.createPullRequest
description: Opens a pull request for the workspace's pushed branch unless one is already open.
---

Opens a pull request for the checked-out branch, which must already be pushed. Without a title,
`gh` fills the title and body from the branch's commits. It answers `created` with the URL, or
`exists` with the pull request already open for the branch, and opens nothing then. It also answers
the precondition that stopped it: `cli_missing`, `signed_out`, `no_remote`, `detached`, or `failed`
with a message.

## When to call it

After [`git.push`](/docs/reference/operations/git/push), from a "create pull request" action.

## Access

Needs `owner` authority. Workspace scope, with the `github` capability.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "input": { "title": "Fix the flaky date test", "draft": true }
}
```

Response:

```json
{ "kind": "created", "url": "https://github.com/ada/shop/pull/42" }
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer GitHub.
