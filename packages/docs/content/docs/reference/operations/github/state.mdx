---
title: github.state
description: Reads the workspace's repository and the pull request for its branch, with checks.
---

Reads the GitHub repository the workspace's remotes name, and the pull request for its checked-out
branch with the checks on its head commit, each `pending`, `passed`, `failed` or `skipped`. The pull
request is `none` with no GitHub remote or a detached HEAD, and `unavailable` while the machine's
`gh` has no account that can read it.

## When to call it

To show a branch's pull request and CI status next to its changes.

## Access

Any principal with `participant` authority. Workspace scope, with the `github` capability.

## Example

Request body:

```json
{ "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0" }
```

Response:

```json
{
  "repository": {
    "owner": "ada",
    "name": "shop",
    "remoteName": "origin",
    "url": "https://github.com/ada/shop"
  },
  "pullRequest": {
    "kind": "ready",
    "pullRequest": {
      "number": 42,
      "title": "Fix the flaky date test",
      "url": "https://github.com/ada/shop/pull/42",
      "state": "OPEN",
      "draft": false,
      "headRefName": "fix-date-test",
      "baseRefName": "main",
      "checks": [{ "name": "test", "state": "passed" }]
    }
  }
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer GitHub.
