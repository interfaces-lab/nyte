title: jobs.recover
description: Finds a job again by its key, or reports how it ended or that it is gone.
---

Finds a running pty job again by the key [`jobs.start`](/docs/reference/operations/jobs/start)
gave it. It answers the job's view with its key while it runs, `ended` with how it ended, or
`missing` when this host process no longer has it.

## When to call it

When a terminal tab reopens after a reload and has its job's key saved.

## Access

Any principal with `participant` authority. Workspace scope; a key from another workspace answers
`missing`.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "key": "6b8d0f2a-4c1e-4a3b-9d5f-7e9a1c3b5d70"
}
```

Response:

```json
{ "kind": "ended", "end": { "kind": "exited", "code": 0, "reason": "exited" } }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
