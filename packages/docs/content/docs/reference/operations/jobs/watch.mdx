---
title: jobs.watch
description: Streams the workspace's jobs as they change.
---

Streams the workspace's jobs. The first frame is the whole list as `jobs`; each later frame is one
job that changed, as `job` with its new view, or `forgotten` with the id of one the list no longer
keeps. While the reader is behind, a job's own changes coalesce into its latest.

## When to call it

To keep a jobs or terminals panel current.

## Access

Any principal with `participant` authority. Workspace scope.

## Example

Request body:

```json
{ "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0" }
```

A frame after the first:

```json
{ "kind": "forgotten", "id": "8a0c2e4f-6b1d-4f3a-9c5e-7b9d1f3a5c7e" }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
