---
title: head.history
description: Returns older messages before a given message, with their turns.
---

Returns up to `limit` messages before the message `before` on a head, with the turns they belong
to, and the prompt of the earliest of those turns when it comes before them. A `before` the head
doesn't hold, or a `limit` of zero or less, answers an empty page.

## When to call it

When the user scrolls above the window a view holds. Pass the id of the oldest message you have.

## Access

Any principal with `participant` authority. Session scope.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "head": "main",
  "before": "7c1e9a3b-2d4f-4a6c-8e0b-1f3d5a7c9e2b",
  "limit": 50
}
```

Response, when nothing comes before:

```json
{ "messages": [], "leadingPrompt": null, "turns": [] }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
