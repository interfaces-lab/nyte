---
title: head.view
description: Reads the current transcript and state of a head.
---

Reads a head's view once: its last `tail` messages (200 by default), the queue, parts, turns,
usage, execution, background items, configuration, context, changed files, the command catalog,
and when the caller last saw it. It is the view the rows of
[`head.read`](/docs/reference/operations/head/read) make, read whole. Older messages come from
[`head.history`](/docs/reference/operations/head/history).

## When to call it

To render a chat once, such as a preview or a script. To keep it current, read its rows with
[`head.read`](/docs/reference/operations/head/read) after
[`events.subscribe`](/docs/reference/operations/events/subscribe). The view's `revision` is what
`expect` takes on edits and moves.

## Access

Any principal with `participant` authority. Session scope. `seenThrough` belongs to the caller.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "head": "main",
  "options": { "tail": 50 }
}
```

The response is a `SessionView`. Its first fields, with the rest left out here:

```json
{
  "revision": "2b4d6f8a-0c1e-4a3b-9d5f-7e9a1c3b5d7f",
  "seq": 128,
  "activation": { "kind": "active" },
  "messages": [],
  "queue": [],
  "leadingPrompt": null,
  "execution": { "kind": "idle", "lastRun": null },
  "seenThrough": 1767240300000
}
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
