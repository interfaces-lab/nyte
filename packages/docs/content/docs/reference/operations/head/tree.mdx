---
title: head.tree
description: Returns the tree of messages and branches behind a head.
---

Returns every commit in the session as a tree, in display order: each node's parent, depth,
whether it starts a branch, whether it is on this head's path, the heads whose tip it is, its kind,
and an 80-character preview of its text.

## When to call it

To draw a branch map of a chat, or to let the user pick a point to move a head to or to branch
from.

## Access

Any principal with `participant` authority. Session scope.

## Example

Request body:

```json
{ "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f", "head": "main" }
```

Response, with one node:

```json
{
  "revision": "2b4d6f8a-0c1e-4a3b-9d5f-7e9a1c3b5d7f",
  "tip": {
    "kind": "commit",
    "id": "a3f1c5e7b9d2f4a6c8e0b1d3f5a7c9e2b4d6f8a0c1e3b5d7f9a2c4e6b8d0f1a3"
  },
  "nodes": [
    {
      "id": "a3f1c5e7b9d2f4a6c8e0b1d3f5a7c9e2b4d6f8a0c1e3b5d7f9a2c4e6b8d0f1a3",
      "parent": null,
      "depth": 0,
      "branch": false,
      "active": true,
      "heads": ["main"],
      "kind": "user",
      "partKind": null,
      "preview": "Find out why the date test fails on CI",
      "at": 1767240000000,
      "run": null
    }
  ]
}
```
