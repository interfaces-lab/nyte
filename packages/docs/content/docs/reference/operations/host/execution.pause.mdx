Ends the host's model streams in flight and holds every new model request until
[`host.execution.resume`](/docs/reference/operations/host/execution.resume). Runs stay live: a run
whose stream was cut retries once the host resumes and continues where its committed text ends.
Pausing an already paused host changes nothing.

## When to call it

When the machine the host runs on is about to sleep, so no request is cut off mid-answer by the
network going away. Nyte.app calls it on macOS's suspend notice when the user keeps Pause agents
while asleep on.

## Access

Needs `owner` authority, and answers only on the host's local socket: never over the network or
the tailnet. Host scope.
