---
title: host.tailnet.status
description: Returns the status of the host's embedded tailnet node.
---

Returns the status of the host's embedded tailnet node: its `state`, the sign-in `authUrl` while
it waits for a login, its `dnsName` once it runs, whether `https` certificates are available, and
the `access` and `tags` it runs with. A host with the node turned off answers `state: "disabled"`.

## When to call it

To show the node's state in a settings screen, or to poll for `running` after
[`host.tailnet.configure`](/docs/reference/operations/host/tailnet.configure). A client that
already watches [`connection.watch`](/docs/reference/operations/connection/watch) reads the same
status from its `tailnet` field as it changes.

## Access

Needs `owner` authority, and answers only on the host's local socket: never over the network or
the tailnet. Host scope.

## Example

Request body:

```json
{}
```

Response:

```json
{
  "state": "running",
  "dnsName": "nyte.example.ts.net",
  "https": "available",
  "access": "owner",
  "tags": []
}
```

## Errors

- `denied` off the local socket: `host.tailnet.status answers only on the host's local socket.`
- `unavailable` when the host runs no tailnet node: `This host runs no tailnet node.`
