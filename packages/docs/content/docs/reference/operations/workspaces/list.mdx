---
title: workspaces.list
description: Lists the workspaces the host knows.
---

Lists the workspaces registered on the host, each with its target, identity, availability, trust,
session count and the runs writing to it.

## When to call it

To show a workspace picker, or to find the workspace id for a folder. A workspace that registered
and later went away still lists, with `availability` `unavailable`.

## Access

Any principal with `participant` authority. Host scope.

## Example

Request body:

```json
{}
```

Response:

```json
[
  {
    "id": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
    "target": { "kind": "local", "path": "/Users/ada/code/shop" },
    "identity": "e3a1c9f04b7d2e6a8c5f1b3d9e7a2c4f6b8d0e1a3c5f7b9d2e4a6c8f0b1d3e5a",
    "availability": { "kind": "available" },
    "projectResources": true,
    "trusted": true,
    "projectSources": [".nyte/plugins/review.ts", ".nyte/mcp.json"],
    "addedBy": "local",
    "sessions": 3,
    "writers": [],
    "isolation": null
  }
]
```
