---
title: workspaces.forget
description: Forgets a workspace and removes every session on it.
---

Unregisters a workspace and removes every session on it or on one of its worktrees, archived ones
too, with each session's children. It answers `busy` with the sessions that still have a live run,
and removes nothing, and `missing` when no workspace has the id.

Forgetting a source workspace leaves its own folder and files alone. Removing sessions also releases
their managed worktrees: the local provider may remove their folders and delete branches that still
point to their original base commit. It keeps folders with uncommitted changes and branches whose
commit has moved from that base.

## When to call it

When the user removes a workspace from the list. Confirm removal first: its sessions can't be
restored, and managed worktrees may be removed. Stop its running sessions before calling it.

## Access

Needs `owner` authority. Host scope.

## Example

Request body:

```json
{ "id": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0" }
```

Response:

```json
{ "kind": "busy", "sessions": ["0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f"] }
```

## Errors

Only the [errors every operation can raise](/docs/reference/operations#errors).
