---
title: workspaces.cleanWorktrees
description: Cleans eligible worktrees through their provider and returns how many it cleaned.
---

Asks each eligible git worktree's provider to clean it. A worktree is eligible when it has been idle
for the `worktrees.idleDays` setting, or when more worktrees exist than `worktrees.maxCount` allows,
and none of its sessions has a live run. `cleaned` counts worktrees whose provider reported cleanup,
not the files or folders removed.

The built-in local provider removes recognized ignored generated folders, such as `node_modules`
and build caches. It keeps the worktree and its branch, and does not require a clean git status.

## When to call it

From a "clean up worktrees" action, or on a schedule. The provider decides what it can remove; one
that fails to clean is skipped, not reported.

## Access

Needs `owner` authority. Host scope.

## Example

Request body:

```json
{}
```

Response:

```json
{ "cleaned": 2 }
```
