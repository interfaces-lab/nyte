---
title: workspaces.cleanWorktrees
description: Removes leftover worktrees with no changes and returns how many it cleaned.
---

Removes leftover git worktrees that chats ran in. A worktree is cleaned when it has been idle for
the `worktrees.idleDays` setting, or when more worktrees exist than `worktrees.maxCount` allows,
and none of its sessions has a live run. It answers how many it removed.

## When to call it

From a "clean up worktrees" action, or on a schedule. The provider decides what it can remove; one
that fails to clean is skipped, not reported.

## Access

Needs `owner` authority. Host scope.

## Example

Request body:

```json
{}
```

Response:

```json
{ "cleaned": 2 }
```
