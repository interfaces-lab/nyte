---
title: session.info
description: Reads a session's name, state and other details.
---

Reads one session's row: its name, parent, workspace, pinned and archived flags, activation, each
head with its tip, execution and unread state, and its creation and last activity times. It is the
same row [`sessions.watch`](/docs/reference/operations/sessions/watch) and
[`sessions.list`](/docs/reference/operations/sessions/list) carry.

## When to call it

To check a saved session id still exists, or to read one session without watching the whole list.
A head's `unread` is true when its tip is past what the calling principal marked seen with
[`head.see`](/docs/reference/operations/head/see).

## Access

Any principal with `participant` authority. Session scope: the input names the session.

## Example

Request body:

```json
{ "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f" }
```

Response:

```json
{
  "id": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "name": "Fix the flaky test",
  "parent": null,
  "call": null,
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "pinned": false,
  "archived": false,
  "activation": { "kind": "active" },
  "heads": [
    {
      "name": "main",
      "tip": {
        "kind": "commit",
        "id": "a3f1c5e7b9d2f4a6c8e0b1d3f5a7c9e2b4d6f8a0c1e3b5d7f9a2c4e6b8d0f1a3"
      },
      "stack": null,
      "execution": { "kind": "idle", "lastRun": null },
      "unread": true,
      "background": { "working": 0, "waiting": 0 }
    }
  ],
  "createdAt": 1767240000000,
  "lastActivityAt": 1767240300000
}
```

## Errors

- `unknown` when no session has the id: `No session has the id <id>.`
