---
title: session.update
description: Renames, pins, archives or moves a session to another workspace.
---

Changes a session's name, pinned or archived flag, or moves it to another workspace. A field left
out keeps its value, and a `name` of `null` clears the name. A patch that changes nothing succeeds
without writing.

Moving to another workspace answers `busy` with the live runs while any run is live, and
`unknown-workspace` when the workspace isn't registered. After a move, the session's environment
detaches, its plugins reload, and a worktree it ran in is released.

## When to call it

From rename, pin, archive and "move to workspace" actions on a session.

## Access

Any principal with `participant` authority. Session scope.

## Example

Request body:

```json
{
  "session": "0b7d2c4e-6f1a-4b3c-9e8d-7a6b5c4d3e2f",
  "patch": { "name": "Fix the date test", "pinned": true }
}
```

Response:

```json
{ "kind": "updated" }
```

## Errors

- `unknown` when no session has the id.
- `stale` when the write lost to concurrent writes several times in a row.
