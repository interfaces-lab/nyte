---
title: mcp.remove
description: Removes an MCP server from the user or project mcp.json.
---

Removes a server from one `mcp.json`, `user` or `project`. Its stored OAuth credentials stay. It
answers `updated`, `missing` when that file has no server with the name, or `invalid`.

## When to call it

From a delete action on a server.

## Access

Needs `owner` authority. Workspace scope.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "server": "docs",
  "scope": "user"
}
```

Response:

```json
{ "kind": "missing" }
```

## Errors

- `unavailable` when the host has no MCP servers.
- `unknown` when no workspace has the id.
