---
title: mcp.logout
description: Deletes an MCP server's stored OAuth credentials.
---

Deletes an MCP server's stored OAuth credentials. The server asks for sign-in again. It answers
`updated`, `missing` or `invalid`.

## When to call it

When the user signs out of a server, or to sign in as someone else.

## Access

Needs `owner` authority. Workspace scope.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "server": "docs"
}
```

Response:

```json
{ "kind": "updated" }
```

## Errors

- `unavailable` when the host has no MCP servers.
- `unknown` when no workspace has the id.
