---
title: mcp.grants.revoke
description: Revokes an MCP client's grant and every token issued under it.
---

Revokes an outside agent's MCP grant. Its access and refresh tokens stop working at once, and its
open calls end.

## When to call it

When an agent should no longer reach this host, or a token may have leaked.

## Access

Needs `owner` authority, and answers only on the host's local socket. Host scope.

## Example

Request body:

```json
{ "id": "u2Q0b3hYxW5zLk1e" }
```

Response:

```json
null
```

## Errors

- `unknown` when no grant has the id: `No MCP grant has the id u2Q0b3hYxW5zLk1e.`
- `unavailable` when the host serves no MCP endpoint.
- `denied` off the local socket.
