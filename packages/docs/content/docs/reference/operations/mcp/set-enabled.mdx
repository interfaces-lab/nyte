---
title: mcp.setEnabled
description: Turns an MCP server on or off in the mcp.json that defines it.
---

Turns an MCP server on or off by writing `enabled` to the `mcp.json` that defines it, or to the
project override of a user server when there is one. The rest of the file stays as it was. It
answers `updated`, `missing` or `invalid`.

## When to call it

From an on/off switch next to each server.

## Access

Needs `owner` authority. Workspace scope.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "server": "docs",
  "enabled": false
}
```

Response:

```json
{ "kind": "updated" }
```

## Errors

- `unavailable` when the host has no MCP servers.
- `unknown` when no workspace has the id.
