Both run the agent on your machine and keep each session in a local SQLite database.

## <PlatformIcon name="IconFinderFace" /> macOS [#macos]

<DesktopDownload />

<small>
  Open the disk image and drag Nyte to Applications. Older versions are on the [releases
  page](https://github.com/interfaces-lab/nyte/releases).
</small>

The desktop app includes its own host, so there is nothing else to install.

## <PlatformIcon name="IconConsole" /> Terminal [#terminal]

For macOS and Linux, on arm64 and x64. The installer puts `nyte` on your PATH.

```sh
curl -fsSL https://nyte.sh/install | sh
```

Sign in, then start a session:

```sh
nyte login
nyte
```

`nyte` uses the same host as the desktop app, so the same chats show in both. Without the app, the
first `nyte` starts the host in the background, and it keeps running after you quit. A host that's
already running doesn't see an API key you export only in your shell; save it with `nyte login`.

<small>
  Run `nyte -p "your prompt"` for a single answer without the interface. The [CLI
  guide](https://github.com/interfaces-lab/nyte/blob/main/packages/cli/docs/README.md) covers
  commands and configuration.
</small>

## Updates [#updates]

The desktop app and the terminal client update separately, and each follows its own channel:
**stable** releases, or **nightly** builds of every change on `main`.

The desktop app downloads updates in the background and installs them when you restart. To
change its channel, open **Settings > Developer** and pick an **Update channel**.

In a terminal, `nyte update` installs the newest release on the channel you're on. To switch
channels:

```sh
nyte update nightly
nyte update stable
```

Switching to stable installs the newest stable release, even when it's older than the
nightly you had. To have `nyte` update itself when it starts, turn on **Auto-update** in
`/settings`.

<small>
  Both apps keep your sessions in the same database, and a nightly can upgrade it to a format the
  stable release can't read yet. Stable then refuses to open your sessions until the next stable
  release, so keep both apps on nightly once either uses it.
</small>
