---
title: Examples
description: Short programs that stream answers, add tools, answer approvals, stop runs and serve a host.
---

Each example is a file you can run with `node`. Most open a host with `sdk.open({})`, which works in
the current folder and needs a model you're signed in to;
[Build an agent app](/docs/build/composition#build-the-chat) shows the sign-in.

A host is three choices: where chats are stored, where the agent works, and which plugins it loads.
Each has a default. The examples below change one of them or use one more handle.

## Stream the answer [#stream-the-answer]

The host serves its rows on a local listener, and `openHost` follows them: a head store for the
chat's rows and `live.text` for the text a part streams. `print` writes the new end of each text
part from this message's run, and stops when that run ends.

```ts tab="stream.ts"
import process from "node:process";
import { isPart, text } from "@nyte-ai/plugin/core";
import type { SendReceipt, Session } from "@nyte-ai/sdk";
import { headView, streamText, withStreamedText } from "@nyte-ai/sdk/client";
import type { HostConnection, StreamedText } from "@nyte-ai/sdk/client";

export async function print(live: HostConnection, session: Session, receipt: SendReceipt) {
  const landed = await receipt.landed();
  const run = landed.kind === "landed" ? landed.run : null;
  const written = new Map<string, number>();
  const store = live.head(session.id, session.name, { tail: 20 });
  const done = Promise.withResolvers<void>();
  let texts: StreamedText = new Map();

  const show = () => {
    const snapshot = store.snapshot();

    if (snapshot === null) return;
    const view = withStreamedText(headView(snapshot), texts);
    const turns = new Set(view.turns.filter((turn) => turn.run === run).map((turn) => turn.id));

    for (const message of view.messages) {
      if (!turns.has(message.turn) || !isPart(message, text)) continue;
      const { markdown } = message.state;
      process.stdout.write(markdown.slice(written.get(message.id) ?? 0));
      written.set(message.id, markdown.length);
    }

    if (view.execution.kind === "idle" && view.execution.lastRun?.id === run) done.resolve();
  };

  const stopRows = store.subscribe(show);

  const stopText = live.text((update) => {
    texts = streamText(texts, update);
    show();
  });

  show();
  await done.promise;
  stopText();
  stopRows();
  store.close();
}
```

```ts tab="answer.ts"
import { sdk } from "@nyte-ai/sdk";
import { openHost } from "@nyte-ai/sdk/client";
import { print } from "./stream";

const host = await sdk.open({});
const token = crypto.randomUUID();

const listener = await host.listen({
  transport: { kind: "http", hostname: "127.0.0.1", port: 0 },
  auth: { kind: "token", token },
});

const live = openHost(listener.address ?? "", {
  credentials: { kind: "token", token },
  client: { kind: "other", name: "stream", version: "1.0.0" },
});

const { session, receipt } = await host.sessions.start({ content: "Explain this repository" });

await print(live, session, receipt);
live.release();
await host.close();
```

`landed()` resolves once the message reaches the chat, with the run that answers it.
`tail: 20` keeps the view to the last 20 messages.

## Chat in a terminal [#chat-in-a-terminal]

The first message starts the chat. Every message after that is a `send`. This uses `print` from
`stream.ts` above.

```ts title="chat.ts"
import process from "node:process";
import { createInterface } from "node:readline/promises";
import { sdk } from "@nyte-ai/sdk";
import { openHost } from "@nyte-ai/sdk/client";
import { print } from "./stream";

const host = await sdk.open({});
const token = crypto.randomUUID();

const listener = await host.listen({
  transport: { kind: "http", hostname: "127.0.0.1", port: 0 },
  auth: { kind: "token", token },
});

const live = openHost(listener.address ?? "", {
  credentials: { kind: "token", token },
  client: { kind: "other", name: "chat", version: "1.0.0" },
});

const prompt = createInterface({ input: process.stdin, output: process.stdout });

let { session, receipt } = await host.sessions.start({ content: await prompt.question("> ") });

while (true) {
  await print(live, session, receipt);
  receipt = await session.send(await prompt.question("\n> "));
}
```

## Give the agent a tool [#give-the-agent-a-tool]

A tool is an object with a schema and an `execute` function. A plugin carries it into every chat.

```ts title="weather.ts"
import type { Plugin } from "@nyte-ai/plugin/core";
import { sdk } from "@nyte-ai/sdk";
import type { ToolDefinition } from "@nyte-ai/sdk";
import { standard } from "@nyte-ai/schema";
import { Type } from "typebox";

const weather: ToolDefinition<{ city: string }> = {
  name: "weather",
  description: "Get the current weather in a city.",
  parameters: standard(Type.Object({ city: Type.String() })),
  class: () => ({ kind: "custom", label: "Weather" }),
  effects: "none",
  replay: "safe",
  async execute({ city }) {
    const response = await fetch(`https://wttr.in/${encodeURIComponent(city)}?format=3`);
    return { content: [{ kind: "text", text: await response.text() }] };
  },
};

const tools = { id: "weather", contribute: { tools: [weather] } } satisfies Plugin;

const host = await sdk.open({ plugins: [tools] });
const { receipt } = await host.sessions.start({ content: "Do I need an umbrella in Oslo?" });

await receipt.settled();
```

`effects: "none"` says the tool doesn't write files, so the host skips the snapshot around it.
`replay: "safe"` says running the call twice does no harm, so the host may run it again after a
crash. [Plugins](/docs/plugins) covers the rest of what a plugin can add.

## Ask before tool calls [#ask-before-tool-calls]

With the `permissions` setting on `ask`, the agent waits for an answer before it runs a command or
changes a file. Each request shows up in the chat's view, here followed through a head store as in
[Stream the answer](#stream-the-answer). `openApprovals` lists the ones nobody has answered, and
`act` answers one.

```ts title="approve.ts"
import process from "node:process";
import { createInterface } from "node:readline/promises";
import { approvalPrompt, openApprovals } from "@nyte-ai/plugin/approvals/schema";
import { sdk } from "@nyte-ai/sdk";
import { headView, openHost } from "@nyte-ai/sdk/client";

const host = await sdk.open({});
const token = crypto.randomUUID();

const listener = await host.listen({
  transport: { kind: "http", hostname: "127.0.0.1", port: 0 },
  auth: { kind: "token", token },
});

const live = openHost(listener.address ?? "", {
  credentials: { kind: "token", token },
  client: { kind: "other", name: "approve", version: "1.0.0" },
});

const prompt = createInterface({ input: process.stdin, output: process.stdout });

await host.settings.apply("permissions", "ask");

const { session, receipt } = await host.sessions.start({
  content: "Run the tests and fix what fails",
});
const landed = await receipt.landed();
const run = landed.kind === "landed" ? landed.run : null;
const store = live.head(session.id, session.name, { tail: 20 });
const asked = new Set<string>();
const done = Promise.withResolvers<void>();
let answering = Promise.resolve();

const check = () => {
  const snapshot = store.snapshot();

  if (snapshot === null) return;
  const view = headView(snapshot);

  for (const request of openApprovals(view)) {
    if (asked.has(request.part)) continue;
    asked.add(request.part);

    answering = answering.then(async () => {
      const { title, detail } = approvalPrompt(request);
      const answer = await prompt.question(`${title}\n${detail}\nAllow? [y/N] `);

      await session.part(request.part).act(answer === "y" ? "once" : "deny", {});
    });
  }

  if (view.execution.kind === "idle" && view.execution.lastRun?.id === run) done.resolve();
};

const stopRows = store.subscribe(check);

check();
await done.promise;
stopRows();
store.close();
live.release();
prompt.close();
await host.close();
```

`approvalPrompt` returns the same question and detail the desktop app shows, such as "Run this
command?" and the command. The answers are `once`, `session`, which allows that tool for the rest
of the chat, and `deny`. The setting is saved in the store, so later chats ask too until you apply
`"full"` again. `"auto-edit"` lets the agent edit files in the folder and asks before commands,
edits outside it and other tools.

## Stop a run that takes too long [#stop-a-run]

`receipt.stop()` stops the work behind a message: it withdraws the message if it's still queued,
or stops the run answering it.

```ts title="deadline.ts"
import { sdk } from "@nyte-ai/sdk";

const host = await sdk.open({});
const { receipt } = await host.sessions.start({ content: "Find every flaky test" });

const timer = setTimeout(() => void receipt.stop(), 5 * 60_000);
const end = await receipt.settled();

clearTimeout(timer);
console.log(end.kind);
await host.close();
```

`settled()` resolves either way. A run that finished gives `completed`, and one cut short gives
`stopped`. To stop everything in a chat at once, see
[Stop everything](/docs/sdk/guides/send-messages#stop-everything).

## Read token usage [#read-token-usage]

A completed run reports the tokens it used and their cost. `models.usage()` reads how much of each
signed-in account's plan limits is used.

```ts title="usage.ts"
import { sdk } from "@nyte-ai/sdk";

const host = await sdk.open({});
const { receipt } = await host.sessions.start({
  content: "Write a changelog entry for the last commit",
});
const end = await receipt.settled();

if (end.kind === "completed") {
  const { input, output, total, cost } = end.usage;
  console.log(`${input} in, ${output} out, ${total} tokens, cost ${cost.total}`);
}

for (const provider of await host.models.usage()) {
  if (provider.state.kind !== "ready") continue;
  for (const limit of provider.state.limits) {
    console.log(`${provider.name} ${limit.label}: ${limit.used} of ${limit.limit}`);
  }
}

await host.close();
```

`usage` also has `cacheRead`, `cacheWrite` and `reasoning`. `models.usage()` needs owner authority,
which a host from `sdk.open` has.

## Chat without a folder [#chat-without-a-folder]

Swap the environment for one with no files or processes, and keep chats in your own store. The
agent can still answer, but it has no folder to read or commands to run.

```ts title="chat-only.ts"
import { sqliteStore } from "@nyte-ai/host";
import { chatOnlyProvider } from "@nyte-ai/host/providers";
import { sdk } from "@nyte-ai/sdk";

const store = sqliteStore({ path: "./chat.db" });
const host = await sdk.open({
  store,
  plugins: [{ id: "chat-only", environment: chatOnlyProvider() }],
  workspace: { kind: "chat-only", locator: null },
});
const { receipt } = await host.sessions.start({ content: "Draft a polite reminder email" });

await receipt.settled();
await host.close();
await store.close();
```

A store you pass stays yours, so close it after the host.

## Work on a branch of its own [#work-on-a-branch]

`isolation: "worktree"` gives the chat a git worktree on a new branch, with your uncommitted changes
copied in. Your checkout stays as it was.

```ts title="upgrade.ts"
import { sdk } from "@nyte-ai/sdk";

const host = await sdk.open({});
const { receipt } = await host.sessions.start({
  content: "Upgrade the test runner and fix what breaks",
  isolation: "worktree",
});

await receipt.settled();
```

Removing the chat removes the worktree. It keeps the folder while it has uncommitted changes, and
the branch once it has commits. A folder outside git throws `SdkError("unavailable")`.

## Ask several questions at once [#ask-several-questions]

Chats are independent, so `Promise.all` runs them side by side.

```ts title="survey.ts"
import { isPart, text } from "@nyte-ai/plugin/core";
import { sdk } from "@nyte-ai/sdk";

const host = await sdk.open({});
const questions = ["Where is auth handled?", "What does CI run?", "Which tests are slowest?"];

const answers = await Promise.all(
  questions.map(async (content) => {
    const { session, receipt } = await host.sessions.start({ content });
    await receipt.settled();
    const { messages } = await session.view();
    return messages.findLast((message) => isPart(message, text))?.state.markdown ?? "";
  }),
);

for (const [index, question] of questions.entries()) {
  console.log(`# ${question}\n\n${answers[index]}\n`);
}

await host.close();
```

## List chats as they change [#list-chats]

`live.directory` is a store of the chat list, and its listener runs each time the list changes.
`limit` caps it at 20 chats.

```ts title="sessions.ts"
import { sdk } from "@nyte-ai/sdk";
import { openHost } from "@nyte-ai/sdk/client";

const host = await sdk.open({});
const token = crypto.randomUUID();

const listener = await host.listen({
  transport: { kind: "http", hostname: "127.0.0.1", port: 0 },
  auth: { kind: "token", token },
});

const live = openHost(listener.address ?? "", {
  credentials: { kind: "token", token },
  client: { kind: "other", name: "sessions", version: "1.0.0" },
});

const sessions = live.directory({ limit: 20 });

sessions.subscribe(() => {
  const snapshot = sessions.snapshot();

  if (snapshot === null) return;
  console.table(snapshot.ids.map((id) => ({ name: snapshot.rows.get(id)?.name, id })));
});
```

## Serve it and connect from anywhere [#serve-it]

Every example above works over the network. Put the host on HTTP, then swap `sdk.open` for
`sdk.connect` in the client.

```ts tab="serve.ts"
import process from "node:process";
import { sdk } from "@nyte-ai/sdk";

const host = await sdk.open({});

await host.listen({
  transport: { kind: "http", port: 8787 },
  auth: { kind: "token", token: process.env.NYTE_TOKEN ?? "" },
});
```

```ts tab="client.ts"
import process from "node:process";
import { sdk } from "@nyte-ai/sdk/client";

const connection = await sdk.connect({
  url: "http://127.0.0.1:8787",
  credentials: { kind: "token", token: process.env.NYTE_TOKEN ?? "" },
});
```

Set `NYTE_TOKEN` to the same secret of at least 16 characters in both. The token grants full access
to the host; to give each device its own revocable credential, use
[pairing](/docs/sdk/guides/choose-an-entry-point#give-each-device-its-own-credential).

[Build an agent app](/docs/build/composition#build-the-chat) puts a host behind a chat page in Vite,
Next.js, Svelte, Vue, Nuxt or Solid.
