## Desktop app

The desktop app is built for Apple Silicon Macs. Download the latest disk image from
[GitHub releases](https://github.com/interfaces-lab/nyte/releases/latest), open it, and drag
Nyte to Applications. The app embeds the host, so it needs nothing else installed.

## CLI

The installer places a `nyte` binary on your `PATH`. It has prebuilt binaries for macOS and
Linux on arm64 and x64.

```sh
curl -fsSL https://nyte.sh/install | sh
```

Sign in, then start a session:

```sh
nyte login
nyte
```

Run a single prompt without opening the TUI:

```sh
nyte -p "your prompt"
```

See the [user guide](https://github.com/interfaces-lab/nyte/blob/main/packages/cli/docs/README.md)
for commands and configuration.
