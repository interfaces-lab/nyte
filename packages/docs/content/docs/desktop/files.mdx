title: Files
description: Browse, edit, split and review your project's files in the desktop app's workbench.
---

The Files tab is the workbench's editor: a file tree, editors you can split side by side, and the
agent's changes marked in the margin. Open it from the workbench with **New workbench tab** ›
**Files**. Shortcuts below are for macOS; use `Ctrl` for `⌘` on Linux.

## Open files [#open]

Click a file in the tree to open it as a preview, shown in italics. The next file you click
replaces the preview. Double-click a file or its tab, or start editing, to keep it open.

| Shortcut | What it does                                     |
| -------- | ------------------------------------------------ |
| `⌘P`     | Go to a file by name                             |
| `⌃G`     | Go to a line; type `:12` or `:12:4` for column 4 |
| `⇧⌘O`    | Go to a symbol in the open file                  |
| `⌘S`     | Save                                             |
| `⌘F`     | Search the workspace                             |

All three go-to shortcuts open the same box: type `:` for a line or `@` for a symbol. Click
**Ln, Col** at the bottom right of the editor to go to a line too.

Symbols come from the lines that start declarations: functions, classes, types and variables in
TypeScript, JavaScript, Python, Go and Rust, and headings in Markdown. The **Outline** under the
tree lists them; click one to go there.

## The file tree [#tree]

- **All** shows every file, **Changed** only the files git reports as changed, with their count.
- **Filter files** narrows the tree to paths that contain what you type.
- A letter beside a file shows its git status: `M` modified, `A` added, `U` untracked, `D` deleted.

Right-click a file or folder for these actions:

| Action               | What it does                                               |
| -------------------- | ---------------------------------------------------------- |
| New File, New Folder | Creates it inside the folder; type its name in the tree    |
| Rename (`F2`)        | Renames in place, a folder with everything in it           |
| Duplicate            | Copies the file or folder beside itself as `name copy`     |
| Delete               | Deletes it; see [undo](#undo)                              |
| Add File to Chat     | Mentions the file in the message you're writing            |
| Copy Path            | Copies the absolute path, or the path inside the workspace |
| Reveal in Finder     | Shows it in Finder                                         |

A rename, move or duplicate never replaces what's already at the new name. Renaming a folder moves
it in one step with everything in it, including files git ignores such as `.env`, links, empty
folders and file permissions. Open tabs and unsaved edits under it follow it to the new path.

The right-click menu is part of the desktop app; in a browser, rename with `F2`.

### Undo a delete [#undo]

In a git repository, **Delete** shows **Undo** for a few seconds. Nyte keeps what you deleted in the
repository's git folder until the host restarts, so undo brings back the whole folder, ignored files
included. Outside a repository Nyte asks first, then deletes for good.

## Split editors [#split]

Click **Split Editor Right** or press `⌘\` to open the current file in a new editor group beside
it. Right-click a tab for **Split Right** or **Split Left**.

- With two or more groups, each has its own row of tabs. The workbench's tab strip shows the
  files of the group you last clicked.
- Drag a tab or a file from the tree onto a group to open it there, or onto a group's left or right
  edge to open it in a new group beside it.
- A file open in two groups is one file: an edit in one shows in the other.
- **Close Group** closes a group's tabs. A group closes once its last tab does.

Splits last until you quit; the next start opens every file in one group.

## Review changes in the margin [#changes]

Lines that differ from the last commit are marked in the gutter: green for added, blue for changed,
red for removed. Click a mark to see what the lines were before, and **Revert** to put them back.
`⌥F3` and `⇧⌥F3` step through the changes.

## Add code to the chat [#add-to-chat]

Select lines and choose **Add to Chat** in the popover that appears, or press `⇧⌘L`. The message
you're writing gets a mention of those lines, such as `date.ts:12-18`, which the agent reads from
the file. Right-click the editor or a tab for **Add File to Chat**.

## Options [#options]

**File options** (`…`) in the toolbar has:

- **Line Numbers**, **Word Wrap**, **Git Blame**, **Auto Save** and **Format on Save**
- **Move Side Panel Left** or **Right**, for the tree and search
- **View Source** or **View Document** for a Markdown file
- **Discard Changes** to reload the file from disk

Code folding and choosing the indentation or language by hand aren't available yet.
