`@nyte-ai/ui` has styled [Base UI](https://base-ui.com) controls and chat components, each
imported from its own subpath.

```ts
import "@nyte-ai/ui/ui.css";
import { Button } from "@nyte-ai/ui/button";
import { Popover } from "@nyte-ai/ui/popover";
```
