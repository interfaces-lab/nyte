```ts title="Import"
import { Collapsible } from "@nyte-ai/ui/collapsible";
```

A trigger that shows and hides one panel. Use it for detail a reader opens on demand, such as tool
output or earlier messages.

## Usage

- `defaultOpen` leaves the panel uncontrolled. `open` with `onOpenChange` controls it.
- Use `variant="plain"` when another styled part, such as `Row.Primary`, renders the trigger.
- `Collapsible.Root` and `Collapsible.Panel` bring no look of their own. Lay them out with `xstyle`.
- `Collapsible.Panel` defaults `hiddenUntilFound` to `true`. The closed panel stays in the DOM, and
  find-in-page can match its text and open it. Pass `hiddenUntilFound={false}` to unmount it.

## Anatomy

```tsx
<Collapsible.Root>
  <Collapsible.Trigger>
    <Collapsible.Chevron />
  </Collapsible.Trigger>
  <Collapsible.Panel />
</Collapsible.Root>
```

### Controlled

```tsx
const [open, setOpen] = useState(false);

<Collapsible.Root open={open} onOpenChange={setOpen}>
  <Collapsible.Trigger>
    Earlier messages
    <Collapsible.Chevron />
  </Collapsible.Trigger>
  <Collapsible.Panel>{messages}</Collapsible.Panel>
</Collapsible.Root>;
```

### A row that opens a panel

```tsx
<Collapsible.Root open={expanded} onOpenChange={setExpanded}>
  <Row>
    <Row.Primary render={<Collapsible.Trigger variant="plain" />}>
      <Row.Leading>
        <Icon name={expanded ? "folder-open" : "folder"} size={14} />
      </Row.Leading>
      <Row.Label>{name}</Row.Label>
    </Row.Primary>
  </Row>
  <Collapsible.Panel>{sessions}</Collapsible.Panel>
</Collapsible.Root>
```

## Props

Every part takes `xstyle`, and `className` and `style` as plain values, not functions of state.
See [Theming](/docs/components/foundations/theming).

### Trigger

| Prop      | Type                      | Default        | Description                           |
| --------- | ------------------------- | -------------- | ------------------------------------- |
| `variant` | `"disclosure" \| "plain"` | `"disclosure"` | Inline toggle look, or a bare button. |

### Chevron

Renders a `<span>` with `aria-hidden`, holding a `chevron-right` [icon](/docs/components/components/icon).
It takes every `<span>` prop, plus:

| Prop   | Type     | Default | Description          |
| ------ | -------- | ------- | -------------------- |
| `size` | `number` | `11`    | Icon size in pixels. |

## Accessibility

- The trigger renders a native `<button>` with `aria-expanded`, and `aria-controls` pointing at the
  panel while it is open. Enter and Space toggle it.
- Rendering the trigger as something other than a `<button>` needs `nativeButton={false}`.
- `disclosure` draws a focus ring. With `plain`, the rendered part owns focus styling.
