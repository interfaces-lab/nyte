```ts title="Import"
import { Input, InputGroup } from "@nyte-ai/ui/input";
```

`InputGroup` frames an `Input` with the icons or controls beside it. For multi-line text, use
[Textarea](/docs/components/components/textarea).

## Usage

- Inside an `InputGroup`, set `size` and `variant` on the group. The `Input` drops its frame and
  fills the row.

## Anatomy

```tsx
<InputGroup>
  <Icon />
  <Input />
</InputGroup>
```

### Controlled

```tsx
const [query, setQuery] = useState("");

<Input aria-label="Search" value={query} onValueChange={setQuery} />;
```

## Props

### Input

Takes every Base UI `Input` prop except the native `size` attribute. `className` and `style` take
plain values, not functions of state.

| Prop                           | Type                                                | Default                             | Description |
| ------------------------------ | --------------------------------------------------- | ----------------------------------- | ----------- |
| `variant`                      | `"raised" \| "quiet" \| "bare"`                     | `"raised"`, `"bare"` inside a group |             |
| `size`                         | `"md" \| "lg" \| "xl"`                              | `"md"`, or the group's size         |             |
| `className`, `style`, `xstyle` | see [Theming](/docs/components/foundations/theming) |                                     |             |

### InputGroup

Takes every native `<label>` attribute.

| Prop                           | Type                                                | Default    | Description                          |
| ------------------------------ | --------------------------------------------------- | ---------- | ------------------------------------ |
| `variant`                      | `"raised" \| "quiet"`                               | `"raised"` |                                      |
| `size`                         | `"md" \| "lg" \| "xl"`                              | `"md"`     | Height, and the size of its `Input`. |
| `className`, `style`, `xstyle` | see [Theming](/docs/components/foundations/theming) |            |                                      |

## Accessibility

- `InputGroup` renders a `<label>`. An `aria-label` on the input still wins as its name.
- Focus recolors the border of the input, or of its group.
