```ts title="Import"
import {
  Autocomplete,
  AutocompleteCollection,
  AutocompleteContent,
  AutocompleteEmpty,
  AutocompleteGroup,
  AutocompleteGroupLabel,
  AutocompleteInput,
  AutocompleteItem,
  AutocompleteList,
  AutocompleteSeparator,
  AutocompleteStatus,
  AutocompleteTrigger,
} from "@nyte-ai/ui/autocomplete";
```

A search field for a long list, such as fonts or models. For a short list, use
[Select](/docs/components/components/select).

## Usage

- Pass the current value as the children of `AutocompleteTrigger`.
- Pass the data to `items` on `Autocomplete` and render each entry from a function child of
  `AutocompleteList`. Inside an `AutocompleteGroup`, render its entries with
  `AutocompleteCollection`.
- Give each `AutocompleteItem` a `value`. Act on a pick in its `onClick`, and mark the current one
  with `selected`.
- `value` is the search text. Clear it in `onOpenChange` so the next open starts empty.
- To nest the list in another surface, such as a submenu, set `inline` and `open` on
  `Autocomplete`, drop `AutocompleteContent`, and set [`variant="inline"`](#variant).
- Keep `AutocompleteStatus` and `AutocompleteEmpty` mounted and change their children, so screen
  readers announce the change.

## Anatomy

```tsx
<Autocomplete>
  <AutocompleteTrigger />
  <AutocompleteContent>
    <AutocompleteInput />
    <AutocompleteStatus />
    <AutocompleteList>
      <AutocompleteGroup>
        <AutocompleteSeparator />
        <AutocompleteGroupLabel />
        <AutocompleteCollection>
          <AutocompleteItem />
        </AutocompleteCollection>
      </AutocompleteGroup>
    </AutocompleteList>
    <AutocompleteEmpty />
  </AutocompleteContent>
</Autocomplete>
```

### Searchable picker

<Preview>
  <AutocompleteDemo />
</Preview>

```tsx
interface ModelGroup {
  readonly label: string;
  readonly items: readonly string[];
}

const groups: readonly ModelGroup[] = [
  { label: "Anthropic", items: ["claude-opus-4-6", "claude-sonnet-4-6", "claude-haiku-4-5"] },
  { label: "OpenAI", items: ["{{modelId}}"] },
  { label: "Google", items: ["gemini-3-pro"] },
];

const [model, setModel] = useState("claude-sonnet-4-6");
const [search, setSearch] = useState("");

<Autocomplete
  items={groups}
  value={search}
  autoHighlight
  onValueChange={setSearch}
  onOpenChange={(open) => {
    if (!open) setSearch("");
  }}
>
  <AutocompleteTrigger aria-label="Model">{model}</AutocompleteTrigger>
  <AutocompleteContent>
    <AutocompleteInput aria-label="Search models" placeholder="Search models" />
    <AutocompleteList>
      {(group: ModelGroup, index: number) => (
        <AutocompleteGroup key={group.label} items={group.items}>
          {index > 0 && <AutocompleteSeparator />}
          <AutocompleteGroupLabel>{group.label}</AutocompleteGroupLabel>
          <AutocompleteCollection>
            {(item: string) => (
              <AutocompleteItem
                key={item}
                value={item}
                selected={item === model}
                onClick={() => setModel(item)}
              >
                {item}
              </AutocompleteItem>
            )}
          </AutocompleteCollection>
        </AutocompleteGroup>
      )}
    </AutocompleteList>
    <AutocompleteEmpty>No models match</AutocompleteEmpty>
  </AutocompleteContent>
</Autocomplete>;
```

### Inside a submenu

The [Menu](/docs/components/components/menu) submenu supplies the popup. `mode="none"` leaves filtering to
you.

```tsx
<MenuSubContent>
  <Autocomplete
    inline
    open
    mode="none"
    autoHighlight
    items={options}
    value={search}
    onValueChange={setSearch}
  >
    <AutocompleteInput variant="inline" aria-label="Search models" placeholder="Search models" />
    <MenuSeparator />
    <AutocompleteList variant="inline">
      {(option: ModelOption) => (
        <AutocompleteItem
          variant="inline"
          key={option.key}
          value={option}
          selected={option.key === current}
          onClick={() => choose(option)}
        >
          {option.name}
        </AutocompleteItem>
      )}
    </AutocompleteList>
  </Autocomplete>
</MenuSubContent>
```

`AutocompleteInput`, `AutocompleteList`, `AutocompleteItem`, and `AutocompleteGroupLabel` take

| Value      | Geometry                                         |

| `"popup"`  | Default. Sized for `AutocompleteContent`.        |
| `"inline"` | Menu row geometry, for a host such as a submenu. |

## Accessibility

- Name the input and the trigger with `aria-label`. The trigger's text is only the current value.
- `AutocompleteList` renders `role="listbox"` and each `AutocompleteItem` `role="option"`. The
  checkmark is hidden from assistive technology.
- Arrow Down and Up move the highlight. The input is part of the loop. Enter picks the highlighted
  item. Escape closes the popup.
- `AutocompleteGroupLabel` names its group.
- Keyboard focus on the trigger shows the [focus ring](/docs/components/foundations/focus).
