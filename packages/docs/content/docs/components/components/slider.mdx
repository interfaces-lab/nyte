```ts title="Import"
import { Slider } from "@nyte-ai/ui/slider";
```

A single-value or range slider.

## Usage

- For server rendering, give each range thumb an explicit `index`.

## Anatomy

```tsx
<Slider.Root>
  <Slider.Label />
  <Slider.Value />
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>
```

## Examples

### A labeled slider

```tsx
<Slider.Root defaultValue={40} thumbAlignment="edge">
  <div>
    <Slider.Label>Intensity</Slider.Label>
    <Slider.Value />
  </div>
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>
```

### Controlled

```tsx
const [volume, setVolume] = useState(0.5);

<Slider.Root value={volume} onValueChange={setVolume} min={0} max={1} step={0.1}>
  <Slider.Label>Volume</Slider.Label>
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>;
```

### A range

```tsx
<Slider.Root defaultValue={[25, 75]} thumbCollisionBehavior="swap">
  <Slider.Label>Price range</Slider.Label>
  <Slider.Control>
    <Slider.Track>
      <Slider.Indicator />
      <Slider.Thumb index={0} aria-label="Minimum price" />
      <Slider.Thumb index={1} aria-label="Maximum price" />
    </Slider.Track>
  </Slider.Control>
</Slider.Root>
```

### Thumb alignment

```tsx
<Slider.Root thumbAlignment="center" />
```

### In a form

```tsx

      <Slider.Indicator />
```

## Accessibility

- Each thumb renders a nested `<input type="range">`. Arrow keys move by `step`, and Home and End
  jump to the ends of the range.
- Page Up, Page Down, and Shift with an arrow key move by `largeStep`.
- `Slider.Label` names every thumb. In a range, or without a visible label, give each thumb an
  `aria-label`.
- `aria-valuetext` on a thumb replaces the announced number. `getAriaValueText` overrides it.
- `Slider.Value` renders an `<output>` element.
- Keyboard focus on a thumb shows the [focus ring](/cloud/foundations/focus).
