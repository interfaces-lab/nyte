```ts title="Import"
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@nyte-ai/ui/tooltip";
```

A visible label and optional shortcut for a control with an accessible name. For longer content,
use [Preview card](/cloud/components/preview-card).

## Usage

- Pass the control to `TooltipTrigger` through `render`. Give the control its own `aria-label`,
  because the tooltip does not name it.
- An icon-only [Button](/cloud/components/button) also sets its label as the native `title`. Pass
  `title={undefined}` so only one tooltip appears.
- `TooltipContent` keeps line breaks in its text.
- Wrap the app once in `TooltipProvider`. A trigger's own `delay` or `closeDelay` overrides it.
- Keep instructions and disabled reasons visible outside the tooltip.

## Anatomy

```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger />
    <TooltipContent />
  </Tooltip>
</TooltipProvider>
```

```tsx
import { Button } from "@nyte-ai/ui/button";
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@nyte-ai/ui/tooltip";

<TooltipProvider>
  <Tooltip>
    <TooltipTrigger
      render={<Button iconOnly icon="copy" aria-label="Copy output" title={undefined} />}
    />
    <TooltipContent>Copy output</TooltipContent>
  </Tooltip>
  <Tooltip>
    <TooltipTrigger
      render={<Button iconOnly icon="trash" aria-label="Delete session" title={undefined} />}
    />
    <TooltipContent>Delete session ⌘⌫</TooltipContent>
  </Tooltip>
</TooltipProvider>;
```

functions of state. See [Theming](/cloud/foundations/theming). `Tooltip` and `TooltipTrigger` are

## Accessibility

- Hover opens after `delay`. Keyboard focus opens at once.
- Escape, an outside press, and a trigger click close it.
- The popup appears without motion under `prefers-reduced-motion: reduce`.
