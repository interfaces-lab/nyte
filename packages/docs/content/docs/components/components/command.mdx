```ts title="Import"
import { Command } from "@nyte-ai/ui/command";
```

A dialog near the top of the window holding an inline
[Autocomplete](/docs/components/components/autocomplete). The dialog owns open state, the scrim, and focus;
the autocomplete owns the input, the highlight, and arrow-key and Enter handling. Focus lands in
the input when the palette opens, and Enter runs the highlighted row's `onClick`.

## Usage

- The palette does not filter. Render the rows that match the query from `onValueChange`, and
  pass their values to `items` in render order, so the highlight tracks the rows that exist.
- `Command.Empty` shows its children while `items` is empty and announces the change. Keep it
  mounted and change its text for loading, failure, and no match.
- `Command.Popup` names the dialog with its `title`, read by screen readers only. Name the
  palette after what it searches.
- Rows keep the menu's three columns, `leading`, label, and `meta`, so labels align in every group.
- Coming from shadcn's `Command`: `CommandDialog` is `Command.Root` plus `Command.Popup`,
  `heading` keeps its name, `onSelect` is `onClick`, and `CommandShortcut` is `meta`. `value` on
  the popup is the query, as in Base UI, not the highlighted row. Use `onItemHighlighted` for that.

## Anatomy

```tsx
<Command.Root>
  <Command.Trigger />
  <Command.Popup>
    <Command.Input />
    <Command.List>
      <Command.Empty />
      <Command.Group>
        <Command.Item />
      </Command.Group>
      <Command.Separator />
    </Command.List>
  </Command.Popup>
</Command.Root>
```

## Examples

```tsx
const [open, setOpen] = useState(false);
const [query, setQuery] = useState("");
const matches = commands.filter((command) =>
  command.label.toLowerCase().includes(query.toLowerCase()),
);

<Command.Root open={open} onOpenChange={setOpen}>
  <Command.Trigger render={<Button variant="outline">Search</Button>} />
  <Command.Popup
    title="Search commands"
    items={matches.map((command) => command.id)}
    value={query}
    onValueChange={setQuery}
  >
    <Command.Input aria-label="Search" placeholder="Search…" trailing={<Kbd keys={["⌘", "K"]} />} />
    <Command.List>
      <Command.Empty>No commands match "{query}"</Command.Empty>
      <Command.Group heading="Commands">
        {matches.map((command) => (
          <Command.Item
            key={command.id}
            value={command.id}
            leading={<Icon name={command.icon} size={16} />}
            meta={<Kbd keys={command.keys} plain />}
            onClick={() => {
              setOpen(false);
              command.run();
            }}
          >
            {command.label}
          </Command.Item>
        ))}
      </Command.Group>
    </Command.List>
  </Command.Popup>
</Command.Root>;
```

## Props

| Part                | Renders                                                   | Styling                             |
| ------------------- | --------------------------------------------------------- | ----------------------------------- |
| `Command.Root`      | Nothing                                                   | None                                |
| `Command.Trigger`   | `<button>`                                                | None                                |
| `Command.Popup`     | A portal, the scrim, a viewport, a `<div>`, the list root | Translucent panel near the top      |
| `Command.Input`     | A `<div>` holding the search glyph and an `<input>`       | Full-width row under a hairline     |
| `Command.List`      | `<div role="listbox">`                                    | Scrolls when rows overflow          |
| `Command.Group`     | `<div role="group">` with an optional heading             | Small, secondary heading            |
| `Command.Separator` | `<div role="separator">`                                  | Hairline                            |
| `Command.Item`      | `<div role="option">`                                     | Three columns, highlighted on hover |
| `Command.Empty`     | `<div role="status">`                                     | Centered secondary text             |
| `Command.Close`     | `<button>`                                                | None                                |

Except `Command.Root`, each part takes `xstyle`, `className`, and `style`. `className` and `style`
take plain values, not functions of state. See [Theming](/docs/components/foundations/theming).

### Popup

Renders the portal, scrim, viewport, popup, and a visually hidden title, then an always-open
inline autocomplete root with `autoHighlight="always"` and `keepHighlight`. It takes the Base UI
dialog popup props, including `ref`, and these.

| Prop                | Type                            | Default             | Description                                             |
| ------------------- | ------------------------------- | ------------------- | ------------------------------------------------------- |
| `title`             | `string`                        | `"Command palette"` | The dialog's accessible name.                           |
| `description`       | `string`                        |                     | The dialog's accessible description.                    |
| `tint`              | `Tint`                          |                     | Scopes the panel to a hue. The scrim stays neutral.     |
| `items`             | `readonly ItemValue[]`          |                     | Every row's `value`, in render order.                   |
| `loopFocus`         | `boolean`                       | `true`              | Whether arrow keys wrap from the last row to the first. |
| `value`             | `string`                        |                     | The controlled query.                                   |
| `defaultValue`      | `string`                        |                     | The initial query when uncontrolled.                    |
| `onValueChange`     | `(value, eventDetails) => void` |                     | Fires as the query changes.                             |
| `onItemHighlighted` | `(value, eventDetails) => void` |                     | Fires as the highlight moves.                           |
| `itemToStringValue` | `(value) => string`             |                     | Names a non-string `value` for assistive tech.          |
