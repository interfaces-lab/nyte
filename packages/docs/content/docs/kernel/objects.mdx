A `Change` is a commit body waiting for its parent: a user message, a completion or a config. Landing turns it into a commit. The `Run` object is replaced on every phase change, so the run ref's history is the run's history. `done`, `failed` and `aborted` are terminal.

Every commit records when it was written, and the run that wrote it when a runner did. Assistant `calls` and `outcome`, a tool result's `call` and `tree`, and `start` on the commit that opens a run are provenance: the runner stamps them, and the model never sees them.
