## One way to write

Every write a step makes to a run or head goes through one function.

<Source title="publish" excerpt={EXCERPTS.publish} />

The appended update is an assertion. It writes nothing, but it must hold, so once `sessions.delete` writes `refs/deleted`, every runner publish conflicts. Effect writes are the exception. They call `refs.update` with the lease alone.

## When a publish loses

A `conflict` means another writer moved a ref first. `afterConflict` re-reads the run and the tip and decides from what it finds.
