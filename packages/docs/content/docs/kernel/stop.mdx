A stop is a flag on the run, written without a lease. The runner honours it at its next publish, and nothing clears it. A second stop is a no-op.

<Source title="requestAbortAtRef" excerpt={EXCERPTS.requestAbortAtRef} />

The flag and the revoked delegate authorizations land in one CAS. `abortLocalDrive` then cancels this host's provider or tool call, and `runs.abort` interrupts the command jobs the run owns.

A failure it would have reported becomes a runner notice. A tool that ignores its signal keeps running, and the lease keeps renewing until it returns. Children the run created keep working; only `stop` ends a child.
