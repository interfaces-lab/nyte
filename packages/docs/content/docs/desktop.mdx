title: Desktop
description: The Nyte desktop app, an Electron host that composes createNyte
---

Desktop hosts `createNyte` in Electron's main process and exposes SDK operations to the renderer as
`window.nyte`.

```bash
pnpm --dir packages/desktop dev
```

## Workspaces

Desktop and the TUI share `~/.nyte/workspaces/<path-hash>/sessions.db` for each workspace.
`NYTE_HOME` overrides `~/.nyte`. On first open, a client copies an existing
`<workspace>/.nyte/sessions.db` and leaves the original in place.

Trust grants live in `~/.nyte/workspaces.json` and apply in both clients. Opening a workspace loads
history without checking trust. Sending resolves the folder and requests trust before loading
project code. A missing path leaves the failed send in the outbox for retry. Switching workspaces
keeps attached sessions and jobs open.

## The IPC bridge

The renderer never imports `@nyte-ai/core`. `window.nyte` mirrors the in-process namespaces
`sessions`, `messages`, `jobs`, `runs`, `heads`, `workspace`, `provider`, and `plugins` through one
validated `nyte:call` channel. Across IPC, `watch` becomes a start/stop pump with the same `afterSeq`
and `live` cursors.

## Subagent models

Delegated tasks default to `openai-codex/gpt-6.1-sol` with `high` thinking. If unavailable, they
fall back once to `anthropic/claude-opus-5-5` with `medium` thinking. The parent can request another
model or thinking level. An unavailable explicit model fails without fallback.

Provider and model switches apply to subagents, including the default and fallback. Disabling a model
also blocks it in existing sessions. Provider request failures do not switch models.

Child sessions do not appear in the sidebar or chat search. Inspect them from the parent task or
Jobs panel.

## Web search

Desktop and TUI share the web-search plugin and saved credentials. In `auto`, search prefers keyed
providers and keeps its route after restart. HTTP 429 can switch once to each other eligible provider
per call. Keyed searches never use anonymous access. Explicit providers never fail over.

Before the first anonymous request, the run waits for the user to allow automatic search, choose an
installed provider, or disable search. Desktop shows these controls above the composer. Escape,
messages, and closing the client do not approve search. The session remembers the choice. Headless
clients use `runs.reply`.

Results name the provider, credential source, and any rate-limit failover.
`/websearch-key <provider> [key]` saves a key. Omit the key to remove it. Environment keys still
apply, but terminal-only variables may not reach desktop.

## Jobs

Each chat has a Jobs panel above the composer for commands and subagents. It shows mode, state, and
expandable output. Foreground jobs have **Run in background** and **Cancel job**. Background jobs keep
**Cancel job**. Finished jobs keep their output. These controls remain available while the parent is
parked and affect one job.

```text
Jobs panel -> window.nyte.jobs -> validated IPC -> owning workspace SDK
job event  -> refresh jobs list
```

The panel polls every two seconds while mounted. Closing it or switching chats does not cancel work.
Closing the owning host interrupts live jobs, and they do not rerun. A finished background command can
join an active run but never starts one. Background agents inherit workspace trust and cannot use
tools marked `availability: "foreground"`.

## GitHub account

Accounts uses the installed GitHub CLI, even at Home without a workspace. Browser sign-in copies the
one-time code to the clipboard. Sign-out removes the CLI login that terminal commands and other apps
share. Local Git does not require it.

At startup on POSIX systems, desktop reads PATH from a login shell. Windows keeps its inherited
environment. Shell-only GitHub tokens and configuration overrides do not carry over, so use
`gh auth login` to store CLI credentials.

Set `NYTE_OTEL_ENDPOINT` in the launch environment to enable OTLP export. GitHub commands emit
`desktop.github.command` spans with only an allowlisted operation, outcome, exit code, and duration.
