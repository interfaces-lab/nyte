# Cloudflare

`worker.ts` runs one Nyte host in one SQLite-backed Durable Object, `NyteHost`, and the Worker in front of it sends every request to that object. The object keeps sessions in its own storage through `durableObjectStore`, serves a chat-only workspace (no files, no processes), answers the protocol through `listenFetch`, and runs sessions from its alarm: each pass advances up to 32 due heads within 10 seconds, re-alarms at once for the rest, and sets the alarm for the next due head from its `nyte_schedule` table. It imports only the node-free subpaths (`@nyte-ai/host/durable-object`, `/listen-fetch`, `/providers`), never the Node root. `wrangler.jsonc` requires the `NYTE_TOKEN` secret (at least 16 characters): run `wrangler secret put NYTE_TOKEN`, to enable `secrets.set` also `wrangler secret put NYTE_SECRET_KEY` with a base64 key, and to answer identity challenges `wrangler secret put NYTE_IDENTITY_KEY` with a base64 32-byte Ed25519 seed (without it `/.nyte/identity` answers `unknown`), then `wrangler deploy` from this directory.
