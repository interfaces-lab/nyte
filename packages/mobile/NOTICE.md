## Expo morphing menu

The attachment menu, morph geometry, photo selection, Add-button text animation,
thumbnail entry/removal, and measured photo-flight modules under `src/chat/`
port the corresponding components and timing constants from
[rit3zh/expo-morphing-menu](https://github.com/rit3zh/expo-morphing-menu),
commit `0aca4280254850ad065987bb8641ba69ae8ac891`. The attachment menu keeps Nyte's
photo-permission, image-staging, annotation, and camera-capture integrations.
The upstream project is an Expo example app, not an npm library.
