# @nyte-ai/host

The Node side of a Nyte host, around the kernel `composeHost` builds in `@nyte-ai/core`: `listen` serves it over `node:http` or as a bare fetch handler through `@nyte-ai/protocol`'s handler, with token, pairing and custom authentication, CORS, the `/.nyte/identity` and `/.nyte/describe` routes, and in-process driving when the kernel only admits; `sqliteStore` (`node:sqlite`) and `postgresStore` (any `pg`-shaped pool) implement core's `Store`, each publish one transaction with its compare-and-set and log append; `localProvider` serves a folder on this machine, with files over `node:fs` versioned by content, `.gitignore`-aware scan, find, search (ripgrep, else a scan) and watch, processes over pipes or a pty (`@lydell/node-pty`, loaded on first use), git over its CLI with hunks parsed on the host, and run snapshots kept as hidden git refs or a content-addressed tree walk; and `loadPluginFiles` and `pluginLoader` import the core plugins in `.nyte/plugins` directories.
