```ts title="Import"
import {
  NumberField,
  NumberFieldDecrement,
  NumberFieldGroup,
  NumberFieldIncrement,
  NumberFieldInput,
} from "@nyte-ai/ui/number-field";
```

For a small bounded value, such as a font size.

## Usage

- Both value callbacks can receive `null` for an empty input.
- Save in `onValueCommitted`, not on every keystroke.
- The buttons default to "−" and "+". Pass children to replace them.

## Anatomy

```tsx
<NumberField>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

```tsx
<NumberField defaultValue={13} min={12} max={16}>
  <NumberFieldGroup>
    <NumberFieldDecrement />
    <NumberFieldInput aria-label="UI font size" />
    <NumberFieldIncrement />
  </NumberFieldGroup>
</NumberField>
```

```tsx
<NumberField
  defaultValue={settings.uiFontSize}
  min={12}
  max={16}
  onValueCommitted={(uiFontSize) => {
    if (uiFontSize !== null) save({ uiFontSize });
  }}
>
  …
</NumberField>
```

## Props

Styled parts add `xstyle`. `className` and `style` accept values or Base UI part-state functions.
See [Theming](/design/theming).

For every other prop, see Base UI's [Number Field](https://base-ui.com/react/components/number-field) reference.

### NumberField

Passes through Base UI `NumberField.Root` unstyled, without `xstyle`.

### NumberFieldGroup

| Prop     | Type                          |
| -------- | ----------------------------- |
| `xstyle` | `Restyle<"NumberFieldGroup">` |

### NumberFieldDecrement

| Prop       | Type                              | Default |
| ---------- | --------------------------------- | ------- |
| `xstyle`   | `Restyle<"NumberFieldDecrement">` |         |
| `children` | `ReactNode`                       | `"−"`   |

### NumberFieldInput

| Prop     | Type                          |
| -------- | ----------------------------- |
| `xstyle` | `Restyle<"NumberFieldInput">` |

### NumberFieldIncrement

| Prop       | Type                              | Default |
| ---------- | --------------------------------- | ------- |
| `xstyle`   | `Restyle<"NumberFieldIncrement">` |         |
| `children` | `ReactNode`                       | `"+"`   |

## Accessibility

Name `NumberFieldInput` with `aria-label` or a label.
