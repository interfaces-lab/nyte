Lists the types a type hierarchy item extends or implements, each with a token to go one level further. A stale token answers empty, as a type with no parent does.

## When to call it

To expand an item of [`language.typeHierarchy`](/docs/reference/operations/language/type-hierarchy) upwards.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "token": {
    "kind": "typeHierarchy",
    "server": "4f0c2b9e-6a1d-4c3b-9e57-2d8a6f1b0c34",
    "answer": 3,
    "item": 0
  }
}
```

Response:

```json
[
  {
    "name": "Channel",
    "detail": "example.com/notifyhub/hub",
    "kind": "interface",
    "location": {
      "path": "hub/hub.go",
      "range": {
        "start": {
          "line": 18,
          "utf16Column": 5
        },
        "end": {
          "line": 18,
          "utf16Column": 12
        }
      }
    },
    "selection": {
      "start": {
        "line": 18,

      },

      "answer": 3,
      "item": 1
    }
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
