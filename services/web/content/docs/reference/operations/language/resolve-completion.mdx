---
title: language.resolveCompletion
description: Fills in a completion's documentation and edits, or answers null for a stale token.
---

Asks the server for the rest of one completion item: its documentation, detail and the edits it makes elsewhere, such as an import. The token names one item of one answer of one server run, so a later completion or a server restart makes it stale and the answer null.

## When to call it

When the user selects or accepts a completion item.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "token": {
    "kind": "completion",
    "server": "4f8c2a1e-0b6d-4e3f-9a7c-5d2e1f0a3b4c",
    "answer": 3,
    "item": 0
  }
}
```

Response:

```json
{
  "label": "Names",
  "kind": "method",
  "tail": "()",
  "type": "[]string",
  "documentation": "Names returns the channel names in alphabetical order.",
  "filter": "Names",
  "sort": "00000",
  "insert": { "text": "Names", "stops": [], "replace": null },
  "additionalEdits": [],
  "commitCharacters": [],
  "preselect": false,
  "deprecated": false,
  "invocation": "withoutArguments",
  "resolve": {
    "kind": "completion",
    "server": "4f8c2a1e-0b6d-4e3f-9a7c-5d2e1f0a3b4c",
    "answer": 3,
    "item": 0
  }
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
