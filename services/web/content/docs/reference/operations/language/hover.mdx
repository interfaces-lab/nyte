title: language.hover
description: Reads the documentation and type at a position as markdown.
---

Answers the server's hover at a position as markdown, with the range it covers, or null where it has none. A file no server handles, or whose server is `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

When the pointer rests on code, or for a quick documentation popup.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "main.go",
  "position": { "line": 31, "utf16Column": 12 }
}
```

Response:

````json
{
  "markdown": "```go\nfunc (h *hub.Hub) Stats() hub.Stats\n```\n\nStats returns a copy of the counts so far.",
  "range": { "start": { "line": 31, "utf16Column": 12 }, "end": { "line": 31, "utf16Column": 17 } }
}
````

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
