title: language.rename
description: Computes the edits that rename the symbol at a position, without applying them.
---

Computes the edits that rename the symbol at a position, per file, against the text the server has: a client's open documents and the disk's for the rest. Nothing is written; the client applies the edits. An edit that would create, rename or delete a file is `refused`, as is a rename the server refuses, with its reason.

## When to call it

When the user confirms a rename, to preview and then apply its edits.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "hub/stats.go",
  "position": { "line": 5, "utf16Column": 5 },
  "name": "Totals"
}
```

Response:

```json
{
  "kind": "edit",
  "edit": {
    "files": [
      {
        "path": "hub/stats.go",
        "edits": [
          {
            "range": {
              "start": { "line": 5, "utf16Column": 5 },
              "end": { "line": 5, "utf16Column": 11 }
            },
            "text": "Totals"
          }
        ]
      }
    ]
  }
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
