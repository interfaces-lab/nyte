title: language.renameFiles
description: Computes the edits that keep code working when files or folders are renamed, such as changed import paths, without applying them or renaming anything.

Computes the edits that keep code working once files or folders are renamed or moved, such as the import paths that name them. Nothing is renamed and nothing is written. It starts the servers of the files named, then asks every running server that follows renames and puts their edits together. No such server answers an empty edit.

## When to call it

Before renaming or moving a file, while it still sits at `from`. Apply the edits, then rename.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "files": [
    {
      "from": "src/stats.ts",
      "to": "src/moved-stats.ts"
    }
  ]
}
```

Response:

```json
{
  "kind": "edit",
  "edit": {
    "files": [
      {
        "path": "src/hub.ts",
        "edits": [
          {
            "range": {
              "start": {
                "line": 0,
                "utf16Column": 48
              },
              "end": {
                "line": 0,
                "utf16Column": 58
              }
            },
            "text": "./moved-stats.ts"
          }
        ]
      },
      {
        "path": "src/index.ts",
        "edits": [
          {
            "range": {
              "start": {
                "line": 3,
                "utf16Column": 30
              },
              "end": {
                "line": 3,
                "utf16Column": 40
              }
            },
            "text": "./moved-stats.ts"
          }
        ]
      }
    ]
  }
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
