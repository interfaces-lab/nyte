Answers the ranges whose text changes together with the one at a position, from the first server that has any, or null. An HTML element's opening and closing tag names are the usual pair. `wordPattern` is a regular expression the shared text must keep matching, or null when any text goes. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

When the caret enters a name, to mirror edits to it in its linked ranges.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "index.html",
  "position": {
    "line": 4,
    "utf16Column": 6
  }
}
```

Response:

```json
{
  "ranges": [
    {
      "start": {
        "line": 4,
        "utf16Column": 5
      },
      "end": {
        "line": 4,
        "utf16Column": 12
      }
    },
    {
      "start": {
        "line": 8,
        "utf16Column": 6
      },
      "end": {
        "line": 8,
        "utf16Column": 13
      }
    }
  ],
  "wordPattern": null
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
