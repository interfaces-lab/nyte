title: language.workspaceSymbols

Finds symbols by name across the projects of the language servers that are running, each with its kind, the symbol it sits in and where it is. It starts no server, so it answers empty until a file of the project has been opened or queried. How a query matches, as a prefix or fuzzily, is the server's choice.

## When to call it

For go to symbol in workspace.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "query": "newStats"
}
```

Response:

```json
[
  {
    "name": "newStats",
    "kind": "function",
    "container": "example.com/notifyhub/hub",
    "location": {
      "path": "hub/stats.go",
      "range": {
        "start": {
          "line": 18,
          "utf16Column": 5
        },
        "end": {
          "line": 18,
          "utf16Column": 13
        }
      }
    },
    "deprecated": false
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
