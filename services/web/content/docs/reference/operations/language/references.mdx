---
title: language.references
description: Finds every reference to the symbol at a position.
---

Lists every reference to the symbol at a position across the server's project, with its declaration when `includeDeclaration` is true. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

For find usages.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "hub/stats.go",
  "position": { "line": 54, "utf16Column": 5 },
  "includeDeclaration": true
}
```

Response:

```json
[
  {
    "path": "hub/stats.go",
    "range": {
      "start": { "line": 39, "utf16Column": 11 },
      "end": { "line": 39, "utf16Column": 15 }
    }
  },
  {
    "path": "hub/stats.go",
    "range": {
      "start": { "line": 43, "utf16Column": 21 },
      "end": { "line": 43, "utf16Column": 25 }
    }
  },
  {
    "path": "hub/stats.go",
    "range": { "start": { "line": 54, "utf16Column": 5 }, "end": { "line": 54, "utf16Column": 9 } }
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
