title: language.callHierarchy

Finds the function at a position as the root of a call hierarchy, from the first server that finds one. Each item carries a token for [`language.incomingCalls`](/docs/reference/operations/language/incoming-calls) and [`language.outgoingCalls`](/docs/reference/operations/language/outgoing-calls). Asking for a new root, or a restart of the server, makes the earlier tokens stale. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

When someone asks who calls a function, or what it calls.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "hub/stats.go",
  "position": {
    "line": 54,
    "utf16Column": 5
  }
}
```

Response:

```json
[
  {
    "name": "bump",
    "detail": "example.com/notifyhub/hub \u2022 stats.go",
    "kind": "function",
    "location": {
      "path": "hub/stats.go",
      "range": {
        "start": {
          "line": 54,
          "utf16Column": 5
        },
        "end": {
          "line": 54,
          "utf16Column": 9
        }
      }
    },
    "selection": {
      "start": {
        "line": 54,
        "utf16Column": 5
      },
      "end": {
        "line": 54,
        "utf16Column": 9
      }
    },
    "deprecated": false,
    "token": {
      "kind": "callHierarchy",
      "server": "4f0c2b9e-6a1d-4c3b-9e57-2d8a6f1b0c34",
      "answer": 1,
      "item": 0
    }
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
