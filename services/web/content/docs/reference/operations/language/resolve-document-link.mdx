---
title: language.resolveDocumentLink
description: Works out where a link leads, or answers null for a stale token.
---

Works out where a link leads, for a link listed without a target. It answers the link with its target and no token, or null for a stale token. A token goes stale when its server lists links again, for any file, or restarts.

## When to call it

When someone hovers or follows a link from [`language.documentLinks`](/docs/reference/operations/language/document-links) whose `target` is null.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "token": {
    "kind": "documentLink",
    "server": "4f0c2b9e-6a1d-4c3b-9e57-2d8a6f1b0c34",
    "answer": 9,
    "item": 1
  }
}
```

Response:

```json
{
  "range": {
    "start": {
      "line": 9,
      "utf16Column": 2
    },
    "end": {
      "line": 9,
      "utf16Column": 29
    }
  },
  "target": {
    "kind": "file",
    "path": "hub/hub.go",
    "position": null
  },
  "tooltip": "",
  "token": null
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
