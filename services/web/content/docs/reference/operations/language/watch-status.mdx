---
title: language.watchStatus
description: Streams the workspace's language servers each time one changes state.
---

Streams the same rows as [`language.status`](/docs/reference/operations/language/status): first the rows as they are, then all of them again each time one server changes state, reports download progress or registers a feature. A reader that falls behind gets the latest rows, not every step.

## When to call it

To keep a status bar or a server panel current, such as a download's progress or a `missing` server's install hint.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{ "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0" }
```

A frame:

```json
[
  {
    "languages": ["typescript"],
    "server": "typescript-language-server",
    "root": "web",
    "state": {
      "kind": "busy",
      "title": "Initializing",
      "percent": null
    },
    "version": "TypeScript 6.0.3",
    "executable": "/usr/local/bin/typescript-language-server",
    "features": ["completion", "hover", "definition", "references", "rename"]
  },
  {
    "languages": ["python"],
    "server": "ruff",
    "root": "",
    "state": {
      "kind": "installing",
      "percent": 42
    },
    "version": null,
    "executable": null,
    "features": []
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
