---
title: language.semanticTokens
description: Reads a document's semantic tokens, or those in a range, with the legend that names them.
---

Reads a document's semantic tokens from the first server that has any, or null when none does. `data` holds five numbers per token, as LSP encodes them: lines since the token before, columns since that token when both sit on one line and since the line's start otherwise, the token's length, an index into `types`, and a bit set over `modifiers`. Columns and lengths count UTF-16 code units. With `range`, a server that can answers only the tokens in it. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

To colour what a grammar can't tell apart, such as a parameter from a variable. Ask again after an edit, and when [`language.refreshes`](/docs/reference/operations/language/refreshes) names `semanticTokens`.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "hub/stats.go",
  "range": {
    "start": {
      "line": 5,
      "utf16Column": 0
    },
    "end": {
      "line": 6,
      "utf16Column": 0
    }
  }
}
```

Response:

```json
{
  "types": [
    "namespace",
    "type",
    "typeParameter",

    "variable",

  ],

    "definition",

```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
