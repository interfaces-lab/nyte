---
title: language.documentLinks
description: Lists the links in a document, such as URLs and paths, with where each leads.
---

Lists the links in a document, from every server that finds some, in document order. A link leads to a file, with a position when the link names one, or to any other URL. `target` is null while the server has yet to work it out; such a link carries a token for [`language.resolveDocumentLink`](/docs/reference/operations/language/resolve-document-link). A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

To make import paths, URLs in comments and links between documents clickable.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "main.go"
}
```

Response:

```json
[
  {
    "range": {
      "start": {
        "line": 4,
        "utf16Column": 2
      },
      "end": {
        "line": 4,
        "utf16Column": 9
      }
    },
    "target": {
      "kind": "url",
      "url": "https://pkg.go.dev/context"
    },
    "tooltip": "",
    "token": null
  },
  {
    "range": {
      "start": {
        "line": 9,
        "utf16Column": 2
      },
      "end": {
        "line": 9,
        "utf16Column": 29
      }
    },
    "target": null,
    "tooltip": "",
    "token": {
      "kind": "documentLink",
      "server": "4f0c2b9e-6a1d-4c3b-9e57-2d8a6f1b0c34",
      "answer": 9,
      "item": 1
    }
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
