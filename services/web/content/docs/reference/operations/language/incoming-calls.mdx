---
title: language.incomingCalls
description: Lists the callers of a call hierarchy item, each with its call sites.
---

Lists the callers of a call hierarchy item, each with the ranges in the caller where the calls sit and a token to go one level further. A stale token answers empty, as an item nothing calls does.

## When to call it

To expand an item of [`language.callHierarchy`](/docs/reference/operations/language/call-hierarchy) towards its callers.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "token": {
    "kind": "callHierarchy",
    "server": "4f0c2b9e-6a1d-4c3b-9e57-2d8a6f1b0c34",
    "answer": 1,
    "item": 0
  }
}
```
