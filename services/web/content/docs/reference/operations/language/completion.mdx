---
title: language.completion
description: Lists completions at a position, each with a token to resolve its details.
---

Lists the server's completions at a position. Each item has its label, kind, the parameters that follow the label (`tail`) and its type, and what to insert: the text with any snippet expanded, its tab stops in UTF-16 code units and the range it replaces. A callable row whose server left out its parameters gets them from a resolve, for as many rows as answer within a short budget. A newer completion in the workspace cancels one still waiting, which then answers an empty list. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

As the user types a trigger character or asks for completions. Resolve the chosen item with [`language.resolveCompletion`](/docs/reference/operations/language/resolve-completion).

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "main.go",
  "position": { "line": 32, "utf16Column": 7 },
  "trigger": { "kind": "character", "character": "." }
}
```

Response:

```json
{
  "items": [
    {
      "label": "Names",
      "kind": "method",
      "tail": "()",
      "type": "[]string",
      "documentation": "",
      "filter": "Names",
      "sort": "00000",
      "insert": {
        "text": "Names",
        "stops": [],
        "replace": {
          "start": { "line": 32, "utf16Column": 7 },
          "end": { "line": 32, "utf16Column": 7 }
        }
      },
      "additionalEdits": [],
      "commitCharacters": [],
      "preselect": false,
      "deprecated": false,
      "invocation": "withoutArguments",
      "resolve": {
        "kind": "completion",
        "server": "4f8c2a1e-0b6d-4e3f-9a7c-5d2e1f0a3b4c",
        "answer": 3,
        "item": 0
      }
    }
  ],
  "incomplete": false
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
