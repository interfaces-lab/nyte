---
title: language.documentColors
description: Lists the colours written in a document, each with its range.
---

Lists the colours written in a document, from every server that finds some, in document order. Each channel runs from 0 to 1. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

To draw a swatch beside each colour. For the ways to rewrite one, call [`language.colorPresentations`](/docs/reference/operations/language/color-presentations).

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "site.css"
}
```

Response:

```json
[
  {
    "range": {
      "start": {
        "line": 2,
        "utf16Column": 9
      },
      "end": {
        "line": 2,
        "utf16Column": 16
      }
    },
    "color": {
      "red": 1,
      "green": 0,
      "blue": 0,
      "alpha": 1
    }
  }
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
