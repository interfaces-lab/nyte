---
title: language.signatureHelp
description: Reads the signature of the call at a position and its active parameter.
---

Answers the signatures of the call around a position, the active one, and the active parameter; each parameter is a span of its signature's label in UTF-16 code units. Null outside a call. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

As the user types a call's arguments.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "main.go",
  "position": { "line": 26, "utf16Column": 26 }
}
```

Response:

```json
{
  "signatures": [
    {
      "label": "Submit(ctx context.Context, message hub.Message) error",
      "documentation": "Submit sends a message through its channel and records how it went.",
      "parameters": [
        { "utf16Start": 7, "utf16End": 26 },
        { "utf16Start": 28, "utf16End": 47 }
      ]
    }
  ],
  "activeSignature": 0,
  "activeParameter": 1
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
