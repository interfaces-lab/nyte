---
title: language.format
description: Computes the edits that format a document, or why no server formatted it.
---

Computes the edits that format a whole document with the server's formatter, gofmt for Go and TypeScript's for TypeScript and JavaScript. Nothing is written. It answers `edits`, empty when the document is already formatted. A file no server handles, whose server is `missing` or `failed`, or whose server doesn't format documents answers `unavailable` rather than failing, so a client can fall back to [`files.format`](/docs/reference/operations/files/format); [`language.status`](/docs/reference/operations/language/status) says why. A server that errors while formatting answers `failed` with its message.

## When to call it

For format document, or before saving.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "hub/hub.go",
  "options": { "tabSize": 4, "insertSpaces": false }
}
```

Response:

```json
{
  "kind": "edits",
  "edits": [
    {
      "range": {
        "start": { "line": 41, "utf16Column": 0 },
        "end": { "line": 41, "utf16Column": 6 }
      },
      "text": "\t"
    }
  ]
}
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
