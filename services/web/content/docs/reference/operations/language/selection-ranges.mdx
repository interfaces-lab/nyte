Lists, for each position asked, the ranges a growing selection steps through, from the innermost out: a name, the expression around it, its statement, its function, the file. Every server's ranges are put together, and a range that does not hold the one before it is left out. A file no server handles, or whose servers are `missing` or `failed`, answers empty rather than failing; [`language.status`](/docs/reference/operations/language/status) says why.

## When to call it

For expand selection and shrink selection.

## Access

Any principal with `participant` authority. Workspace scope, with the `language` capability. Paths are relative to the workspace, or absolute; answers name files inside the workspace by their relative path and others, such as the standard library, by their absolute one. Lines are zero-based and columns count UTF-16 code units.

## Example

Request body:

```json
{
  "workspace": "9b1f0c7e5a2d48e3b6c4f1a0d9e8c7b6a5f4e3d2c1b0a9f8e7d6c5b4a3f2e1d0",
  "path": "hub/stats.go",
  "positions": [
    {
      "line": 54,
      "utf16Column": 5
    }
  ]
}
```

Response:

```json
[
  [
    {
      "start": {
        "line": 54,
        "utf16Column": 5
      },
      "end": {
        "line": 54,
        "utf16Column": 9
      }
    },
    {
      "start": {
        "line": 54,
        "utf16Column": 0
      },
      "end": {
        "line": 62,
        "utf16Column": 1
      }
    },
    {
      "start": {
        "line": 0,
        "utf16Column": 0
      },
      "end": {
        "line": 62,
        "utf16Column": 1
      }
    }
  ]
]
```

## Errors

- `unavailable` or `denied` when the workspace doesn't offer language intelligence.
