Kernel API

Everything the clients use is public. The host is a library first, an app second.

Call Returns Durability
createSession() SessionHandle journaled
send(message) AsyncIterable<Event> journaled
resume(id) SessionHandle replay
fork(id, at) SessionHandle copy-on-write
export(id) EventLog portable
const session = await host.resume("8f21a")
for await (const event of session.send("continue the refactor")) {
  render(event) // already on disk
}

How it works

Three moving parts, one event log.

01

The kernel records

Each prompt, tool call, and error is appended to a durable log before any client renders it.

02

Clients replay

The terminal and desktop apps are views over that log. Open either one and the session rebuilds in milliseconds.

03

Hosts move

Run in-process on your laptop, or point the same session at a long-lived or serverless host over JSON and SSE.
